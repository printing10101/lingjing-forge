# Phase 2: 真实切削实验方案

> DL-LNN 铣削颤振预测 — 追赶前沿的关键堵点：从 sim-to-sim 走向 real-data validation
>
> 起草日期：2026-07-30 | 目标：15-20 次真实切削，3-5 组工况 × 3 次重复

---

## 1. 目标与背景

### 1.1 为什么必须做真实实验

当前 DL-LNN 全部在合成数据（Tlusty ZOA 解析模型）上训练和评估。2025 年领域前沿已进化到：
- Zhao MSSP 2025：DSAN + LMMD，**大量真实铣削实验**验证
- 朱/Engineering 2026：物理引导 + **真实数据微调**（2.67% 误差）

**没有真实实验 = 无法投 Q1/Q2 期刊。** 但这不意味着需要做 500 次——15-20 次真实切削 + 仿真预训练 + 分布自适应 = 有说服力的验证。

### 1.2 最小可行目标

| 指标 | 目标值 |
|------|--------|
| 工况组数 | 3-5 组（不同主轴转速 + 轴向切深） |
| 每工况重复 | 2-3 次 |
| 切削总次数 | 15-20 次 |
| 材料 | 6061-T6 铝合金（最便宜、最易切） |
| 传感器 | 加速度计 + 麦克风（或手机替代） |
| 标签定义 | 稳定/颤振（基于加工面质量 + 振动 FFT） |
| 核心指标 | sim→real 迁移后 MAE 改善 ≥ 5% |

## 2. 实验参数矩阵

### 2.1 基础切削条件

| 参数 | 符号 | 范围 | 单位 |
|------|------|------|------|
| 主轴转速 | n | 2000, 4000, 6000, 8000 | rpm |
| 轴向切深 | a_p | 0.5, 1.0, 2.0, 4.0 | mm |
| 径向切宽 | a_e | 2.0（固定） | mm |
| 进给速度 | f | 0.1（固定） | mm/齿 |
| 刀具直径 | D | 10 | mm |
| 刀具齿数 | z | 4 | — |
| 切削方式 | — | 顺铣（down-milling） | — |

### 2.2 推荐工况组合（5 组 × 3 次 = 15 次）

| 工况 | n (rpm) | a_p (mm) | 预期状态 | 理论 a_lim (mm) |
|------|---------|----------|---------|-----------------|
| C1 | 2000 | 0.5 | 稳定 | ~1.2 |
| C2 | 2000 | 2.0 | 颤振/临界 | ~1.2 |
| C3 | 4000 | 1.0 | 稳定 | ~2.0 |
| C4 | 4000 | 4.0 | 颤振 | ~2.0 |
| C5 | 6000 | 2.0 | 临界 | ~3.5 |

每条切痕长度 ≥ 50mm，宽度 = a_e = 2mm，确保信号采集时长 ≥ 3 秒。

## 3. 传感器与采集方案

### 3.1 方案 A：专业传感器（推荐，预算 ~1500 元）

| 设备 | 型号参考 | 数量 | 单价 | 用途 |
|------|---------|------|------|------|
| 三轴加速度计 | ADXL335 / MPU-6050 | 1 | ~50 元 | 机床/主轴振动 |
| IEPE 加速度计 | PCB 352C33（国产替代：东华 DH186） | 1 | ~500 元 | 高频振动（>10kHz） |
| 数据采集卡 | NI USB-6009（国产：阿尔泰 USB3200） | 1 | ~800 元 | 16 位，≥25kHz 采样 |
| 麦克风 | 普通 USB 麦克风 | 1 | ~100 元 | 切削声音（辅助判别） |

**总预算**：~1500 元（若借用贵大实验室设备则可降至 0）。

### 3.2 方案 B：极简方案（预算 ~200 元）

| 设备 | 来源 | 成本 |
|------|------|------|
| 手机加速度计 | 固定在主轴壳体上 | 0 |
| 手机录音 | 距离切削区 ~50cm | 0 |
| 数据导出 | MATLAB Mobile / phyphox App | 0 |
| 铝板 6061-T6 | 淘宝，100×50×20mm | ~150 元/10 块 |
| 整体刀具 | 淘宝，D10×4 齿硬质合金 | ~50 元/把 |

**此方案可用手机 APP (phyphox) 直接导出 CSV，采样率约 100-500 Hz（加速度计）和 44.1 kHz（音频）。低频加速度足以判别颤振主频（通常在 100-2000 Hz 范围）。**

### 3.3 采集参数

| 参数 | 值 |
|------|-----|
| 加速度采样率 | ≥ 5 kHz（专业）/ 100-500 Hz（手机） |
| 音频采样率 | 44.1 kHz |
| 每工况采集时长 | ≥ 3 秒（稳态切削段） |
| 数据格式 | CSV（时间戳, acc_x, acc_y, acc_z, audio） |
| 元数据 | 转速、切深、进给、刀具编号、材料批次 |

## 4. 颤振标签标注协议

### 4.1 判别方法（四级标签）

| 标签 | 含义 | 判别标准 |
|------|------|---------|
| 0: 稳定 | 无颤振 | 表面光滑、FFT 仅有刀齿通过频率 (f_t = n×z/60) 及其谐波 |
| 1: 轻微颤振 | 临界 | 表面有规律振纹、FFT 出现非谐波峰 ±20% f_t 范围内 |
| 2: 明显颤振 | 不稳定 | 表面粗糙、振纹密集、FFT 主频偏移 >20% f_t、出现倍频分裂 |
| 3: 严重颤振 | 灾难级 | 剧烈噪声、表面破坏、FFT 宽带噪声淹没峰值 |

### 4.2 标注流程

```
原始信号 → 带通滤波（100-5000 Hz）→ FFT 频谱
         → 表面粗糙度视觉评级
         → 结合 Tlusty 解析模型计算的理论 a_lim 交叉验证
         → 双盲标注（本人 + 协作者独立标注，不一致时讨论裁决）
```

## 6. 公开数据集备选

若贵大 CNC 获取失败，以下公开数据集可作为 Phase 2 的替代验证源：

### 6.1 Piecuch & Żabiński (Nature Scientific Data, 2025)
- **来源**：https://www.nature.com/articles/s41597-025-04923-y
- **内容**：14 把刀具全生命周期，968 次铣削循环
- **传感器**：8 通道振动（主轴 + 工作台）、12 通道电流
- **材料**：42CrMo4 钢，Haas VF-1 机床
- **优势**：同行评审期刊数据，质量高；振动信号完整
- **局限**：以刀具磨损为目标，**无颤振标签**（需自建 FFT 标签）

### 6.2 Wang (figshare, 2024)
- **来源**：https://figshare.com/articles/dataset/Milling_dataset/27323346
- **内容**：68 样本 × ~500 万行/样本，Ti6Al4V 钛合金
- **传感器**：旋转式测力仪（切削力/扭矩）、振动、声音
- **优势**：含直接切削力（颤振分析的黄金标准）
- **局限**：数据量大（~3.4 亿行），需预降采样

### 6.3 PHM 2010（已在项目中）
- 项目内 `research/datasets/uniwear/` 已有 PHM2010 数据
- 当前用于合成实验框架，原数据仅含刀具磨损标签
- 可复用为 Phase 2 的对照组（但非铣削颤振，是刀具磨损，需在论文中注明）

## 7. 贵大 CNC 获取路径（按优先级）

### 路径 1：RoboMaster 战队（最高成功概率）
- 贵大 RoboMaster 战队每赛季需大量 CNC 加工（机器人底盘/云台/发射器零件）
- 战队必然与机械工程学院/工程实训中心有加工合作
- **行动**：联系战队队长/机械负责人，询问 CNC 使用渠道和是否可以"借 1 小时车几刀铝板"
- **话术**：带上 DL-LNN 论文草稿和本方案——"我需要 15 次切削验证一个颤振预测算法，对你们的零件加工策略优化也有潜在价值"

### 路径 2：机械工程学院导师
- 贵大机械学院有制造工程/机械制造方向教授，通常有研究生做切削实验
- **行动**：通过课程老师/辅导员介绍 → 联系一位做制造方向的副教授/讲师 → 提出合作（"我提供算法，您提供实验数据，共同署名"）
- **话术**："老师您好，我是土木学院的学生，在做一项关于铣削颤振预测的 AI 方法研究，已有初步代码和合成数据验证，缺少真实切削实验。能否请您实验室的研究生帮忙做几组简单的铣削验证？我可以共享算法代码和论文署名。"

### 路径 3：工程实训中心
- 贵大工程实训中心通常有教学用数控铣床（Fanuc/Siemens 系统）
- **行动**：直接询问实训中心管理教师
- **注意**：教学用机床可能精度较低，但足以完成 6061 铝的简单切削

### 路径 4（备用）：外校协作
- 贵州理工学院、贵州师范大学等可能有更宽松的实验室访问
- 通过已认识的同学/竞赛队友介绍

## 8. 预算估计

| 项目 | 方案 A（专业） | 方案 B（极简） |
|------|---------------|---------------|
| 传感器 | ~1500 | ~0（手机） |
| 材料（铝板 6061-T6） | ~150 | ~150 |
| 刀具（D10 硬质合金） | ~50 | ~50 |
| 机床使用费 | 0（校内） | 0（校内） |
| **合计** | **~1700 元** | **~200 元** |

**方案 B 足以满足论文验证需求**。专业传感器的优势是高频信号（>5kHz），但颤振主频通常在数百到 2000 Hz，手机 100-500 Hz 采样率可覆盖（Nyquist 定理下可检测 ≤250 Hz，颤振始发频率在此范围内）。
