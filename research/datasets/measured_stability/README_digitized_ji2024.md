# Ji 2024 图形数字化数据集（provenance 与方法说明）

## 来源

- 论文：Ji Yongjian, Liu Runnan. *Research on the influence of cutter overhang length on robotic milling chatter stability*. **Scientific Reports** (2024). DOI: `10.1038/s41598-024-76165-8`. Open Access, PMC11496886。
- 提取对象：图 10（35 mm 悬伸 / x 向进给）、图 15（65 mm / x 向）、图 18（65 mm / y 向）中的铣削验证试验点（实心圆=稳定，红叉=再生日颤振）。

## 试验条件（论文正文核实）

| 项目 | 值 |
|---|---|
| 机床 | 串联工业机器人（本文研究对象） |
| 刀具 | 硬质合金立铣刀，直径 6 mm，3 齿 |
| 工件 | Al7075 铝合金（150×20×100 mm） |
| 悬伸 | 35 mm（Fig10）/ 65 mm（Fig15、Fig18） |
| 进给方向 | x 向（Fig10、Fig15）/ y 向（Fig18），全局坐标系 |
| 模态参数 | 每悬伸两套（论文表 1/2，正文测量） |

## 数字化方法（可复现）

1. 原图从 Springer Nature CDN 下载（`41598_2024_76165_Fig{10,15,18}_HTML.png`）。
2. 自动提取管线（脚本备份于 `.workbuddy/tmp/digitize_figures.py` + `clean_digitized.py`）：
   - 面板框检测（灰度 <200 长线）；
   - x 标定：左右框线 = xlim [2000, 20000] rpm（matplotlib 惯例，已用网格线验证：35.3 px/1000 rpm）；
   - y 标定：浅灰网格线（RGB 相等且 230–249）等间距 + 底框 = 0；各面板网格线检出数与期望完全一致（9/9、4/4、17/17、2/2、17/17、2/2）；
   - 标记检测：颜色连通域（蓝：B>130 且 B−R>50 且 B−G>50；红对称），包围盒 ≤16/18 px（排除同色曲线陡段）；
   - 图例伪点剔除：按手工测量的图例框区域（每图 2–3 个伪点：图例圆点、图例叉、粉色边框碎片）。
3. **锚点验证**：正文点名的 6 个可核对组合 A/B/D/E/F/G 全部匹配，误差 ≤30 rpm、≤0.1 mm（E 的 ap 数字化读数 0.30 mm vs 正文 0.4 mm，属于图与正文取整差异，见下）。

## 精度与局限（使用前必读）

| 项 | 说明 |
|---|---|
| 坐标精度 | n: ±30 rpm；ap: ±0.1 mm（锚点验证实测） |
| **ae（径向切宽）未知** | 每图上下两个子图对应两种径向切宽，**图注未写明数值**。本文件不设 ae 列；使用时勿臆测。子图以 `panel` 列区分 |
| E/G 的 ap 口径 | 正文 E=(12000, 0.4 mm)，图中该行数字化为 0.30 mm；G 正文 1.2 mm，图上同行多数点读 1.1、G 读 1.2。以 `ap_mm`（数字化）与 `ap_level_mm`（行值）两列同时保留 |
| 双重颤振点 | Fig18 top 有 2 个"方框叉"（再生日颤振+低频颤振并存，位于 (2500, 3.2) 与 (2500, 2.0)），本表按 chatter 计，未单列类型 |
| 同源性 | **全部 152 点来自同一台机器人、同一刀具、同一材料**——机床/刀具多样性仍需 `LITERATURE_POINTS_CHECKLIST.md` 中其余 4 篇文献补充 |
| 类别分布 | stable 27 / chatter 125（作者主要标绘失稳区，属论文呈现偏差，使用时注意先验） |

## 字段说明

| 列 | 含义 |
|---|---|
| fig / panel | 来源图与子图（top=大盘，bot=小盘，两盘 ae 不同） |
| overhang / feed | 悬伸 mm / 进给方向（x/y） |
| n_rpm | 主轴转速（数字化，±30 rpm） |
| ap_mm | 轴向切深 mm（数字化，±0.1） |
| ap_level_mm | 所属离散试验水平行（空白=未能归行） |
| ap_off_level | 1=偏离任何水平行（曲线碎片嫌疑，当前为 0 行） |
| result | stable / chatter |
| px / py / size | 原图像素坐标与连通域大小（审计用） |

## 与既有数据集的关系

- `measured_stability_points.csv`（7 点）= 正文文字点名组合，**文字精确值**，继续作为"金标准锚点"。
- 本文件（152 点）= 同一篇论文图中**全部**可提取试验点，量大但带数字化容差。
- 二者并入分析时以 `measured_stability_points.csv` 为校准、本文件为统计样本。
