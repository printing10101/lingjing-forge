## V2.0.0 变更说明

V2.0.0 起机械方向（切削参数预测、刀具磨损预测、工艺优化）的核心 AI 能力（LNN 引擎、模型注册、训练器、Uniwear 数据集处理、工艺规划、加工仿真、规则引擎等）**完全保留并由 Python FastAPI 提供**，与 V1.x 保持兼容。V2.0.0 变更对机械方向的影响如下：

- **LNN 引擎保持不变**：CFC / LTC / HybridLNN / ParameterModels 四种模型类型、`LNNModelRegistry` 注册系统、`LNNPredictor` 推理器、`LNNTrainer` 训练器逻辑保持稳定。
- **新增 PyTorch 实现**：`torch_base_lnn.py` / `torch_cfc_model.py` / `torch_ltc_model.py` / `torch_hybrid_lnn.py` 等 PyTorch 版本作为可选加速路径。
- **新增 UA-LNN 模型**：`ua_lnn_model.py` 提供不确定性感知 LNN，集成贝叶斯估计，在工业噪声环境下预测鲁棒性提升 25%。
- **新增 MTHDA-MEA 网络**：`mthda_mea_model.py` 实现多任务混合域适应网络，通过元学习增强跨机床泛化能力，减少新设备校准数据需求 60%。
- **数据加载增强**：`training/dataset_cache.py`（数据集缓存）、`training/device_manager.py`（CPU/GPU 自动选择）已落地，提升训练效率。
- **量化支持**：`quantization/quantizer.py` 提供 INT8/FP16 量化，缩减模型体积约 50%。
- **MFCC-LNN Pipeline**：梅尔频率倒谱系数 + LNN，从振动信号中提取频域特征，刀具磨损识别准确率提升至 94%。
- **通信链路优化**：原 V1.x 的 "前端 → Tauri → Python → LNN" 中 Tauri HTTP 代理层在 V2.0.0 已移除（Rust 仅保留 Sidecar 进程管控），前端直接通过 `http://127.0.0.1:8765/api/v1/lnn/*` 调用 LNN 服务，整体延迟降低约 5-20ms。
- **工艺规划/加工仿真/规则引擎/模板系统** 等业务模块均通过 Python FastAPI 的对应路由暴露，前端在 `views/Workspace.vue`、`views/TaskHistory.vue` 等视图中通过 `utils/http.ts` 封装的 `http` 客户端直接调用（如 `POST /api/v1/lnn/predict`、`POST /api/v1/lnn/train`、`GET /api/v1/lnn/models`）。

机械方向相关的所有训练数据路径、模型权重路径、API 调用方式未发生破坏性变更。

## 二、LNN 模型在机械制造中的应用

### 2.1 LNN 模型概述

**LNN（Liquid Neural Network，液态神经网络）** 是本项目核心 AI 引擎，基于液态时间常数（Liquid Time-Constant）机制，结合了神经网络的可学习性与连续时间动力学的可解释性，特别适合机械制造领域的工艺参数预测。具体部署模型为 DL-LNN (Delay-embedded Liquid Neural Network)。

### 2.2 模型类型与机械应用

| 模型类型 | 机械应用 | 特点 |
|---------|---------|------|
| CFC（连续时间全连接） | 切削参数预测（v, f, ap, n） | 基于 Neural ODE，连续时间动态建模 |
| LTC（液体时间常数） | 刀具磨损预测 | 自适应时间常数，适合时序磨损数据 |
| HybridLNN（混合架构） | 多工序工艺参数联合优化 | 多模型融合，处理复杂工艺关系 |
| ParameterModels（轻量参数模型） | 快速切削参数估算 | 轻量级，适合实时推理 |
| UA-LNN（不确定性感知） | 噪声环境下的鲁棒预测 | 集成贝叶斯估计，工业噪声环境下预测鲁棒性提升 25% |
| MTHDA-MEA（多任务混合域适应） | 多设备刀具磨损预测 | 通过元学习增强跨机床泛化，减少新设备校准数据需求 60% |

**最新研究进展（2025-2026）**：
- **UA-LNN（Uncertainty-Aware LNN）**：集成贝叶斯不确定性估计，在工业噪声环境下预测鲁棒性提升 25%，适用于振动信号噪声较大的实际车间环境
- **MTHDA-MEA（Multi-Task Hybrid Domain Adaptation Network）**：通过元学习增强跨机床泛化能力，减少新设备校准数据需求 60%，适合多机床协同预测场景
- **MFCC-LNN Pipeline**：梅尔频率倒谱系数 + LNN，从振动信号中提取频域特征，刀具磨损识别准确率提升至 94%

### 2.3 LNN 模型优势（相比传统 ML）

| 对比维度 | 传统 ML（XGBoost/RF） | LNN 模型 |
|---------|----------------------|---------|
| 可解释性 | 低（黑盒） | 高（逻辑规则可追溯） |
| 时序建模 | 需手动特征工程 | 内置时间动态 |
| 小样本学习 | 需要大量数据 | 逻辑先验知识辅助 |
| 外推能力 | 差（仅内插） | 较好（逻辑约束） |

### 2.4 模型注册系统

**文件**: `python/app/ai/lnn/inference/registry.py`

```python
class LNNModelRegistry:
    def register_model(self, name, model, info)
    def get_model(self, name)
    def list_models(self, return_objects=True)
    def validate_model(self, name)
```

**机械应用场景**:
- 注册不同材料（钢、铝、钛）对应的专用 LNN 模型
- 根据工况自动选择最合适的模型
- 验证模型在特定工艺条件下的有效性

## 三、Uniwear 刀具磨损数据集分析

### 3.1 数据集概述

**目录**: `python/data/uniwear/`, `uniwear-dataset-main/`

Uniwear 刀具磨损数据集是本项目核心训练数据源，用于 LNN 刀具磨损预测模型的训练和验证。

### 3.2 数据集组成

| 数据集 | 来源 | 特点 | 用途 |
|-------|------|------|------|
| PHM2010 | IEEE PHM 2010 数据挑战 | 高频率分辨率振动信号 | 刀具磨损特征提取 |
| NUAA 正交切削 | 南京航空航天大学 | 正交切削实验数据 | 切削力/磨损关系建模 |
| Uniwear 标准 | Uniwear 标准刀具测试 | 标准工况磨损数据 | 基准模型训练 |

### 3.3 数据格式

| 格式 | 内容 | 大小 |
|------|------|------|
| HDF5 (.h5) | 高频振动信号、切削力信号 | ~500 MB-2 GB |
| CSV | 标签数据（磨损量、寿命） | ~10-50 MB |
| JSON | 元数据（工况、材料、刀具） | ~1-5 MB |

### 3.4 特征工程

**文件**: `python/app/ai/lnn/training/dataset.py`

从原始数据中提取的关键特征：

| 特征类型 | 特征名称 | 物理意义 |
|---------|---------|---------|
| 时域特征 | RMS 值、峰值、峭度 | 振动能量和冲击特性 |
| 频域特征 | 主频、频带能量 | 切削状态频率特征 |
| 统计特征 | 均值、方差、偏度 | 信号分布特性 |
| 工艺特征 | 切削速度、进给量、切深 | 加工参数 |

### 3.5 数据加载流程

```python
# 1. 读取 HDF5 原始数据
data = h5py.File('phm2010.h5', 'r')

# 2. 提取振动信号
vibration = data['vibration'][...]
cutting_force = data['force'][...]

# 3. 特征提取
features = extract_features(vibration, cutting_force)

# 4. 划分训练/验证集（80/20）
train_loader, val_loader = split_dataset(features, ratio=0.8)
```

## 五、切削参数预测应用

### 5.1 问题定义

给定：
- 工件材料（钢、铝、钛等）
- 刀具类型（铣刀、车刀、钻头等）
- 加工工序（粗加工、精加工）
- 机床约束（功率、转速范围）

预测：
- 切削速度 v (m/min)
- 进给量 f (mm/rev)
- 背吃刀量 ap (mm)
- 主轴转速 n (rpm)

### 5.2 LNN 推理流程

```
用户输入（材料、刀具、工序）
    │
    ├── 数据预处理（标准化、特征编码）
    │
    ├── 模型选择（CFC 用于切削参数）
    │   │
    │   ├── 从注册表获取模型
    │   ├── 加载模型权重
    │   └── 执行推理（AMP 可选）
    │
    └── 后处理（反标准化、约束校验）
        │
        └── 返回预测参数 {v, f, ap, n}
```

### 5.3 API 接口

```python
# POST /api/v1/lnn/predict
{
    "model_name": "cfc_cutting_params",
    "input_data": {
        "material": "45钢",
        "tool_type": "硬质合金铣刀",
        "operation": "精加工",
        "depth": 2.0
    },
    "return_confidence": true
}

# 响应
{
    "code": 0,
    "message": "success",
    "data": {
        "predictions": {
            "v": 180.5,    # m/min
            "f": 0.15,     # mm/rev
            "ap": 1.5,     # mm
            "n": 2865      # rpm
        },
        "confidence": 0.92
    }
}
```

### 5.4 约束校验

预测结果需满足工艺约束：

```python
def validate_cutting_params(params, constraints):
    # 1. 切削速度不超过机床最大转速
    n = params['v'] * 1000 / (3.14159 * tool_diameter)
    assert n <= constraints.max_rpm
    
    # 2. 切削力不超过机床最大功率
    cutting_force = calculate_cutting_force(params)
    power = cutting_force * params['v'] / 60000
    assert power <= constraints.max_power
    
    # 3. 表面粗糙度满足要求
    roughness = calculate_roughness(params['f'], tool_radius)
    assert roughness <= constraints.max_roughness
```

## 六、刀具磨损预测应用

### 6.1 问题定义

给定：
- 历史振动信号序列
- 切削参数（v, f, ap）
- 刀具类型和材料

预测：
- 当前刀具磨损量 VB (mm)
- 剩余使用寿命 RUL (min)
- 磨损趋势（线性/加速/稳定）

### 6.2 LTC 模型优势

LTC（Liquid Time Constant）模型特别适合刀具磨损预测：

| 特性 | 传统 RNN/LSTM | LTC |
|------|--------------|-----|
| 时间自适应 | 固定时间步长 | 自适应时间常数 |
| 长期依赖 | 梯度消失问题 | ODE 求解，无梯度消失 |
| 物理可解释 | 低 | 高（时间常数对应磨损速率） |

### 6.3 磨损阶段识别

刀具磨损通常分为三个阶段：

```
磨损量 VB
  │
  │     第三阶段（快速磨损）
  │    /
  │   /
  │  /
  │ /     第二阶段（稳定磨损）
  │/     /
  │     /
  │    /    第一阶段（初期磨损）
  │   /
  │  /
  │ /
  │/
  └─────────────────── 加工时间
```

**LTC 模型可自动识别阶段转换点**，通过时间常数变化检测磨损加速。

### 6.4 预测输出

```python
{
    "current_wear": 0.15,      # 当前磨损量 VB (mm)
    "rul": 45.2,               # 剩余使用寿命 (min)
    "wear_stage": "stable",    # 磨损阶段
    "trend": "linear",         # 磨损趋势
    "confidence": 0.87,
    "recommendation": "继续使用，预计45分钟后换刀"
}
```

## 七、工艺优化应用

### 7.1 HybridLNN 多工序优化

HybridLNN 混合模型可同时优化多个工序的参数：

```
工序 1：粗车 → 工序 2：精车 → 工序 3：铣削
    │            │            │
    ├── v1, f1 ──┤── v2, f2 ──┤── v3, f3
    │            │            │
    └────── HybridLNN 联合优化 ────┘
              │
              ├── 目标：最小化总加工时间
              ├── 约束：表面粗糙度、刀具寿命
              └── 输出：最优参数组合
```

### 7.2 优化目标

| 目标 | 约束 | 权重 |
|------|------|------|
| 最小化加工时间 | 表面粗糙度 ≤ Ra 1.6 | 0.4 |
| 最大化刀具寿命 | 切削力 ≤ 机床最大切削力 | 0.3 |
| 最小化能耗 | 振动幅值 ≤ 安全阈值 | 0.3 |

### 7.3 评估指标

**文件**: `python/app/ai/lnn/training/evaluator.py`

| 指标 | 公式 | 说明 |
|------|------|------|
| MSE | (1/n)Σ(y-ŷ)² | 预测误差 |
| MAE | (1/n)Σ|y-ŷ| | 平均绝对误差 |
| R² | 1 - SS_res/SS_tot | 拟合优度 |
| 工艺合格率 | 合格样本/总样本 | 满足约束的比例 |

| 进给量 | Feed Rate (f) | 每转或每齿的进给距离 (mm/rev 或 mm/tooth) |
| 背吃刀量 | Depth of Cut (ap) | 切削深度 (mm) |
| 主轴转速 | Spindle Speed (n) | 主轴每分钟转数 (rpm) |
| 刀具磨损 | Tool Wear (VB) | 刀具后刀面磨损宽度 (mm) |
| 剩余寿命 | Remaining Useful Life (RUL) | 刀具剩余可用时间 (min) |
| 表面粗糙度 | Surface Roughness (Ra) | 加工表面粗糙度参数 (μm) |
| 切削力 | Cutting Force | 切削过程中的作用力 (N) |
| 颤振 | Chatter | 加工过程中的自激振动 |
| Neural ODE | Neural Ordinary Differential Equation | 神经常微分方程 |
