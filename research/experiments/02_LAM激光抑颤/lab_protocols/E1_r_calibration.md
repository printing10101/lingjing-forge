# E1 实验协议：温差比 r 与功率-温升系数 ξ 标定（闭合 §4.4）

> 对应论文 §11 E1 与 §4.4。目标：**闭合唯一未实测参数 r**，并独立标定 ξ。
> 完成本实验后，论文 §4.4 的 r=0.3 假设升级为实测值，§10.3 局限 1 消除。

## 1. 硬件清单

| 设备 | 规格 | 用途 |
|---|---|---|
| 光纤激光器 | ≥1 kW，聚焦光斑 2 mm（可调），PWM/模拟量功率控制接口 | 加热源 |
| K 型热电偶 ×6 | 焊接式/点胶式，量程 0–1200 °C，采样 ≥10 Hz（推荐 100 Hz） | 温度测量 |
| 热像仪（可选） | FLIR 级，分辨率 ≈0.1 mm/像素 | 切削区温度复核 |
| 数据采集卡 | ≥16 通道，同步采样 | 多通道同步 |
| 数控车床/铣床 | 主轴转速可调 20–70 m/min | 切削平台 |

## 2. 测点布置（关键）

```
          激光头（出光方向→切削区）
             │
   切削区热电偶 T1（刀刃后方 2–3 mm，切削区近端）
   结构远端热电偶 T2（工件夹持端，距切削区 ≥100 mm）
   主轴壳体热电偶 T3（轴承座外侧）
   备用 T4/T5/T6（T2/T3 冗余 + 工件另一端）
```

- **T1 必须是切削区近端**（反映 ΔT 切削区）
- **T2 是结构远端点**（反映结构体整体温升）→ r = ΔT_结构/ΔT_切削区 = T2 温升/T1 温升
- 激光功率阶梯：**0 / 200 / 400 / 600 / 800 W**（每档稳态 30 s，共 5 档）
- 每组重复 **3 次**（随机顺序，统计离散度）

## 3. 步骤

1. 装夹工件，布置热电偶（T1 焊接于切削区近端面，T2 于夹持端，T3 于主轴壳体），连接采集卡，设置同步采样 100 Hz
2. **无切削标定**（不启动主轴）：激光功率阶梯 0→800 W，每档保持 30 s，记录 T1–T3 温升 → 得 ξ 无切削基线
3. **稳态切削标定**：转速 20–70 m/min 内选 3 档，每档重复功率阶梯（0/200/400/600/800 W），记录温升与切削力（需测力计，E2 联动）
4. 数据处理（见 `lab_analysis.py`）：
   - ξ = ΔT_切削区/ΔP（每档功率差，单位 °C/kW）
   - r = ΔT_结构/ΔT_切削区（稳态窗平均）
   - 检查 r 是否随功率/转速漂移（若漂移，论文 §7.1 的 r 分布应改为分段分布）

## 4. 判定标准（对照论文）

| 指标 | 论文当前假设 | 实验通过标准 |
|---|---|---|
| r | 0.3（聚焦激光） | 实测 r ∈ [0.2, 0.6] 且不随功率显著漂移 → §4.4 升级 |
| ξ | 733–1107 °C/kW | 实测 ξ 落入该区间（否则 §4.3 交叉标定需修正） |
| r 最坏情形 | r→1（MC 披露） | 实测 r 上限 <0.8 → §7.2 最坏情形收紧 |

## 5. 输出

- 数据文件：`lab_data/e1_*.csv`（时间戳/功率/T1–T6/主轴状态）
- 结果文件：`lab_data/e1_results.json`（ξ、r 各工况值 + 统计）
- 论文更新：§4.4 表格填实测值，§10.3 局限 1 标记"已闭合"

## 6. 学术诚信要求

- 原始 CSV 与处理脚本**一并归档**（可复现性硬约束）
- 若 r 实测与 0.3 假设偏离 >0.2，必须如实报告并重跑 §5–§7 关键结果（脚本已参数化，改 r 重跑即可）
- 负结果（如 r 随功率强漂移）同样发表——这本身就是有价值的发现
