# 支持与反馈

> 单人维护项目：响应有承诺、修复不承诺。请按下表选择入口，避免私信/电话丢失上下文。

## 响应入口

| 场景 | 入口 | 说明 |
|---|---|---|
| 缺陷（崩溃、报错、结果不对） | GitHub Issues · [Bug Report](https://github.com/printing10101/Virtual-Realm-Manufacturing/issues/new?template=bug_report.yml) | 附复现步骤与日志 |
| 功能建议 | GitHub Issues · [Feature Request](https://github.com/printing10101/Virtual-Realm-Manufacturing/issues/new?template=feature_request.yml) | 说明使用场景与期望行为 |
| 安全漏洞 | [GitHub Security Advisory](https://github.com/printing10101/Virtual-Realm-Manufacturing/security/advisories/new)（私密） | 请勿公开提交 |
| 安装/许可问题 | 同上 Bug Report，标题加 `[安装]` / `[许可]` 前缀 | 附 `VERSION` 与安装包 SHA256 |

## 响应时限（可执行承诺）

- **工作日 72 小时内首次响应**（确认收到 + 初步判断）。
- 修复时间**不做承诺**：取决于复现难度与是否触及物理校验逻辑。
- 不在承诺范围内：电话、远程接管、QQ/微信群实时答疑。

## 提交必备信息

1. **版本**：`VERSION` 文件内容，或应用「关于」页截图；
2. **环境**：Windows 版本、是否干净机安装、Python/运行时版本（如为源码运行）；
3. **复现步骤**：最短路径，含输入文件类型（DXF/STEP）与操作顺序；
4. **日志**：`data/logs/` 下对应时间段的日志片段（≤200 行）；
5. **脱敏**：图纸与日志中去除客户名、零件号、绝对路径中的个人信息。

## 支持范围

覆盖：安装与启动、DXF/STEP 导入、特征识别、切削参数、G-code 生成、体素校验、国产控制器后处理、许可证。

不覆盖：

- **上机安全责任**：本软件输出仅供工程师复核，实际加工须经 CAM 二次校验与持证操作员确认；
- 客户数据代管、图纸保密托管；
- 生产现场实时救火。

## 已知问题的自查顺序

1. 先看 [故障排查](/user-guide/故障排查)；
2. 再搜 Issues 是否已有同类；
3. 仍无法解决再新开 Issue，按上面「必备信息」填写。
