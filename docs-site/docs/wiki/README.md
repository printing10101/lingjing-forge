# 灵境制造（Virtual-Realm-Manufacturing）Code Wiki

> 版本：v2.5.0  
> 仓库：printing10101/Virtual-Realm-Manufacturing  
> 文档生成时间：2026-06-10

本仓库是一套面向机械加工行业的 **AI 驱动桌面工具**（同时支持 Web 与 Tauri 桌面形态），核心解决"图纸 → NC 代码"全流程效率低、门槛高、数据不安全的问题。系统以"数据不出厂"为安全底线，本地集成大模型（LNN / LLM / Ollama）、工艺知识图谱与后处理器，可在车间一线完成"三视图解析 → 3D 重建 → 工艺规划 → 后处理 → 仿真"全流程。

## 一句话总结

> 灵境制造 = **Vue 3 + Tauri 桌面壳** ↔ **FastAPI 后端** ↔ **LNN/AI 推理** + **DXF/STEP 解析** + **CNC 后处理**，运行在本地或内网，做到"图纸-模型-工艺-NC 代码"端到端自动化，"数据不出厂"。
