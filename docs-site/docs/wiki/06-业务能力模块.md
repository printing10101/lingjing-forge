# 06. 业务能力模块

> 本章覆盖 DXF/STEP 解析、CAM、工艺规划、后处理、CAD、RAG、插件等"非 AI 引擎"但与制造工艺紧密耦合的模块。

## 6.1 DXF 流水线 `app/dxf/`

### 6.1.1 端到端流程
`pipeline.py:DxfPipeline` 编排 6 个阶段：

| 阶段 | 模块 | 作用 |
|------|------|------|
| 1. DXF 解析 | `dxf_parser.py` | 提取几何实体 + 尺寸标注 |
| 2. 特征提取 | `feature_extractor.py` | 识别孔/槽/型腔等加工特征 |
| 3. 3D 转换 | `dxf_to_model.py` | CadQuery 实体建模 |
| 4. 数据组装 | `pipeline.py` | 转换为 process_planning 兼容格式 |
| 5. 工艺规划 | `ProcessPlanningPipeline` | 工序 + 刀轨 |
| 6. 结果验证 | `pipeline.py` | 完整性 + 语法校验 |

### 6.1.2 关键 API
- `app/dxf/api.py` 暴露：
  - `POST /api/dxf/parse` — 仅解析
  - `POST /api/dxf/features` — 提取特征
  - `POST /api/dxf/to-model` — 3D 转换
  - `POST /api/dxf/pipeline` — 端到端

### 6.1.3 异常体系
`exceptions.py` 自定义 DXF 解析/特征/转换异常，UI 层统一捕获。

## 6.3 工艺规划 `app/process_planning/`

> 具体代码在 `pipeline.py` 路径引用，模块根在 `python/app/process_planning/`。

主要功能：
- 根据加工特征（孔/槽/型腔/平面）自动选刀
- 工序编排（粗/精加工、铣/钻/攻丝）
- 切削参数计算（基于材料 + 刀具库）
- 刀轨生成（粗加工：型腔铣；精加工：轮廓铣）
- 输出兼容后处理器的刀轨描述

数据依赖：
- 刀具库：`python/app/data/tools.json` + `python/app/database/data/tools.json`
- 材料库：`python/app/data/materials.json`
- 机床库：`python/app/database/data/machines.json`
- 工艺规则：`python/app/data/process_rules.json`

## 6.4 后处理 `app/postprocessor/`

### 6.4.1 抽象基类 `base.py:BasePostProcessor`
```python
class BasePostProcessor(ABC):
    decimal_places: int
    safe_z_height: float
    rapid_feed: float
    config: Dict
    limiter: ConfigLimiter

    @abstractmethod
    def generate_header(self, ctx) -> str: ...
    @abstractmethod
    def generate_footer(self, ctx) -> str: ...
    @abstractmethod
    def format_move(self, x, y, z, feed, rapid=False) -> str: ...
    @abstractmethod
    def format_spindle(self, rpm, direction="CW") -> str: ...
    @abstractmethod
    def format_tool_change(self, tool_id) -> str: ...
```

### 6.4.2 已实现控制器
| 文件 | 控制器 | 特点 |
|------|--------|------|
| `fanuc.py` | Fanuc | G 代码 + 宏变量 |
| `siemens.py` | Siemens | SINUMERIK 840D 方言 |
| `heidenhain.py` | Heidenhain | Klartext 对话式编程 |
| `registry.py` | 注册表 | 工厂 + 缓存 |

### 6.4.3 配置加载 `config_loader.py`
- `ConfigLimiter`：主轴/进给速度限幅
- `create_limiter(config)`：根据配置创建限幅器
- `config/postprocessor_config.yaml` 提供默认值
