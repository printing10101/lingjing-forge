# 03. 目录结构与代码地图

> 本仓库同时是 **Web 应用**（Vue 3 + FastAPI）和 **桌面应用源码**（Tauri 嵌入 WebView + Python Sidecar）。
> 代码主体在 `src/`（前端）和 `python/app/`（后端）。
