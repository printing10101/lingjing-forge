# 09. 前端架构

> 前端以 Vue 3 + TypeScript + Vite 为主，技术栈详见 [01. 项目概览](./01-项目概览.md)。

## 9.1 入口与启动

### 9.1.1 `src/main.ts`
```typescript
const app = createApp(App)
app.use(createPinia())
app.use(i18n)
app.use(router)
registerDirectives(app)
app.mount('#app')
```

### 9.1.2 `src/App.vue`
- 顶部应用栏（菜单 + 顶栏按钮 + 文件下拉）
- 全局对话框：ErrorConflictDialog、ErrorNotification
- 全局目标对齐 + 工程信息展示

## 9.2 路由 `src/router/index.ts`

### 9.2.1 路由模式
- 默认：`createWebHistory`（HTML5 History）
- 桌面模式：Tauri 提供的 `tauri://localhost`

### 9.2.2 守卫
```typescript
router.beforeEach((to, from, next) => {
  // 1. 公开页面（/login）放行
  // 2. 未登录 → /login
  // 3. 已登录 → /login → /workspace
  // 4. 权限校验（meta.requiresPermission）
  next()
})
```

## 9.4 HTTP 客户端 `src/utils/http.ts`

```typescript
const http = axios.create({ baseURL: '/api' })

http.interceptors.request.use(config => {
  config.headers['X-Request-ID'] = nanoid()
  return config
})

http.interceptors.response.use(
  response => response.data,
  error => {
    // 统一错误处理：弹窗 + 上报
    showErrorDialog(error)
    return Promise.reject(error)
  }
)
```

## 9.8 构建与开发

```bash
pnpm install
pnpm dev                # 启动开发服务器
pnpm build              # 生产构建
pnpm test:run           # Vitest 单元测试
pnpm test:coverage      # 覆盖率
pnpm tauri dev          # 桌面开发模式
pnpm tauri build        # 桌面生产构建
pnpm lint               # ESLint
```

`vite.config.ts` 配置：
- 代理 `/api` → `http://localhost:8765`
- 代理 `/api/v1` → `http://localhost:8765`
- 端口 1420（Tauri 默认）
- unplugin-auto-import
- unplugin-vue-components
