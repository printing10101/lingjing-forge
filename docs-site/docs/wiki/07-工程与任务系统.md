# 07. 工程与任务系统

## 7.1 工程管理 `app/projects/`

### 7.1.1 核心文件
| 文件 | 职责 |
|------|------|
| `project_api.py` | FastAPI 路由（CRUD） |
| `project_store.py` | 存储与持久化（`.vrm` 文件） |

### 7.1.2 `.vrm` 文件
- 后缀：`.vrm`
- 内容：JSON（图形/工艺/参数/历史）
- 用途：跨会话/跨设备保存/分享完整工程

### 7.1.3 API
- `POST /api/projects` — 创建
- `GET  /api/projects` — 列表
- `GET  /api/projects/{id}` — 详情
- `PUT  /api/projects/{id}` — 更新
- `DELETE /api/projects/{id}` — 删除
- `POST /api/projects/{id}/export` — 导出
- `POST /api/projects/import` — 导入

### 7.1.4 前端 `src/stores/project.ts`
Pinia store 集中管理：
- 工程列表 / 当前工程 / 加载状态
- CRUD 操作 / 导入导出
- 错误处理

视图：
- `src/views/Workspace.vue` — 主工作区
- `src/views/ApprovalDashboard.vue` — 审批工作流
- `src/views/BranchManager.vue` — 分支管理

## 7.2 异步任务系统 `app/tasks/`

### 7.2.1 核心组件
| 组件 | 文件 | 职责 |
|------|------|------|
| `AsyncTaskManager` | `task_system.py` | 中央调度器 |
| `TaskType` | `task_manager.py` | 任务类型枚举 |
| `TaskStatus` | `task_manager.py` | 任务状态枚举 |
| `execution.py` | `app/tasks/execution.py` | 执行函数包装 |
| `execution_lock.py` | `app/tasks/execution_lock.py` | 互斥锁（签出） |
| `task_checkout.py` | `app/tasks/task_checkout.py` | 签出/释放 |
| `worker_process.py` | `app/tasks/worker_process.py` | 独立进程 worker（重型任务） |

### 7.2.2 数据存储
| 介质 | 用途 | Key/Table |
|------|------|-----------|
| PostgreSQL | 任务元数据（id/类型/状态/参数/结果/时间） | `training_tasks` |
| Redis | 实时进度 + 取消标志 | `task_progress:{id}` / `cancel:{id}` |
| asyncio | 协程调度 + 并发控制 | `max_concurrent` |

### 7.2.3 任务生命周期
```
PENDING ──→ RUNNING ──→ COMPLETED
                    │
                    ├──→ FAILED
                    ├──→ CANCELLED
                    └──→ TIMEOUT
```

### 7.2.4 幂等与取消
- **幂等键**：`idempotency_key` 字段，相同 key 不重复创建
- **取消**：`cancel:{id}` 标志，协程定期检查

### 7.2.5 API
- `POST /api/v1/jobs` — 提交任务
- `GET  /api/v1/jobs/{id}` — 查询状态
- `GET  /api/v1/jobs` — 列表
- `POST /api/v1/jobs/{id}/cancel` — 取消
- `GET  /api/v1/jobs/{id}/stream` — SSE 进度流

### 7.2.6 前端
- `src/stores/tasks.ts` — Pinia store
- `src/composables/useEventSource.ts` — SSE 订阅封装
- `src/views/TaskBoard.vue` — 任务看板
- `src/views/TaskHistory.vue` — 历史

## 7.3 SSE 实时通信 `app/api/v1/sse.py`

### 7.3.1 设计
```
SSEConnectionManager
  ├─ connections: Dict[str, List[asyncio.Queue]]
  ├─ connect(channel) → queue
  ├─ disconnect(channel, queue)
  ├─ broadcast(channel, event, data)
  └─ send_to(channel, target, event, data)
```

### 7.3.2 Channel 命名约定
- `tasks/{task_id}` — 单任务进度
- `user/{user_id}` — 用户级通知
- `system/{topic}` — 系统事件

### 7.3.3 前端
- `useEventSource` 封装 EventSource 自动重连
- `SseStatus` 状态显示（连接/重连/错误）

## 7.4 工作区 `app/workspace/`

- `workspace.py` — 工作区生命周期
- 在桌面模式下与 Tauri 主进程协调文件系统

## 7.5 典型交互链

```
用户提交 LNN 训练
   │
   ▼
POST /api/v1/lnn/train
   │
   ▼
LNN 路由 → AsyncTaskManager.submit()
   │
   ├─── INSERT training_tasks(id, status=PENDING)
   ├─── 创建 Redis: task_progress:{id} = 0
   ├─── 调度协程（最多 max_concurrent）
   │
   ▼
协程执行：LNNTrainer.train()
   │
   ├─── 定期更新 Redis: task_progress:{id} = 0.42
   ├─── SSE 广播: tasks/{id} {progress: 0.42}
   │
   ▼
完成 → status=COMPLETED，result 写入 DB
   │
   ▼
SSE: tasks/{id} {status: "completed", result: {...}}
   │
   ▼
前端 useEventSource 收到 → 更新 Pinia store → UI 显示完成
```

## 7.6 工程 ↔ 任务 关联

工程文件（.vrm）可保存对任务的引用：
- 任务的 input/output 可嵌入工程
- 任务失败可被工程回滚
- 同一工程支持多任务编排（branch + A/B test）
