## 2.5 关键技术点

### 2.5.1 统一鉴权
`UnifiedAuthMiddleware`（纯 ASGI）在请求级一次性识别 LNN/JWT/Agent 三种令牌类型，公开路径短路，对保护路径执行权限检查。

### 2.5.2 异步任务持久化
`AsyncTaskManager`（`app/tasks/task_system.py`）使用：
- PostgreSQL 存任务元数据（`training_tasks` 表）
- Redis 存实时进度（`task_progress:{id}`）
- asyncio 协程调度
- SSE 广播（`SSEConnectionManager`）

支持幂等键（`idempotency_key`）和取消标志（`cancel:{id}`）。

### 2.5.3 LNN 混合推理
输入 → `TaskParser` → `TaskRouter`（规则 40% + ML 60%）→ 引擎选择 → 多个引擎并行/串行执行 → `Dempster-Shafer` 融合 → `FusionResult`（结论 + 证据 + 置信度 + 路径）。

### 2.5.4 CORS 安全门
启动时 `enforce_startup_security()` 强制校验，配置错误（非空 `allow_origins` 与 `allow_credentials=True` 冲突等）→ 立即 `sys.exit(1)`，不允许带病上线。

### 2.5.5 限流
基于 `slowapi` 的 `Limiter`，默认 100 req/min/IP，端点级 `@limiter.limit("60/minute")` 覆盖。

### 2.5.6 心跳与自动休眠
`IdleAutoShutdownMiddleware` 跟踪空闲时间，30 分钟无活动自动写入状态文件并优雅退出。

### 2.5.7 数据主权
`/api/v1/user_sovereignty` 提供用户级数据隔离与可携带性。
