# 10. 数据与基础设施

## 10.1 PostgreSQL `app/database/`

### 10.1.1 主要表
| 表 | 用途 |
|----|------|
| `users` | 用户 |
| `roles` / `user_roles` | 角色与关联 |
| `permissions` / `role_permissions` | 权限与关联 |
| `training_tasks` | 异步任务元数据 |
| `task_history` | 任务执行历史 |
| `audit_logs` | 审计日志 |
| `projects` | 工程元数据（可选） |
| `models` | 模型注册（可选） |
| `rule_*` | 工艺规则（可选） |

### 10.1.2 关键文件
| 文件 | 职责 |
|------|------|
| `connection.py` | SQLAlchemy 引擎 + 会话工厂 |
| `models.py` | ORM 模型 |
| `repository.py` | 仓储模式 |
| `constraints.py` | 数据约束（check / unique） |
| `rule_db.py` / `rule_models.py` | 规则专用 |
| `machines.py` / `materials.py` / `tools.py` | 静态数据表 |
| `data/*.json` | 初始化数据 |

### 10.1.3 迁移 (Alembic)
- 启动时自动执行 `alembic upgrade head`
- 失败抛错，阻止启动

## 10.2 Redis `app/services/redis_client.py`

### 10.2.1 用途
- 异步任务进度：`task_progress:{id}`
- 任务取消标志：`cancel:{id}`
- LLM 响应缓存（可选）
- 限流计数器（slowapi 后端）
- 会话/缓存

### 10.2.2 API
```python
from app.services.redis_client import get_redis
redis = await get_redis()
```

## 10.3 ChromaDB（向量存储） `app/rag/vector_store.py`

- 工艺知识库向量存储
- 文档导入后自动 Embedding
- 检索：`rag_retrieval.py` 语义搜索 + `reranker.py` 重排
- 评估：`evaluation.py` 检索质量度量

## 10.4 本地文件存储

| 路径 | 用途 |
|------|------|
| `data/projects/*.vrm` | 工程文件 |
| `data/models/*.pt` | 模型权重（PyTorch） |
| `data/rag/*` | RAG 知识库 |
| `logs/*.log` | 应用日志 |
| `logs/audit/audit_log.jsonl` | 审计日志 |
| `coverage-reports/` | 覆盖率报告 |
| `data/trace_log.jsonl` | 加工轨迹数据 |
| `.lnn_token` / `.lnn_token_meta.json` | LNN 令牌 |
| `.lnn_banned_tokens.json` | 撤销令牌 |

> 模型权重等大文件使用 **Git LFS** 管理（见 `.gitattributes`）。

## 10.5 静态配置

### 10.5.1 根目录 `config/`
- `postprocessor_config.yaml` — 后处理默认值
- `safety_rules.yaml` — 安全规则
- `data_pipeline.yaml` — 数据流水线

### 10.5.2 后端 `python/config/`
- `lnn_workflow.yaml` — LNN 工作流配置

### 10.5.3 数据库静态数据 `python/app/database/data/`
- `machines.json` — 机床库
- `tools.json` — 刀具库
- `materials.json` — 材料库
- `process_rules.json` — 工艺规则

### 10.5.4 共享数据 `python/app/data/`
- 同上，可作为兜底数据源

## 10.6 监控

### 10.6.1 Prometheus
- 路径：`/metrics`
- 内容：HTTP 计数、延迟直方图、活跃任务数等
- 抓取配置：`deploy/prometheus/prometheus.yml`
- 告警规则：`deploy/prometheus/alert_rules.yml`

### 10.6.2 告警规则
`deploy/prometheus/alert_rules.yml`：
- APIErrorRate（5xx 比例）
- LNNTrainingGPUUsage
- LNNInferenceLatency
- RedisDown / PostgresDown
- TaskQueueBacklog
- IdleAutoShutdownWarning

## 10.7 CI/CD `.github/workflows/`
