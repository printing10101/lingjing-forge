# 08. 安全与认证

## 8.1 统一鉴权 `app/auth/`

### 8.1.1 三令牌体系

| 令牌类型 | 来源 | 用途 | 验证器 |
|---------|------|------|--------|
| **LNN Flat Token** | 启动时生成（`.lnn_token` / `LNN_TOKEN` 环境变量） | 内部节点鉴权 + API 入口 | 文件读取 + 对比 |
| **JWT** | 用户登录后签发 | 用户态 API | HS256 + 过期校验 |
| **Agent Token** | 智能体签发 | 智能体间通信 | 独立密钥 + 短 TTL |

### 8.1.2 `unified_auth.py` 行为
`UnifiedAuthMiddleware` 是纯 ASGI 中间件：
1. 检查 `X-Request-ID`，缺失则生成
2. 公开路径短路：`/api/health`、`/api/v1/auth/login`、`/api/docs`、`/api/redoc`、`/api/openapi.json`、`/metrics`、SSE 任务流（可选）
3. 解析 Authorization Header：
   - `Bearer <jwt>` → 走 JWT 验证
   - `LNN <token>` / `Flat <token>` → 走 LNN 验证
   - `Agent <token>` → 走 Agent 验证
4. 写入 `request.state.user` / `request.state.agent`
5. 失败时返回 401/403，统一响应体

### 8.1.3 公开路径注册
```python
PUBLIC_PATHS = {
    "/api/health", "/api/v1/auth/login", "/api/v1/auth/register",
    "/api/docs", "/api/redoc", "/api/openapi.json",
    "/metrics", "/api/v1/jobs/*/stream",  # SSE 通常需要单独签发
}
```

## 8.4 CORS 安全门 `app/middleware/cors_config.py`

### 8.4.1 强制规则
| 规则 | 描述 |
|------|------|
| | `allow_origins=["*"]` + `allow_credentials=True` 同时存在 |
| | 显式白名单 + 显式 allowed_methods/headers |
| | 缺失配置时使用安全的 dev 默认（localhost） |

### 8.4.2 启动校验
```python
def enforce_startup_security():
    if not validate_cors_config(app.state.cors_config):
        logger.critical("CORS configuration failed security check")
        sys.exit(1)
```

## 8.5 安全头中间件 `app/auth/security_headers_asgi.py`

纯 ASGI，不缓冲请求体：
- `Content-Security-Policy`
- `Strict-Transport-Security` (生产)
- `X-Frame-Options: DENY`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy`

## 8.6 限流 `app/middleware/rate_limiter.py`

- 基于 `slowapi.Limiter`
- 默认：`100/minute` per IP
- 端点覆盖：
  ```python
  @router.post("/login")
  @limiter.limit("5/minute")
  def login(): ...
  ```
- 异常：429 Too Many Requests

## 8.8 空闲自动休眠 `app/sidecar/sidecar_lifecycle.py`

- `IdleAutoShutdownMiddleware` — BaseHTTPMiddleware
- 跟踪请求间隔，超过 30 min 触发：

  - 注册 atexit 处理器
  - 触发 `GracefulShutdownHandler.shutdown()`

## 8.10 令牌管理 `app/config.py:TokenConfig`

| 字段 | 含义 |
|------|------|
| `token` | 当前生效的 LNN Flat Token |
| `banned_tokens` | 撤销列表（写入 `.lnn_banned_tokens.json`） |
| `metadata_path` | 元数据（创建时间、来源等） |
| `history_path` | 轮换历史 |

### 8.10.1 优先级
1. `LNN_TOKEN` 环境变量（生产）
2. `.lnn_token` 文件
3. 启动时自动生成 UUID

### 8.10.2 轮换
- 命令：`POST /api/v1/auth/rotate-token`（需 admin）
- 旧 Token 写入 `banned_tokens`（保留 7 天）
