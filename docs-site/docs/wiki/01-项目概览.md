# 01. 项目概览

## 1.1 业务背景

灵境制造是一款面向制造行业的 **AI 驱动桌面工具**，核心解决机械加工里"图纸到 NC 代码"全流程效率低、门槛高、数据不安全的痛点。

### 核心卖点
| 维度 | 描述 |
|------|------|
| 输入 | 工程三视图（DXF）、三维模型（STEP） |
| 输出 | 可直接上机的 NC 代码（G 代码） |
| 数据流 | 图纸 → 3D 重建 → 工艺规划 → 后处理 → 仿真 |
| 隐私 | 全流程本地运行，**数据不出厂** |
| AI 能力 | 本地大模型 + 工艺知识图谱 + 数学规划求解器 |

### 面向用户
- **中小型制造企业** — 用工业级 AI 工具解决工艺规划难题
- **车间一线** — 落地可执行的高精度加工方案
- **工艺工程师** — 减负 + 经验沉淀

## 1.4 运行模式

项目提供 3 种运行形态：

### 1. Web 模式
```bash
# 终端 1：前端
pnpm dev                # http://localhost:1420

# 终端 2：后端
cd python && uvicorn app.main:app --reload --port 8765
```

### 2. 桌面模式（Tauri）
```bash
pnpm tauri dev          # 在启动 Web + API 之后
pnpm tauri build        # 生产构建
```

### 3. 容器化部署
```bash
docker compose --profile full up -d        # 完整服务栈（API + Redis + Postgres + 监控）
docker compose --profile api up -d         # 仅 API
docker compose --profile monitoring up -d  # 仅监控
```

## 1.5 安全设计

- **三令牌体系**：LNN Flat Token / JWT / Agent Token，三者在 `UnifiedAuthMiddleware` 中统一处理
- **CORS 严格校验**：启动时强制校验，配置错误则进程非零退出
- **安全头中间件**：CSP / HSTS / X-Frame-Options / X-Content-Type-Options
- **RBAC 权限模型**：`system:config` / `rule:edit` / `toolpath:edit` / `process:plan` / `user:manage`
- **API 限流**：slowapi 默认 100 req/min/IP，按端点可覆盖
- **审计日志**：所有用户决策、模型推理、关键操作记入 `audit_log.jsonl`
- **数据主权**：用户级数据隔离，端到端可追踪
