# v1.12.0 更新日志

**发布日期**: 2026-05-01

## 新功能

### 知识图谱增强
- **工艺知识本体建模**: 支持自定义工艺知识图谱结构
- **智能检索**: 基于语义的工艺知识检索功能
- **知识可视化**: 图谱关系可视化展示和交互探索
- **知识导入**: 支持从 Excel/CSV 批量导入工艺知识

### RAG 检索优化
- **文档解析增强**: 支持 PDF、Word、Markdown 多格式文档解析
- **向量检索优化**: 检索准确率提升 25%
- **重排序机制**: 引入 Cross-Encoder 重排序，提升相关性
- **上下文窗口**: 支持更长的上下文理解

### 用户体验改进
- **工艺卡片模板**: 提供标准化工艺卡片模板
- **批量操作**: 支持任务和项目的批量操作
- **快捷搜索**: 全局快捷搜索功能 (Ctrl+K)
- **主题切换**: 支持浅色/深色主题自动切换

## 改进
