# v1.11.0 更新日志

**发布日期**: 2026-04-15

## 新功能

### 多物理场仿真集成
- **切削力仿真模块**: 基于物理模型的切削力预测
- **颤振分析模块**: 加工稳定性分析和颤振预测
- **温度场仿真**: 加工区域温度分布预测
- **仿真结果可视化**: 3D 云图展示和动画播放

### 工艺规划增强
- **工序自动排程**: 基于约束的工序自动排序
- **资源冲突检测**: 自动检测设备和工具冲突
- **工艺路线优化**: 多目标工艺路线优化建议
- **工时估算**: 基于历史数据的加工时间预测

### 数据集成
- **OPC UA 客户端**: 完整的 OPC UA 协议支持
- **MTConnect 适配器**: 支持 MTConnect Agent 数据接入
- **数据转换器**: 多格式数据转换和标准化
- **实时数据监控**: 设备状态实时监控面板

- 优化仿真计算性能，速度提升 40%
- 改进网格划分算法
