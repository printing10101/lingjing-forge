# v2.6.0 更新日志

**发布日期**: 2026-07-16
**类型**: 架构重构版本（契约层建设）

> 摘要镜像自 `docs/变更摘要/变更摘要 V2.6.0.md`，完整细节以源文件为准。

## 概要

架构演进版本：聚焦**前后端契约层建设**、**共享模块抽取**（shared/）、**数据飞轮插件系统**与**论文实验脚本支持**。新增超过 300 个单元测试，建立工程与研究模块解耦的基础。

## 主要变更

### 共享契约层

- 新增 `shared/constants/`、`shared/data/`、`shared/lnn/`：材料参数、数据契约、LNN 类型定义统一
- 前端新增 **13 个契约定义**（`src/contracts/`：config/dataset/plugin/task/world_model 等），前后端接口类型安全得到保障

### 前端体系扩展

- 新增 **10 个 Pinia Store**（explainability、flywheel、rlAgent、worldModel 等）
- 新增 **6 个核心视图**（Explainability、RLAgent、SnapshotPanel、WorldModel 等）
- 新增组合式函数 `useExtensionRegistry` / `useSnapshots` / `useWorkflow`

### 数据飞轮插件系统

- 新增 `plugins/data_flywheel/`：反馈收集器、模型热更新管理器、模型迭代流水线模板
- 新增 CAM 软件适配器（NX / PowerMill / PyCAM），支持 G-code 自动验证

### 新增 API

- `POST /api/v1/cam-validation/validate-gcode`、`GET /api/v1/cam-validation/adapters`
- `POST /api/v1/flywheel/feedback`、`GET /api/v1/flywheel/metrics`、`POST /api/v1/flywheel/hot-update`
- `POST /api/v1/image-to-3d/reconstruct`、`GET /api/v1/image-to-3d/status/{task_id}`
- 新增 `scripts/check_response_model.py` 契约一致性检查脚本

### 测试与清理

- 前端新增 80+ 测试文件（API/组件/Store/视图/组合式函数），后端新增 50+（契约/插件/世界模型/集成）
- 清理 20+ 旧版集成测试、`scripts/i18n/`、`scripts/oneoff/`、`tools/` 冗余文档与 `uniwear-dataset-main/` 目录
