# v2.0.0 更新日志

**发布日期**: 2026-06-01

## 重大变更

### 自适应工艺孪生引擎 (APT)

#### 新增功能
- **贝叶斯 LNN 推理引擎**: 支持不确定性量化的工艺参数推荐
- **主动学习触发器**: 自动识别高不确定性区域并触发数据收集
- **自动重训练机制**: 模型性能下降时自动触发增量学习
- **PINN 物理约束**: 融合物理定律的神经网络训练

#### 性能优化
- 推理延迟降低 60%
- 模型训练时间缩短 45%
- 内存占用优化 30%

### 数字孪生仿真

#### 新增模块
- **切削力预测**: 基于 PINN 的实时切削力预测
- **颤振稳定性分析**: 振动稳定性边界预测
- **温度场仿真**: 加工区域温度分布预测
- **刀具磨损演化**: 刀具寿命预测和磨损轨迹模拟

### 工艺师协作界面

#### 透明决策机制
- 参数推荐可解释性展示
- 决策依据可视化
- 一键采纳/修改/拒绝操作

#### 经验沉淀
- 决策反馈自动收集
- 工艺知识图谱自动更新
- 专家经验结构化存储

## 迁移指南

### 从 v1.x 升级到 v2.0

1. **备份数据**
   ```bash
   python scripts/backup_database.py
   ```

2. **更新依赖**
   ```bash
   pip install -r requirements.txt --upgrade
   ```

3. **执行数据库迁移**
   ```bash
   alembic upgrade head
   ```

4. **更新配置文件**
   - 参考 `config/` 目录下的示例文件
   - 使用 `python scripts/migrate_config.py` 自动迁移

5. **验证升级**
   ```bash
   python scripts/verify_upgrade.py
   ```
