# v2.5.0 更新日志

**发布日期**: 2026-07-09
**类型**: 主版本（上线版基线）

## 概要

灵境制造平台上线版基线版本。本版本聚焦学术诚信修复、文档完整性与 docs-site 镜像同步，为 Journal of Intelligent Manufacturing 投稿提供可追溯的工程基线。

## 主要变更

### 学术诚信修复

- **模型命名统一**：全栈统一为 DL-LNN（Delay-embedded Liquid Neural Network），对应代码 `DLLNNModel` 类
- **LNN 定义修正**：ADR-001 中 LNN 由 "Logical Neural Network" 修正为 "Liquid Neural Network"（液态神经网络）
- **CFC 定义修正**：由 "Continuous Fluid Dynamics" 修正为 "Closed-form Continuous-time"
- **LTC 描述修正**：统一为 "Liquid Time-Constant" 网络

### 文档一致性

- 修复架构概述中 PostgreSQL 15 与 ADR-003 SQLite 选型的矛盾
- 统一 API 响应格式文档（数字 `0` 表示成功，与 `response.py` 实现一致）
- 修复 changelog 死链，补齐版本占位文件
- ADR 与代码实现、experiment_design.md 对齐

### 基础设施

- docs-site/docs/ 作为 VitePress 发布镜像与 docs/ 源目录同步
- 依赖与 CI 配置整理
