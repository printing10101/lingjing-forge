# v2.3.0 更新日志

**发布日期**: 2026-06-20
**类型**: 次版本

## 概要

本版本主要新增知识图谱抽取模块与 LLM Provider 注册表。

## 主要特性

- **知识图谱抽取**：聚焦材料（TC4/HRC52/6061-T6）、刀具参数、信号类型（振动/声发射/力）
- **LLM Provider 注册表**：支持 Ollama/LM Studio/llama.cpp/vLLM + 云端 API 多后端
