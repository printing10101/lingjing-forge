# v2.7.0 更新日志

**发布日期**: 2026-07-28
**类型**: 解耦重构版本（工程/研究物理隔离）

> 摘要镜像自 `docs/变更摘要/变更摘要 V2.7.0.md`，完整细节以源文件为准。

## 概要

里程碑式重构版本：完成**工程与研究模块的物理隔离**（`engineering/` + `research/` 顶层结构，2091 个文件变更），完善论文实验体系（24+ 条实验管线），系统性完成 P0-P3 代码质量修复与安全加固。工程运行侧改用 ONNX Runtime 消费训练好的模型，运行时不再依赖 torch（约 2GB → 50MB）。

## 主要变更

### 工程/研究物理解耦

- 前端代码（`src/`、`src-tauri/`）迁入 `engineering/`；后端（`python/app/`）迁入 `engineering/python/app/`
- 训练侧依赖（torch/torchdiffeq/mlflow/xgboost）迁至 `research/requirements.txt`
- API 端点路径不变，仅代码物理位置调整；分支收敛于 `refactor/decouple-research-engineering`（2026-08-19 并入 main）

### 论文实验体系（research/experiments/）

- 新增 24+ 条实验管线（LTC 收敛、基线对比、材料泛化、颤振抑制等），结果自动落盘、多格式输出

### 代码质量与安全

- 15 项系统性质量优化（P0-P3），含单例→DI 迁移、分层整理
- 139 处 `datetime.now()` 统一为 `datetime.now(timezone.utc)`
- 安全加固与工程输出管理规范化

### 测试覆盖

- 工程测试迁入 `engineering/python/tests/`（单元/集成/回归分层）；研究测试独立于 `research/tests/`
