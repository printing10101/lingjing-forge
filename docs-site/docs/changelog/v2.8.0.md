# v2.8.0 更新日志

## 概要

质量专项版本：以稳定性修复、重复代码收敛、仓库结构与内容治理为主线，不含新功能，对外接口（REST API 契约、前端交互）保持兼容。

## 主要变更

### 后端稳定性修复

- **全局异常中间件**：500 响应路径脱敏失效修复；环境判定改服务端 `ENVIRONMENT` 变量，不再信任客户端请求头
- **MTConnect 采集**：TDengine 持久化失败不再静默丢数据，失败批次回灌重试
- **成本预算 API**：20 个端点同步 SQLite 查询不再阻塞事件循环
- **实时监控 WS**：断连自动重探恢复真实数据源，演示数据显式标记 `source: "demo"`
- **LNN 预测器加载**：缓存未命中时加载从未真正生效的缺陷修复
- 其他：llama.cpp `/v1/v1/` 双前缀、SQLite 方言探测留痕、matplotlib figure 泄漏等

### 重复代码收敛

- `app/utils/task_store.py`：四份同构任务存储收敛为基类声明
- `app/ai/llm/providers/openai_compat_base.py`：五份本地 Provider 拷贝（约 630 行）收敛为 preset
- `app/utils/dict_utils.py` / `id.py` / `time.py`：通用工具三合一收敛

### 前端重构

- `composables/sseConnection.ts`：SSE 连接核心（竞态防护 + 指数退避），双份实现收敛为单一实现
- `composables/useEChart.ts`：ECharts 生命周期样板统一
- `utils/formatters.ts:formatDateTimeSafe`：时间格式化收敛

### 移除与治理

- 僵尸目录/文件：根 `src-tauri/` 陈旧副本、`skills/`（147 文件第三方拷贝）、失效脚本等
- 前端死代码：`features/` API 层（16 模块零消费）、未挂载组件及其测试
- 大型数据集 CSV 移出版本库（按原始来源获取）
