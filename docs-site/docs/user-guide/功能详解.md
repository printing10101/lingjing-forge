## 1. 工件导入

### 1.1 功能概述

工件导入模块负责解析工程图与三维模型文件，提取几何信息并生成可供后续工艺规划使用的内部表示。

### 1.2 使用场景

- 从 CAD 软件（SolidWorks、UG、Pro/E）导出 STEP 文件后导入
- 从客户提供 PDF 工程图中提取轮廓
- 从历史 DXF 文件中复刻加工

### 1.3 操作步骤

1. **入口**：项目主页 → **工件管理** 标签 → 右上角 **+ 导入工件** 按钮
2. **选择来源**：
   - `本地文件`（最常用）
   - `样例库`（系统内置示例）
   - `CAD 软件直连`（需安装对应插件）
3. **配置参数**：

| 界面元素 | 参数 | 说明 |
|----------|------|------|
| **单位制下拉框** | `毫米` / `英寸` | 必须与原始 CAD 建模单位一致 |
| **坐标系选择** | `自动检测` / `自定义` | 自动检测失败时手动指定 |
| **精度滑块** | `低 / 中 / 高 / 极高` | 影响解析时间与精度 |

4. **提交**：点击 **开始导入**

### 1.4 参数含义

- **单位制**：影响后续所有尺寸与公差的解析
- **坐标系**：决定工件在工作台上的位置，错误的坐标系会导致后续加工方向错误
- **精度**：影响特征识别准确率与解析时间

### 1.5 功能限制

- 单文件大小 ≤ 50 MB（STEP）
- 文件版本兼容：STEP AP203 / AP214 / AP242
- 曲面识别不支持 NURBS 高阶（> 5 阶）
- 二维图纸中倾斜角度 > 60° 的标注可能识别失败

## 2. 特征识别与标注

### 2.1 功能概述

基于 AI 模型与几何规则，自动识别工件上的加工特征（孔、槽、平面、轮廓等），并支持人工补全。

### 2.2 使用场景

- 自动识别加工特征，提高工艺规划效率
- 自动识别失败的复杂特征需要手动标注
- 补充自动识别遗漏的工艺特征（如螺纹、倒角、滚花）

### 2.3 操作步骤

1. **入口**：工件 → **特征清单** 标签
2. **查看识别结果**：左侧列表显示已识别特征
3. **手动标注**：
   - 点击 **+ 添加特征** 按钮
   - 在 3D 视图中**点击**选择几何元素
   - 在弹出对话框中选择特征类型（`孔` / `槽` / `平面` / `轮廓` ...）
   - 设置参数（如孔的直径、深度）
4. **编辑现有特征**：
   - 双击特征行打开编辑器
   - 修改参数后点击 **保存**

### 2.4 参数含义

- **特征类型**：决定后续可应用的加工策略
- **几何参数**（如孔的直径）：与刀具库联动验证
- **公差**：影响精加工参数选择

### 2.5 功能限制

- 特征类型覆盖：孔、矩形槽、轮廓、平面、倒角、圆角、螺纹孔、键槽（共 8 种）
- 不支持自由曲面识别（需要手动规划走刀路径）
- 复杂组合特征（如带岛屿的型腔）需要先拆分为基本特征

## 3. 工艺规划

### 3.1 功能概述

工艺规划模块基于识别特征、用户配置和 AI 推荐，生成完整加工工序路线（粗加工 → 半精加工 → 精加工 → 切槽 → 攻丝等）。

### 3.2 使用场景

- 新工件首次加工
- 工艺路线优化（缩短工时、降低成本）
- 跨机床/跨材料的工艺适配

### 3.3 操作步骤

1. **入口**：项目 → **工艺规划** 标签
2. **参数配置**：
   - 在 **参数** 子标签中配置粗加工/精加工参数
   - 切换到 **AI 推荐** 子标签，点击 **▶ 开始推理**
   - 选择一个推荐方案，点击 **采纳**
3. **工序调整**：
   - 拖拽工序调整顺序
   - 双击工序编辑详情
   - 右键工序可启用/禁用
4. **预览**：切换到 **预览** 子标签查看走刀路径

### 3.4 参数含义

| 参数 | 取值范围 | 影响 |
|------|----------|------|
| 切削深度 `ap` | 0.05 - 10.0 mm | 越大材料去除越快，但刀具负载越高 |
| 进给量 `f` | 0.01 - 1.0 mm/tooth | 越大加工越快，但表面粗糙度越差 |
| 切削速度 `Vc` | 10 - 500 m/min | 影响刀具寿命与加工温度 |
| 加工策略 | 等高线 / 平行 / 螺旋 / 摆线 | 决定走刀模式 |
| 加工余量 | 0.1 - 5.0 mm | 精加工前的剩余材料厚度 |

### 3.5 功能限制

- 最多支持 20 道工序（超出后系统性能下降）
- 单道工序最多 1000 个走刀段
- 不支持五轴联动规划（当前仅支持 3 轴）

## 4. LNN 推理引擎

### 4.1 功能概述

LNN（Liquid Neural Network，液态神经网络）推理引擎提供切削力预测、刀具磨损预测、刀具寿命估算等 AI 能力。

### 4.2 使用场景

- 新工件缺少经验数据时，给出初始推荐参数
- 优化现有工艺，降低刀具消耗
- 预测剩余刀具寿命

### 4.3 操作步骤

1. **入口**：工艺规划 → **AI 推荐** 子标签
2. **触发推理**：点击 **▶ 开始推理**
3. **查看结果**：
   - 多个推荐方案按置信度排序
   - 每个方案附带：
     - 切削参数推荐
     - 预计刀具寿命
     - 预计表面粗糙度
     - 置信度评分
4. **采纳或反馈**：
   - 点击 **采纳此方案** 填入参数
   - 点击 **标记为不满意** 提供反馈（系统会记录用于模型持续训练）

### 4.4 参数含义

- **模型名称**：可选 `cutting_force` / `wear_prediction` / `tool_life` 等
- **输入特征**：通常包括材料硬度、刀具直径、切削深度、进给量、切削速度
- **置信度评分**：0-1 之间的浮点数，> 0.7 视为高置信度

### 4.5 功能限制

- 模型预测范围：仅在训练数据覆盖的材料/参数范围内可靠
- 当前支持的材料：45 钢、6061 铝合金、黄铜 H62、不锈钢 304
- GPU 加速需要 CUDA 11.8+，否则自动回退到 CPU（速度慢 5-10 倍）
- 推理响应时间：单次 < 200ms（GPU）/ < 1s（CPU）

## 5. 刀具库管理

### 5.1 功能概述

管理企业中所有可用刀具的规格、库存、寿命记录，并支持与工艺规划联动。

### 5.2 使用场景

- 添加新采购的刀具
- 跟踪刀具使用次数与剩余寿命
- 工艺规划时自动选择可用刀具

### 5.3 操作步骤

1. **入口**：系统 → **刀具库**
2. **浏览刀具**：左侧树形结构按类型分类（立铣刀 / 球头铣刀 / 钻头 / 丝攻）
3. **添加刀具**：
   - 点击 **+ 添加刀具**
   - 填写规格参数（直径、刃长、材质、涂层）
   - 上传刀具图片（可选）
   - 点击 **保存**
4. **查看使用记录**：
   - 选中刀具 → 右侧 **使用记录** 标签
   - 显示该刀具的累计切削时间、加工件数

### 5.4 参数含义

| 参数 | 说明 |
|------|------|
| 直径 `D` | 影响最小加工特征尺寸限制 |
| 刃长 `L` | 影响最大加工深度 |
| 材质 | 高速钢（HSS）/ 硬质合金（Carbide）/ 涂层硬质合金 |
| 涂层 | TiN / TiAlN / AlCrN 等，影响高温性能 |
| 库存数量 | 用于"自动选刀"决策 |

### 5.5 功能限制

- 单个系统最多管理 10000 把刀具
- 不支持刀具全生命周期管理（如采购、报废流程）
- 刀具寿命数据需要通过 OPC UA / MTConnect 集成获取（详见 [API 文档 - 数据采集 API](../api/README.md)）

## 6. 刀轨仿真

### 6.1 功能概述

基于 Rust 引擎的体素级切削仿真，提前发现碰撞、过切、欠切等问题。

### 6.2 使用场景

- 工艺路线确认前的最终验证
- 新材料/新刀具的工艺试切
- 复杂五面加工的碰撞检查

### 6.3 操作步骤

1. **入口**：工艺规划 → **▶ 仿真** 按钮
2. **选择精度**：
   - `快速 (1×)`：30 秒内完成，适合早期验证
   - `标准 (4×)`：2 分钟内完成，平衡精度与速度
   - `精细 (16×)`：5 分钟内完成，适合最终验证
3. **查看结果**：
   - **切削余量云图**：颜色越红代表剩余材料越多
   - **碰撞报告**：列出所有碰撞点
   - **过切报告**：列出所有过切区域
4. **处理问题**：根据报告调整工艺或刀具，重复仿真

### 6.4 参数含义

- **精度等级**：体素分辨率（1× = 1mm，4× = 0.5mm，16× = 0.25mm）
- **毛坯定义**：包围盒大小 + 初始位置
- **碰撞阈值**：刀具与工件/夹具的最小安全距离（默认 2mm）

### 6.5 功能限制

- 单次仿真最大支持 100 万个体素
- 不支持五轴仿真（仅 3 轴）
- 仿真不验证后处理输出格式

## 7. 后处理

### 7.1 功能概述

将内部刀轨数据转换为目标数控系统可识别的 NC 代码（Fanuc、Siemens、Heidenhain 等）。

### 7.2 使用场景

- 数控代码生成
- 跨机床代码转换（如 Fanuc 代码转 Siemens）
- 自定义后处理模板

### 7.3 操作步骤

1. **入口**：工艺规划 → **后处理** 标签
2. **选择后处理器**：
   - 系统预设：`Fanuc 0i-MF` / `Siemens 840D sl` / `Heidenhain TNC 640`
   - 自定义：从下拉框选择用户上传的 `.py` 后处理脚本
3. **配置参数**：
   - **行号格式**：`N0001` / `N1` / `无`
   - **小数位数**：`0` / `1` / `2` / `3` / `4`
   - **换刀格式**：`T## M06` / `T## M06\nG43 H##` 等
4. **生成代码**：点击 **生成 NC 代码**

### 7.4 参数含义

- **行号格式**：影响代码可读性，部分旧机床有字符数限制
- **小数位数**：影响精度，机床精度不足时多余位数无意义
- **换刀格式**：必须与目标机床说明书一致

### 7.5 功能限制

- 内置后处理器仅覆盖主流系统，自定义控制器需编写 Python 脚本
- 单文件最大 5MB（约对应 100 万行 NC 代码）
- 不支持带 PLC 逻辑的复合指令（如西门子 `CYCLE` 系列高级语法）

## 8. 项目归档与协作

### 8.1 功能概述

提供项目版本控制、团队协作与历史追溯能力。

### 8.2 使用场景

- 多人协作开发同一项目
- 历史工艺追溯
- 工艺复用与改进

### 8.3 操作步骤

1. **入口**：项目 → **归档** 标签
2. **创建快照**：点击 **+ 创建快照**，填写说明（如 "粗加工参数优化"）
3. **查看历史**：左侧时间线显示所有快照
4. **差异对比**：选中两个快照，点击 **对比** 查看参数变化
5. **回滚**：选中历史快照，点击 **恢复到此版本**

### 8.4 参数含义

- **快照说明**：用于记录此次归档的变更原因，必填
- **包含文件**：默认包含所有工件、工艺、NC 代码
- **可见性**：`私有`（仅自己）/ `团队`（同部门）/ `公开`（全公司）

### 8.5 功能限制

- 单项目最多保留 1000 个快照
- 单快照最大 500 MB
- 不支持分支（branch）模型

## 9. 用户主权

### 9.1 功能概述

提供用户对自身数据的完全控制权，包括数据导出、数据删除、权限审计等。

### 9.2 使用场景

- 用户离职时数据迁移
- GDPR / 个保法合规要求
- 数据所有权确认

### 9.3 操作步骤

1. **入口**：右上角头像 → **我的** → **数据主权**
2. **导出数据**：
   - 选择导出范围（"我的项目" / "我的活动日志" / "我的模型"）
   - 选择导出格式（`JSON` / `CSV` / `ZIP`）
   - 点击 **生成导出包**（生成链接有效期 24 小时）
3. **删除数据**：
   - 选择要删除的内容
   - 二次确认（输入"确认删除"）
   - 数据立即清除（不可恢复）

### 9.4 参数含义

- **导出范围**：按用户维度筛选
- **导出格式**：影响后续处理难度
- **保留期限**：导出链接有效期

### 9.5 功能限制

- 单次导出最大 2GB
- 删除操作不可撤销（需提前备份）
- 团队协作数据删除会影响其他成员（系统会先发通知）

## 10. 智能体（Agent）

### 10.1 功能概述

基于 LLM 的智能体，可执行自动化工作流（如"为 6061 铝件生成粗加工参数"）。

### 10.2 使用场景

- 重复性工艺参数生成
- 跨项目的批量操作
- 工艺知识库问答

### 10.3 操作步骤

1. **入口**：左侧导航 → **智能体**
2. **选择模板**：
   - 内置模板：`粗加工规划` / `精加工优化` / `工艺问答`
   - 自定义模板：用户上传
3. **配置输入**：根据模板提示填写（如材料、工件描述）
4. **运行**：点击 **▶ 运行**，系统返回结果
5. **人工审核**：在结果页面点击 **采纳** 或 **驳回**

### 10.4 参数含义

- **模型选择**：`Qwen2.5-7B`（默认）/ `Llama-3.1-8B` / 自定义
- **温度（Temperature）**：0-1，越高越发散
- **最大 Token 数**：限制单次响应长度

### 10.5 功能限制

- 每个用户最多同时运行 3 个 Agent 任务
- 单次任务最长 5 分钟
- Agent 不可执行破坏性操作（删除/修改）除非有特殊授权

## 11. 模板市场

### 11.1 功能概述

提供企业内工艺模板的共享与下载，支持模板评分、评论、版本管理。

### 11.2 使用场景

- 复用成熟工艺模板
- 跨项目、跨团队推广最佳实践
- 工艺知识沉淀

### 11.3 操作步骤

1. **入口**：左侧导航 → **模板市场**
2. **浏览模板**：
   - 按类别筛选：`车削` / `铣削` / `钻孔` / `电火花` / `线切割`
   - 按评分排序
3. **下载模板**：
   - 选中模板 → **详情** → **下载到我的项目**
4. **上传模板**：
   - 我的项目 → **▶ 上传到市场**
   - 填写模板信息、截图、说明
   - 设置可见性（`部门内` / `公司内` / `公开`）

### 11.4 参数含义

- **模板评分**：1-5 星，影响搜索排名
- **下载次数**：反映模板受欢迎程度
- **版本号**：遵循语义化版本（如 1.2.0）

### 11.5 功能限制

- 单个模板最大 50 MB
- 模板更新需保留所有历史版本
- 公开模板需经过审核（通常 1-3 个工作日）

## 12. 监控与可观测性

### 12.1 功能概述

提供系统健康度、性能指标、审计日志的实时查看能力。

### 12.2 使用场景

- 运维人员日常巡检
- 故障排查
- 性能瓶颈分析

### 12.3 操作步骤

1. **入口**：系统 → **监控**
2. **查看健康度**：
   - 实时仪表盘显示 CPU、内存、磁盘、网络
   - 模型推理 QPS 与延迟
3. **查看日志**：
   - 切换到 **日志** 标签
   - 按级别（INFO / WARNING / ERROR）筛选
   - 按关键字搜索
4. **告警配置**：
   - 切换到 **告警规则** 标签
   - 点击 **+ 新增规则**
   - 配置触发条件与通知方式（邮件 / 钉钉 / 企业微信）

### 12.4 参数含义

- **采样间隔**：5s / 30s / 1min
- **告警阈值**：例如 CPU > 80% 持续 5 分钟触发
- **告警通道**：邮件、钉钉、企业微信、Webhook

### 12.5 功能限制

- 历史数据保留 90 天（更长周期需配置外部存储）
- 不支持自定义仪表盘（仅提供预设视图）
- 告警规则最多 100 条
