## 2. 模块划分说明

### 2.1 用户交互层

| 形态 | 入口 | 用途 |
|------|------|------|
| Tauri 桌面 | `src-tauri/src/main.rs` | 离线车间、单机部署 |
| Web 浏览器 | `src/main.ts` | 协同、远程访问 |
| CLI | `python/cli.py` | 批处理、自动化产线 |
| 前端组件测试 | `tests/*.spec.ts` | Vitest 回归测试 |

### 2.2 API 网关层

**中间件管道**（按执行顺序）：

1. **RequestIdMiddleware** — 注入/透传 `X-Request-Id`
2. **SecurityHeadersMiddleware** — CSP、HSTS、X-Frame-Options
3. **CORSMiddleware** — 跨域白名单
4. **MetricsMiddleware** — Prometheus 指标埋点
5. **UnifiedAuthMiddleware** — 三因素认证（LNN Token + JWT + Agent Token）
6. **RateLimiterMiddleware** — 滑动窗口限流

**路由模块**（`python/app/api/v1/`）：

| 路由 | 前缀 | 主要功能 |

## 3. 核心交互流程

### 3.1 DXF → NC 代码（端到端）

```
                  ┌──────────────┐
                  │   DXF 文件   │
                  └──────┬───────┘
                         ▼
            ┌────────────────────────┐
            │ DxfParser              │   ← 几何实体 + 尺寸标注
            └────────────┬───────────┘
                         ▼
            ┌────────────────────────┐
            │ FeatureExtractor       │   ← 孔/槽/型腔等加工特征
            └────────────┬───────────┘
                         ▼
            ┌────────────────────────┐
            │ DxfToModelConverter    │   ← CadQuery 3D 实体
            └────────────┬───────────┘
                         ▼
            ┌────────────────────────┐
            │ ProcessPlanningPipeline│   ← 工序 + 刀轨 + 切削参数
            └────────────┬───────────┘
                         ▼
            ┌────────────────────────┐
            │ Postprocessor          │   ← Fanuc/Siemens/Heidenhain G 代码
            │ (BasePostProcessor)    │
            └────────────┬───────────┘
                         ▼
            ┌────────────────────────┐
            │ Simulation             │   ← 碰撞检测 + 验证
            └────────────┬───────────┘
                         ▼
                  ┌──────────────┐
                  │   NC 文件    │   → 直接上机
                  └──────────────┘
```

整条流水线由 `app/dxf/pipeline.py` 中的 `DxfPipeline` 编排。

### 3.2 异步任务 + SSE 进度推送

```
客户端                       FastAPI                    JobManager               Worker
  │                            │                            │                       │
  │ POST /jobs                 │                            │                       │
  │ ─────────────────────────► │ enqueue()                  │                       │
  │                            │ ─────────────────────────► │ push to Redis          │
  │ 202 + job_id               │ ◄───────────────────────── │                       │
  │ ◄───────────────────────── │                            │                       │
  │                            │                            │                       │
  │ GET /jobs/{id}/events      │                            │                       │
  │ (SSE)                      │                            │                       │
  │ ─────────────────────────► │ subscribe(job_id)          │                       │
  │                            │ ─────────────────────────► │ pub/sub                │
  │                            │                            │ ◄──── run pipeline    │
  │ data: {progress: 0.1}      │ ◄───────────────────────── │ publish progress      │
  │ ◄───────────────────────── │                            │                       │
  │ data: {progress: 0.5}      │ ◄───────────────────────── │                       │
  │ ◄───────────────────────── │                            │                       │
  │ data: {result: {...}}      │ ◄───────────────────────── │ finish                │
  │ ◄───────────────────────── │                            │                       │
```

### 3.3 LNN 推理调用链

```
Client → POST /api/v1/lnn/infer
        ↓
   UnifiedAuthMiddleware（验证 LNN Token / JWT / Agent Token）
        ↓
   RateLimiterMiddleware
        ↓
   lnn_router.infer()
        ↓
   LNNEngine.load_or_get(model_id)   ← 缓存命中则秒级返回
        ↓
   ModelSelector（CFC / LTC / Hybrid）按任务类型选模型
        ↓
   preprocess(input) → tensor
        ↓
   infer(tensor) → raw_output
        ↓
   postprocess(raw_output) → typed_result
        ↓
   FusionEngine.merge([rule_result, ml_result])  ← Dempster-Shafer
        ↓
   返回 {prediction, confidence, provenance, audit_id}
```

### 3.4 智能体网关（Agent Gateway）

```
用户 → AgentGateway.chat(messages)
        ↓
   IntentClassifier（规则 + LLM 双通道）
        ↓
   SkillRouter.route(intent) → [Skill1, Skill2, ...]
        ↓
   并行调用各 Skill（带超时与降级）
        ↓
   GoalAlignmentChecker 校验输出是否对齐用户目标
        ↓
   CostBudgetGuard 校验 token/算力成本
        ↓
   汇总 → 用户
```

## 4. 技术栈选型理由

| 选型 | 理由 |
|------|------|
| FastAPI | 异步原生、OpenAPI 自动生成、Pydantic 校验 |
| Vue 3 + TS | Composition API、类型安全、Vite 启动毫秒级 |
| Tauri | 包体小（≤10MB）、Rust 内核安全、与 Web 生态无缝衔接 |
| LNN（ncps） | 时序建模优势、低延迟（CFC ≤100ms）、可解释性 |
| Dempster-Shafer | 规则 + ML 冲突下的不确定性量化 |
| PostgreSQL | 事务、JSONB、全文检索一站式 |
| Redis | 高速 pub/sub 用于 SSE、限流、缓存 |
| ChromaDB | 轻量级向量库，支持本地部署 |
| Prometheus | 指标模型成熟，Alertmanager 联动 |
| K8s | 多副本、HPA、滚动升级 |
| GitHub Actions | 与仓库同源、Matrix 矩阵测试 |
| Sigstore/Cosign | 镜像签名、供应链完整性 |

## 5. 设计原则

1. **用户主权**：所有可逆操作（生成内容、技能调用）必须支持撤销与审计。
2. **离线优先**：核心功能（DXF→NC）在无网络下可用；联网仅用于知识更新。
3. **可解释性**：LNN/规则融合推理结果必须带 `provenance` 字段，标识来源。
4. **插件化**：刀轨编辑器、模板演化、规则编辑器均走插件总线，新增功能不改主框架。
5. **渐进增强**：Web 优先，Tauri 打包时附加离线缓存与硬件加速。
6. **最小特权**：RBAC + 用户主权 + 三因素认证（人、机器、技能）。

## 6. 部署形态

| 形态 | 适用场景 | 入口 |
|------|----------|------|
| 桌面单机 | 车间工位 | Tauri 安装包 |
| 本地服务器 | 中小企业 | docker-compose |
| 集群高可用 | 大型工厂 | K8s + Helm |
| 私有云 | 集团客户 | Terraform + K8s |

## 7. 性能基准

| 指标 | 目标值 | 实测值（v2.0.0） |
|------|--------|-------------------|
| DXF 解析 P95 | ≤ 3 s | 2.1 s |
| 工艺规划 P95 | ≤ 8 s | 6.4 s |
| LNN CFC 推理 P95 | ≤ 100 ms | 78 ms |
| LNN Hybrid 推理 P95 | ≤ 500 ms | 420 ms |
| 单工程并发编辑 | 50 用户 | 80 用户（压测） |
| SSE 推送延迟 | ≤ 200 ms | 110 ms |
