# 开发环境搭建

> 本文档面向**新进开发者、贡献者**，提供完整的本地开发环境搭建指南。
> 适用版本：v2.5.0
> 预计完成时间：30–60 分钟

## 1. 系统要求

### 1.1 操作系统

| OS | 版本 | 备注 |
|----|------|------|
| Windows | 10/11（21H2+） | 推荐主力开发机，附 WSL2（可选） |
| macOS | 12 Monterey+ | Apple Silicon 原生支持 |
| Ubuntu | 22.04 LTS | 服务器与 CI 主流 |
| Debian | 11+ | 兼容 Ubuntu 配置 |

### 1.2 硬件最低配置

| 资源 | 最低 | 推荐 |
|------|------|------|
| CPU | 4 核 | 8 核（带 AVX2） |
| 内存 | 8 GB | 16 GB（跑 LNN 模型 ≥ 32 GB） |
| 硬盘 | 20 GB SSD | 50 GB SSD |
| GPU | 可选 | NVIDIA（CUDA 11.8+）用于 LNN 加速 |

### 1.3 软件依赖与版本

| 工具 | 版本 | 安装方式 |
|------|------|----------|
| Python | 3.11.x | pyenv / 官网 / conda |
| Node.js | 20.x LTS | nvm / 官网 |
| pnpm | 9.x | `npm i -g pnpm` |
| Rust | 1.78+ | rustup |
| Docker | 24+ | Docker Desktop |
| Git | 2.40+ | 系统包管理器 |
| Git LFS | 3.4+ | [git-lfs.github.com](https://git-lfs.github.com) |
| Ollama（可选） | 0.5+ | 用于本地 LLM |

> **重要**：本项目使用 **pnpm**，请勿混用 npm/yarn。

## 2. 一次性准备

### 2.1 克隆仓库

```bash
git clone <repository-url> lingjing-manufacturing
cd lingjing-manufacturing
git lfs install
git lfs pull
```

### 2.2 配置 Git

```bash
git config user.name "Your Name"
git config user.email "your.email@example.com"
git config core.autocrlf false  # 跨平台换行符
git config pull.rebase true
```

## 3. 后端环境

### 3.1 创建虚拟环境

```bash
cd python
python -m venv .venv

# 激活
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate
```

### 3.2 安装依赖

```bash
# 升级 pip
python -m pip install -U pip setuptools wheel

# 安装项目（含 dev/test 依赖）
pip install -e ".[dev,test]"

# 或仅装核心
pip install -e .
```

> 国内网络可使用镜像：
> ```bash
> pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 3.3 预提交钩子（可选）

```bash
pip install pre-commit
pre-commit install
```

预提交钩子会自动执行：ruff、black、mypy、ESLint、Prettier。

### 3.4 启动依赖服务

#### 选项 A：本地安装（推荐性能）

| 服务 | 安装 | 启动 |
|------|------|------|
| PostgreSQL 15 | brew / apt / 官网 | `pg_ctl start` |
| Redis 7 | brew / apt / 官网 | `redis-server` |

创建数据库：

```sql
CREATE DATABASE lingjing;
CREATE USER lingjing WITH PASSWORD 'lingjing_dev';
GRANT ALL PRIVILEGES ON DATABASE lingjing TO lingjing;
```

#### 选项 B：Docker（最简）

```bash
docker compose up -d postgres redis chromadb
```

### 3.5 环境变量

复制模板并按需修改：

```bash
cp .env.example .env
```

关键变量：

| 变量 | 默认 | 说明 |
|------|------|------|
| `LNN_DB_URL` | `postgresql+asyncpg://lingjing:lingjing_dev@localhost:5432/lingjing` | 数据库连接 |
| `LNN_REDIS_URL` | `redis://localhost:6379/0` | Redis 连接 |
| `LNN_ENV` | `development` | 环境标识 |
| `LNN_LOG_LEVEL` | `INFO` | 日志级别 |
| `LNN_TOKEN_SECRET` | `change-me` | JWT 签名密钥（生产必须改） |
| `LNN_OLLAMA_HOST` | `http://localhost:11434` | Ollama 地址 |

### 3.6 数据库迁移

```bash
alembic upgrade head
# 初始化种子数据
python -m app.scripts.seed_dev
```

### 3.7 启动后端

```bash
# 开发模式（热重载）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8765

# 带 SSE 调试
uvicorn app.main:app --reload --log-level debug
```

访问验证：

- Swagger UI：http://localhost:8765/api/docs
- ReDoc：http://localhost:8765/api/redoc
- OpenAPI JSON：http://localhost:8765/api/openapi.json
- 健康检查：http://localhost:8765/api/v1/heartbeat

## 4. 前端环境

### 4.1 安装 Node 与 pnpm

```bash
# macOS / Linux
curl -fsSL https://get.pnpm.io/install.sh | sh -

# Windows (PowerShell)
iwr https://get.pnpm.io/install.ps1 -useb | iex
```

### 4.2 安装依赖

```bash
cd ..
pnpm install
```

### 4.3 启动开发服务器

```bash

# 默认 http://localhost:5173
```

## 9. 常见问题

### 9.1 pip 安装失败

**症状**：`pip install -e .` 报 SSL / 网络错误。

**解决**：

```bash
# 临时切换镜像
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -e ".[dev,test]"

# 或使用 pip.conf 持久化
mkdir -p ~/.pip
cat > ~/.pip/pip.conf <<'EOF'
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
EOF
```

### 9.2 数据库连接失败

**症状**：`asyncpg.exceptions.InvalidPasswordError` 或 `Connection refused`。

**排查**：

```bash
# 检查端口
nc -zv localhost 5432     # macOS/Linux
Test-NetConnection localhost -Port 5432   # PowerShell
```

**解决**：

1. 确认 `.env` 中 `LNN_DB_URL` 与实际一致。
2. PostgreSQL 是否监听 `localhost` 而非仅 `unix socket`。
3. `pg_hba.conf` 中 `host all all 127.0.0.1/32 md5` 是否启用。

### 9.3 前端启动白屏

**症状**：`pnpm dev` 启动后页面空白，控制台报 `Failed to load module script`。

**解决**：

```bash
# 清理并重装
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### 9.4 Tauri 启动报错

**症状**：`pnpm tauri dev` 报 `tauri-cli` 未找到。

**解决**：

```bash
cargo install tauri-cli --version "^1.6"
# 或
pnpm add -D @tauri-apps/cli
```

### 9.5 LNN 模型加载慢

**症状**：首次调用 `/lnn/infer` 耗时 > 10s。

**原因**：模型从远端仓库下载。

**解决**：

```bash
# 预下载并放入 LNN 缓存目录
python -m app.lnn.scripts.download_models --all

# 或离线拷贝：把别人机器的 ~/.cache/lnn/* 拷贝到本机
```

### 9.6 Windows 长路径问题

**症状**：`OSError: [Errno 2] No such file or directory`，路径过长。

**解决**：

1. 组策略：计算机配置 → 管理模板 → 系统 → 文件系统 → 启用 Win32 长路径。
2. 或在仓库根目录用 `subst W: .` 创建虚拟盘符。

### 9.7 端口被占用

**症状**：`[Errno 48] Address already in use`（8765 / 5173 / 6379）。

**解决**：

```bash
# macOS / Linux
lsof -i :8765 | tail -n +2 | awk '{print $2}' | xargs kill -9

# Windows PowerShell
Get-NetTCPConnection -LocalPort 8765 | Select-Object OwningProcess
Stop-Process -Id <PID> -Force
```

### 9.8 跨平台换行符冲突

**症状**：Git 提示整个文件被修改。

**解决**：

```bash
git config core.autocrlf false
git rm --cached -r .
git reset --hard HEAD
```
