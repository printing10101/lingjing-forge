本清单是验收步骤；勾选项不是当前通过声明。独立测试环境中的模拟批准不能作为真实工艺批准。

## 审核前资料核对

- [ ] 原文 SHA256 与 `dormer-source-manifest.json` 一致，共 40 页。
- [ ] 对照 `dormer-review-packet.json` 的六项来源事实逐页核对，不把校验值一致理解为事实必然正确。
- [ ] 第4页：核对材料组、硬度、字母进给代码及最近直径选表规则。
- [ ] 第5页：核对 R10A 列、速度代码和 4×D 标识。
- [ ] 第6/7页：核对 NAS907 Type A、HSS、118°、5/16 inch 和目录号 010120。
- [ ] 补齐数字速度代码的明确单位出处；缺失时保持 `cutting_speed_unit` 未解决，不计算转速。
- [ ] 记录实际材料牌号、热处理状态和硬度，说明为何属于所选材料组；不以名称相似自动替代。
- [ ] 确认现场刀具、目标孔径与孔深、冷却、夹持、机床约束；4×D 图标不能代替现场确认。

## 系统闭环验收

| 编号 | 操作 | 预期结果 | 需要保留的证据 |
|---|---|---|---|
| A01 | 查询原待审记录和正式推荐 | pending；正式推荐不引用该记录 | 状态、记录标识、版本、推荐结果 |
| A02 | 原提交标识与原内容再次提交 | 不新增，返回当前版本 | created=false；前后记录数量 |
| A03 | 同提交标识改变参数后重试 | 冲突，原记录不变 | 409；原参数和版本 |
| A04 | 工艺人员在审核页面补充资料 | 修订后保持 pending；版本增加；保留旧内容 | 修订前后内容及审核历史 |
| A05 | 未解决事项非空时尝试批准 | 拒绝，不能产生有效批准 | 错误说明；状态保持不变 |
| A06 | 工艺人员解决疑点并批准 | 服务器记录真实审核人、来源和版本 | 已批准记录及证据；不能使用测试身份 |
| A07 | Nexent 重新查询状态和推荐 | 仅批准当前版本可被引用；标识和版本一致 | 工具调用记录与推荐引用 |
| A08 | 只修改已批准内容再推荐 | 回到待审，原批准失效 | 版本变化、旧摘要和空推荐 |
| A09 | 对已批准内容撤销后再推荐 | 撤销记录不再被引用，重启后也不恢复 | 撤销历史、重启前后结果 |
| A10 | 另一 Agent 查询该候选 | 无权读取，返回404 | 脱敏响应；不记录令牌 |
| A11 | 用户只提出业务请求，由模型自主执行 | 模型自行选择 Skill；待审时停止并提示人工审核 | 完整模型工具轨迹；手动工具验证不替代本项 |
| A12 | 用不符硬度、孔深、刀具的现场条件询问 | 不得声称已验证适用 | 输入条件和系统答复；若缺少自动条件匹配，记为待整改 |

## 当前边界
