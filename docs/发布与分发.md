# 发布与分发

> 版本：v2.7.0 | 更新日期：2026-08-03
> 本文档说明灵境制造的发布产物、分发渠道与国内可访问镜像方案。
> 与 [安装指南](./user-guide/安装指南.md)、[国内部署指南](./国内部署指南.md) 配套阅读。

## 1. 分发架构总览

灵境制造采用**双主路分发**，覆盖不同网络与部署场景：

| 主路 | 产物 | 目标用户 | 分发渠道 |
|------|------|----------|----------|
| **桌面安装包** | `灵境制造-setup-<版本>.exe` / `.msi` | Windows 单机用户 | GitHub Releases + 国内镜像 |
| **容器镜像** | 本地 `docker compose --build` 产物 / 发布到镜像仓库 | 服务器 / 生产环境 | GitHub Packages(ghcr.io) + 国内镜像仓库 |

> 服务端一键脚本（`deploy/install.sh`）从源码仓库直接拉取并构建，**不依赖**任何预发布的二进制或镜像仓库，是第三种轻量分发方式（见安装指南第 4 节）。

## 2. 桌面安装包（GitHub Releases）

### 2.1 产物命名

- NSIS 安装包：`灵境制造-setup-<版本>.exe`（如 `灵境制造-setup-2.7.0.exe`）
- Windows Installer：`灵境制造-<版本>.msi`

发布页：[GitHub Releases](https://github.com/printing10101/Virtual-Realm-Manufacturing/releases)

### 2.2 完整性校验

桌面端安装包的 SHA-256 在 GitHub Release 页面的 Release Notes 中随包公布。当前发布流程**未提供** GPG 签名，请以 Release 页公布的 SHA-256 作为完整性依据。

## 3. 容器镜像

### 3.1 本地构建（默认）

镜像通过仓库根目录 `Dockerfile` 构建，生产编排使用 `docker-compose.yml`（完整版）或 `docker-compose-sqlite.yml`（轻量版）：

```bash
docker compose -f docker-compose.yml --profile full up -d --build
```

基础镜像（通过 `IMAGE_REGISTRY` 环境变量切换国内源）：

- `python:3.12-slim`（应用运行时，由 `Dockerfile` 使用）
- `redis:7.4.2-alpine`、`postgres:15.10-alpine`、`tdengine/tdengine:3.0.7.5`
- `prom/prometheus`、`grafana/grafana`、`nginx`

默认 `IMAGE_REGISTRY=docker.io`；国内用户设为 `swr.cn-north-4.myhuaweicloud.com`（华为云 SWR）或 `registry.cn-hangzhou.aliyuncs.com`（阿里云 ACR）。

### 3.2 发布到镜像仓库（可选）

将构建好的镜像推送到以下仓库以便内网/集群拉取：

| 仓库 | 地址示例 |
|------|----------|
| GitHub Packages | `ghcr.io/printing10101/virtual-realm-manufacturing:<版本>` |
| 华为云 SWR | `swr.cn-north-4.myhuaweicloud.com/<组织>/lingjing:<版本>` |
| 阿里云 ACR | `registry.cn-hangzhou.aliyuncs.com/<命名空间>/lingjing:<版本>` |

> 注意：私有镜像需配置对应仓库的鉴权（`docker login`）。生产部署时请将 `IMAGE_REGISTRY` 指向你的私有仓库地址。

## 4. 国内可访问镜像方案

针对中国大陆网络环境，提供以下加速 / 镜像渠道：

### 4.1 一键脚本加速

`install.sh` 通过 GitHub 原始地址分发，国内可用 ghproxy 代理：

```bash
# 原始地址（境外可直连）
curl -fsSL https://raw.githubusercontent.com/printing10101/Virtual-Realm-Manufacturing/main/deploy/install.sh | bash

# 国内代理（ghproxy）
curl -fsSL https://ghproxy.com/https://raw.githubusercontent.com/printing10101/Virtual-Realm-Manufacturing/main/deploy/install.sh | bash -s -- --cn
```

`--cn` 参数同时启用阿里云 PyPI 镜像（`mirrors.aliyun.com`）加速 Python 依赖安装。

### 4.2 Gitee 镜像仓库

将 GitHub 仓库镜像到 Gitee，供 `git clone` 国内加速：

```bash
git clone https://gitee.com/<镜像组织>/Virtual-Realm-Manufacturing.git
```

> 镜像仓库需手动或定时同步；以 GitHub 官方仓库为唯一事实来源。

### 4.3 对象存储托管（COS / OSS）

将桌面安装包与离线包（`deploy/offline/lingjing_offline_package.tar.gz`）上传至腾讯云 COS 或阿里云 OSS，通过 CDN 分发，适合内网批量部署与官网下载页对接。

### 4.4 官方域名状态

早期规划的 `get.lingjing-mfg.com` / `mirrors.lingjing-mfg.com` 下载域名**建设中（尚未启用）**。在官方域名就绪前，请以本文档列出的 GitHub 原始地址、ghproxy 代理与 GitHub Releases 为准。

## 5. 版本号管理

- 唯一版本源：仓库根目录 `VERSION` 文件（当前 `2.7.0`）。
- 运行时版本由 `engineering/python/app/version.py` 读取 `VERSION` 文件提供，健康端点 `/api/health` 会返回该版本号。
- 桌面安装包、容器镜像标签、`docs/` 文档中的版本号均以 `VERSION` 为准，发布前请统一校对。
- 已知历史偏差：旧文档曾使用 `v2.5.0` 与不可达域名，已于 v2.7.0 文档修订中纠正（见安装指南附录）。
