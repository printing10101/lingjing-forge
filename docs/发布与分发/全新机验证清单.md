# 全新机验证清单（安装包 Go/No-Go 第 2 项）

> 目的：在**未安装任何开发工具**的干净 Windows 机器上，验证桌面安装包可以
> 装上并跑通「图纸 → 3D → 工艺 → NC」全流程。这是对外交付的硬门槛——
> 本机（有开发环境）验证通过不代表客户机器能装上。
> 适用版本：v2.8.0 及以后（首次执行：2026-09 批次完成后）。

---

## 0. 准备

- [ ] 一台**全新/重置**的 Windows 10/11 机器或干净虚拟机（无 Node/Rust/Python 开发环境）
- [ ] 待验证的安装包（`engineering/src-tauri/target/release/bundle/` 下 `.msi`/`.exe`）
- [ ] 测试素材：样例 DXF、样例 STEP、样例图片（各 1 份，放 U 盘/网盘）
- [ ] 记录表（本文件勾选 + 异常截图）

## 1. 安装与首启

- [ ] 安装包双击安装成功，无缺失 DLL / VC++ 运行库报错（如有报错即 No-Go，记录弹窗截图）
- [ ] 首次启动出现 Splashscreen，主窗口正常出现
- [ ] 后端 sidecar 自检通过：设置页/健康检查显示后端已就绪（`/api/health/ping` 由 Tauri 轮询）
- [ ] 重启应用一次：Agent 状态、LLM 配置**不丢失**（持久化验证，发布报告 Go/No-Go 明确项）
- [ ] 拷贝安装目录到另一台机器直接运行（绿色部署场景，若产品承诺包含此项）

## 2. 核心链路（图纸 → NC）

- [ ] 导入样例 DXF → 图纸解析出特征
- [ ] 导入样例 STEP → 3D 模型正常显示（Three.js 渲染）
- [ ] 参数化几何/工艺规划跑通，生成 OperationPlan
- [ ] 颤振预测（阶段 5）出结果，审核并导出 ChatterReport
- [ ] G 代码生成（阶段 6）：工程师逐条审核 → confirm 导出 NC 文件
- [ ] **CAM 校验（阶段 7，含体素仿真）**：对阶段 6 任务执行校验 → 校验报告含
      `voxel_simulation_report` 字段 → 工程师审核 → confirm 导出 cam_report.json
- [ ] **仿真强制闭环（本批次新增）**：
  - 对未通过阶段 7 校验的 NC 文件调用 DNC 发送 → 应被拦截（HTTP 403 + 错误码 8013）
  - 对体素校验通过且已确认任务的原始 NC 文件调用 DNC 发送 → 放行（mock 机床）
  - （如无 DNC 设备页入口，用设置页或开发者工具直接调 `/api/v1/dnc/nc-program/send`）

## 3. 数据与隔离

- [ ] 全程断网（拔网线/禁用网卡）下核心链路可用（数据主权卖点：LLM/推理全本地）
- [ ] 应用数据落在用户目录（`%APPDATA%` 或安装目录），无写系统盘敏感位置
- [ ] 卸载后重装：用户配置不丢（或按产品定义行为验证）

## 4. 结果判定

| 结果 | 判定 |
|---|---|
| 全部勾选 | Go——进入种子客户试点 |
| 第 1 节任一失败 | **No-Go**——交付闭环阻塞，优先修 |
| 第 2 节链路断裂 | No-Go——核心承诺不成立 |
| 第 3 节失败 | 视卖点承诺决定（数据主权是核心卖点 → No-Go） |
