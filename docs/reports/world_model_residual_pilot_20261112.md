# 残差建模匹配试跑：岭回归基座 + 神经网络残差

日期：2026-11-12。承接[短程标签可预测性探针](world_model_label_predictability_20261112.md)。结论：**预登记的 P1 通过（3/3 组），P2 未通过**——切削力信号几乎全部由线性基座承载，神经网络残差在岭回归之外没有学到可测量的额外信息，且在 2/3 组轻微劣化。这是本项目首个在切削力 MSE 口径稳定超过持久性的配置，但增益来自 18 特征线性模型，不来自 LSTM。

## 协议

- 入口 `engineering/python/scripts/wm_residual_pilot.py`，2 臂 × 3 组匹配（c1/c4/c6），种子 42、20 轮、batch 32、CPU 单线程、零增量头初始化，总耗时 35.3s。
- **control 臂**：原始目标，相对增量头 + 物理损失（与 state_scale 最优臂同配置）；**residual 臂**：目标平移为 `target − ridge_delta`，评估时组合预测 = 网络预测 + ridge_delta。两臂唯一差异是目标平移；残差臂零初始化时组合预测精确等于"岭回归单独"（运行时已断言）。
- 岭回归逐通道逐步在训练折拟合（复用探针的闭式解与内部 λ 选择），验证折只评估一次；选模沿用 state_scale 协议（验证折早停/选模，诊断性质）。

## 预登记比较结果

**P1（residual 组合切削力 MSE < control）— 通过 3/3：**

| 组 | control R² | residual R² | 岭单独 R² |
|---|---:|---:|---:|
| c1 | +0.314 | **+0.549** | +0.547 |
| c4 | +0.245 | **+0.282** | +0.338 |
| c6 | +0.209 | **+0.295** | +0.352 |

**P2（residual 组合切削力 MSE < 岭单独，即网络学到岭外残差）— 未通过：**
c1 +0.549 vs +0.547（差 0.002，无实义）；c4、c6 组合反而比岭单独差（+0.282 vs +0.338、+0.295 vs +0.352）——网络残差输出在两组给岭基座加了噪声。

**切削力 MAE（参考口径）：** residual ≈ 岭单独（c1：0.1001 vs 0.09997），c4/c6 组合劣于岭单独（0.1489 vs 0.1439、0.1180 vs 0.1112）。c1 组合 MAE 0.1001 低于训练均值常数 0.1131——本项目首次在该口径越线。

## 磨损与振动（如实记录，无统一赢家）

- 磨损 MAE：control 在 c1 仍最好（0.000150 vs 岭 0.000170 vs residual 0.000172；持久性 0.000123）；c4/c6 三档持平。全部未超持久性，维持既有结论。
- 振动：**c4 残差臂劣化严重（R² −0.665，control +0.283）**——残差目标在该组被噪声主导，网络输出放大误差；c1/c6 正常。跨组不稳定再次确认振动通道不可宣称。

## 解读

1. 线性基座（18 特征，训练折拟合）承载了当前数据中几乎全部可提取的切削力信号；同容量的 LSTM 在原始目标训练（control R² 0.21~0.31）反而低于线性基座（0.34~0.55）——优化而非表达力是瓶颈的直接证据。
2. 残差方案在工程上可用作混合预测器：force 通道用"岭基座"，其余通道维持神经网络。但在宣称之前需解决两件事：**更正**——岭回归并非"按组拟合"：cv 划分为留一实验组交叉（训练=另外两组，验证=留出组），岭与网络评估本就是跨组口径；仍需保留的限制是每折验证组在其它折参与过训练与选模，且仅 113 窗口、单划分。第二件事是多种子复核（见次日种子扫描报告）。
3. 神经网络未能超出线性基座，说明在该数据规模下继续加大模型或轮数预期收益有限；更有价值的方向是把线性条件结构显式并入网络输入/特征，而非残差纠正。

## 已知局限

- 窗口重叠与单划分同探针；验证组即选模组。**更正**：岭回归为跨组口径（训练=另外两组），此前"按组拟合、不含跨组泛化"表述有误。
- 单种子、每臂每组一次训练；无跨种子稳健性。
- 本轮不改动生产权重与默认版本；不构成预测优势声明。
