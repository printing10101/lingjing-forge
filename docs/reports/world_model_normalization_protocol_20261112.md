# 标准化契约与重训诊断口径

日期：2026-11-12。目标先检验训练/推理共用标准化能否恢复历史输入的数值敏感性，再描述现有验证集上的预测表现。已有三个组全部被看过、用于过选模，本轮是探索性修复诊断，不能当作新独立最终测试。

契约：只用划分完成后的训练集历史几何和六项动力学拟合z-score；不读取验证输入、未来目标、动作或状态反馈。标准差低于1e-8的常量列尺度固定1并居中。参数随模型配置和持久buffer双重保存，在网络入口统一应用，动作、反馈和输出仍按原单位。旧模型无契约时保持原行为；契约或buffer缺失/冲突时拒绝加载。

匹配重训矩阵：c1/c4/c6三个留组划分，各训练原量纲与标准化两个新版本，共6项。每组同一随机种子42、初始化、数据、网络参数数量、batch32、AdamW学习率0.001、最多20轮及相同调度/选模规则；模型为Δ预测加末条反馈，不冻结几何，不改变原单位MSE，不从旧权重热启动。参数差异仅为输入标准化的非训练buffer。种子同时传入网络初始化与训练器。

预算：CPU单线程，每项20轮；合计最多约5分钟训练预算。契约测试失败则不训练；发生数值失败记录失败，不临时调参重试追分。输出用全新实验版本路径，拒绝覆盖存量权重，不切换线上激活版本。

主要检查：

1. 训练输入拟合范围可追溯，验证极值不改变参数；手动一次变换与网络内部一次变换的预测一致；保存/重载/服务预测一致；删掉元数据或修改buffer均失败。
2. 与匹配原量纲对照相比，编码器实际输入与首步门仿射量级是否下降；固定末条反馈后，历史动力学的局部梯度是否非零；完整历史与重复末帧、打乱早期顺序的预测是否可区分。
3. 逐组、逐维报告MAE、持久性和仅训练目标拟合的均值常数，不混合量纲。若只是梯度恢复而预测仍差，结论限定为数值通路修复，不能声称精度或模型优势。

每组一对训练不足以估计跨种子的稳定性；窗口和未来步不是新增独立加工实验。不因某组分数好而替换原有评估组，也不把6个训练实例当作6个独立数据来源。
