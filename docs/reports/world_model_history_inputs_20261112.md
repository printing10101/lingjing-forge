# 世界模型历史序列输入：实现与验收

日期：2026-11-12。承接[几何输入与训练选模修复](world_model_ui_inputs_20261112.md)。本轮接通历史输入，没有重新训练或改写存量权重，也未建立真实切削精度的新结论。

## 完成的行为

此前融合预测将状态固定为一个时刻，历史动作使用零值。现在世界模型页支持切换到“从JSON导入历史序列”：

1. 选择已审核零件并读取几何和尺度；历史期间沿用这份几何。
2. 选择历史JSON，页面显示文件声明来源、历史时刻数及秒制采样间隔。
3. 末条状态显示在加工状态面板并锁定；不混用手动状态。未来候选动作仍由用户填写，并沿预测长度重复。
4. 读取失败、字段缺失、时间乱序或不等间隔、已知训练长度不匹配时阻止预测，不自动补零、截断或重采样。
5. 更换模型、零件、尺度或几何修订会清空历史。迟到的文件读取结果不能覆盖新选择；切回手动模式也清空导入内容。

浏览器端限制文件1MB；两端均校验2至256个时刻。页面可下载[明确标注为合成数据的格式示例](../../engineering/public/examples/world-model-history.synthetic.json)，示例可用于接口演示，不能当作独立实测样本。此文件3条记录，仅适用于兼容长度或未记录长度的模型。

## 文件与接口口径

文件顶层：

| 字段 | 含义 |
|---|---|
| `schema_version` | 必须为1 |
| `source` | 1至512字的来源声明；系统未独立核验其真实性 |
| `sample_period_seconds` | 正有限秒数，必须与各相邻记录间隔一致 |
| `samples` | 由旧到新排列的记录列表，2至256条 |

每条记录：

- `time_seconds`：有限秒数，严格递增。
- `current_state`：转速`spindle_speed`（rpm）、进给`feed_rate`（mm/min）、切深`depth_of_cut`（mm）、磨损`tool_wear`（mm）、振动`vibration_rms`（g）、温度`temperature`（°C）。温度允许负值，其他五项非负。
- `action`：同条状态对应的实际历史动作，完整包含`spindle_speed_delta`、`feed_rate_delta`、`depth_of_cut_delta`、`width_of_cut_delta`，均须为有限数，沿用模型delta输入口径。系统不会根据两条状态的差值猜出动作。

状态反馈模型还需要末条`current_state`的`chatter_probability`、`surface_roughness`、`cutting_force_norm`、`mrr_norm`和`confidence`；加上已有磨损、振动及由摄氏温度派生的温度/100，构成训练口径八维反馈。归一化力通道不能直接作为牛顿数使用。

`POST /api/v1/world-model/predict`请求使用：`feature_task_id`、`feature_task_updated_at`、必要的`millimeters_per_unit`、上述`fusion_history`、空`current_state={}`、未来`candidate_action`及`horizon`。禁止同时传直接`unified_state`；原始非融合模型不能使用该任务来源。`/preview`本轮未扩展历史接口。

服务重新读取任务网格和审核参数，保留原来的过期修订检查。模型实际收到几何`[1,T,geo_dim]`、动力学`[1,T,6]`、动作`[1,T+horizon,4]`；前T条动作来自文件，之后来自候选动作。反馈初态取末条记录。

成功响应新增可选`model_info.input_history`，含实际历史条数、秒制间隔、起止时间、声明来源及核实状态。`training_window_match`仅表示条数匹配；旧权重未记录条数时为`unknown`。所有当前权重尚未记录训练采样间隔，因此`training_sample_period_match`为`unknown`，不把“等间隔”误作“与训练采样率一致”。

## 同时修复的推理问题

显式`device="cpu"`原来跳过`model.eval()`，随机丢弃仍开启。现在加载后正确进入推理模式。回归先断言完全相同的输入可重复得到相同输出，再保持末帧不变、只扰动早期历史，确认真实网络预测仍发生变化，排除随机性伪装历史效应。

原始非融合路径的多帧状态还存在动作时间长度固定为1的问题；现补零长度与该旧路径实际T一致，避免维度错误。该旧路径未声称拥有实际历史动作；新融合历史路径则强制提供全部历史动作。
