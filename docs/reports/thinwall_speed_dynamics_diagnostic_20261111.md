# 薄壁结构逆设计：转速相关动力学核查

日期：2026-11-11。第四轮，探索性模型诊断。

**本轮结果：加入公开实测频率曲线，没有消除原来4处偏差；一项变为符合，同时新增4处偏差。频率数据也不能唯一确定完整动态柔度。当前不能把任何一组未测清的柔度假设择优当作“修正后模型”。**

## 1. 核查对象与证据边界

主线仍是用再生切削反馈指导最终零件的壁厚/加强筋设计。这里先核查外部柔性刀具基准，不把刀具实验替代薄壁结构设计验证。

参考标签沿用第三轮第二版：32行分层抽查后暂保留25行，仍由单一助手审阅、坐标继承旧表。其21/25等数字只描述这一暂定子集；原516行表未修改，第一版误判的27行导出不再使用。

动力学来源为[Gradišek等2005原文](https://web.fs.uni-lj.si/lasin/www/~gradisek/gradisek2005.pdf)，Fig8及§3.3。作者分别测量了旋转工具的频率变化，但也说明当时的完整频响不适合直接用于定量稳定性预测。它是同一装置的另一类测量，不是独立实验室的重复验证。

从PDF嵌入的1922×1432图像提取33个点：使用坐标轴刻度标定，在原图已显示的转速位置取标记中心，未使用任何切削稳定/颤振标签拟合。0rpm约722.2Hz，23krpm最低约683.6Hz，与正文近似描述一致。原始像素、轴标定、CSV哈希和叠图保留于`evidence/round4/`。模型只在图示0–34krpm范围内线性插值，不外推。

## 2. 为什么不能只改一个频率数字

本轮模态模型的传递函数为：

`H(s) = V diag[1/(s² + 2ζωs + ω²)] Vᵀ`。

频率图能给出频率比例r，却不能单独给出模态参与量V、旋转状态阻尼ζ及完整传递矩阵。为清楚分开观察与假设，定义静态模态柔度比例α，保持阻尼比为常数：

`ω_new = r ω_old`，`V_new = r sqrt(α) V_old`，

从而满足`H_new(s) = α H_old(s/r)`以及`H_new(0) = α H_old(0)`。

若用等效质量/刚度表述，同一变换为：

`k_new/k_old = 1/α`，`m_new/m_old = 1/(αr²)`。

这里m是等效模态参数，不表示刀具实物质量发生变化。两方向频率按同一比率缩放，保留原表的相对各向差异；这也属于本轮假设。

常见的“质量不变，只把频率降下来”其实还隐含了`α=1/r²`，会让静态柔度上升。它并不等同于“只有已观测信息发生变化”。原文提及的旋转柔度趋势也不足以标定这里的静态α：峰值柔度还受阻尼影响，而旋转阻尼/幅值没有完整数值表。不能把任何一个α声称为实测修正。

## 4. 数值复核及未决项

- 六组×25点×160/320步，共300次确定性谱半径计算，所有160→320分类均保持不变。这不构成300个独立实测样本。
- 之后按事后声明的规则追加：若距离ρ=1不超过前两级差值的3倍，或谱半径相对差超过2%，则复核640步，选出6个情况。
- 其中3个仍离边界较近，追加1280步。640/1280均未改变分类，两个追加阶段分别约18秒和56秒；初始六组约54秒。
- α=0.75、原零基行293（含表头第295行）在320/640/1280步的ρ为0.97345、0.98868、0.97906，非单调；最近一级变化的3倍仍大于距离1的余量。保留为数值未决，不宣布全部参数场景已经收敛。
- 该3倍差值规则是筛查启发式，不是严格误差上界。本轮不继续进行更大参数搜索，不拿未决点支撑关键机制结论。

原型共76项程序检查通过；本轮两个新增模块的16项补充检查通过，语句与分支合计覆盖率100%。检查含变换后的物理质量/刚度/阻尼频响等式、静态柔度极限、源数据漂移拒绝、禁止超图范围外推、全量记录和预算停止。测试通过不证明暂定标签或真实切削预测正确。

## 5. 对下一阶段的具体决定

1. 保持原基准模型与历史结果，不将18/25或20/25中的某组替换为“标定后真模型”。
2. 不再把Gradišek2005当作最终结构逆设计的唯一物理锚点；保留其作为已知局限的刀具模型诊断。不同结构的反馈研究需要另外的薄壁几何、夹持、模态幅值/刚度、阻尼与切削条件。
3. 为下一轮登记了一个更贴近薄壁的公开候选：[Micromachines2022，13(2)，160](https://pmc.ncbi.nlm.nih.gov/articles/PMC8879075/)。正文给出80×40×3mm板、两阶工件模态的频率/阻尼/刚度、刀具X/Y参数及4个加工点。当前只作为候选：还需核清自由高度/夹持、工件模态方向与归一化、切削方向及逐点图像证据，不能直接把两个工件模态硬分到X/Y。
4. 新检索同时发现[2026年多模态薄壁稳定性论文](https://www.mdpi.com/2673-4117/7/9/487)。目前仅核至出版方摘要线索；它已涉及多模态、去材、位置与节点影响，因此这些词本身不作为我们的新颖性。具体先例范围仍需完整审阅。

本轮未建立最终壁厚/加强筋方案的外部实验有效性，也未提高投稿分区判断。已完成的价值在于把“频率确实变化”与“完整加工反馈是否被准确识别”分开，避免在任意闭合假设上扩大优化。
