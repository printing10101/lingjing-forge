# 世界模型界面融合输入接入与验收

日期：2026-11-12。承接[首轮可靠性修复](research_reliability_fixes_20261112.md)，范围是界面输入到训练模型的接线，不新增实切实验或论文精度结论。

后续进展：同日已接入可选历史JSON输入，见[历史序列实现与验收](world_model_history_inputs_20261112.md)。下文单时刻快照描述对应手动输入模式。

## 用户可用流程

1. 在世界模型页选择/填写模型版本，点击“读取当前模型要求”。输入模式、几何维度和状态反馈要求从实际加载的checkpoint读取。
2. 融合模型可以选择已完成审核的特征任务。无已审核来源时提示先完成特征提取与审核，不构造示例零件。
3. 若原始网格与已标定重建任务的输出路径一致，沿用毫米尺度；其他来源须明确填写“每个网格单位对应的毫米数”。模型尺寸、面积、半径采用同一换算，尊重审核后的参数，不修改任务记录。
4. 点击“读取所选零件几何”，查看包围尺寸、已审核特征数和尺度来源。
5. 手动填写当前加工状态。初始为空，模型需要的额外状态反馈字段按训练口径显示；温度/100通道由摄氏温度转换，力归一化值不擅自转换成牛顿。
6. 输入完整后才允许预测。服务重新读取任务网格与审核参数，再调用训练模型，不信任前端缓存的几何向量。网格读取在工作线程执行。

界面没有自动取得传感器历史；当前仍是单时刻快照。用户填写的尺度属于显式输入来源，不代表系统完成了独立测量标定。结果仍需物理验证。

## 数据过期与错误处理

- 修改模型版本后，模型要求、几何选择和摘要失效；必须读取新模型的要求。
- 修改零件或单位换算后，几何摘要失效；换零件会清空旧尺度。
- 几何/模型的旧异步请求不覆盖新选择；修改预测输入或重置后，旧预测请求的迟到结果被丢弃。
- 预测提交`feature_task_updated_at`，若任务在读取摘要后发生变更，服务拒绝并提示重新读取几何。
- 不存在的任务、未完成审核、无已确认特征、缺失/损坏网格、非有限或退化顶点、无效特征尺寸/置信度均报出错误。
- 已标定网格禁止重复缩放；未标定网格缺少明确正有限尺度时不进入模型。
- 来源冲突（直接几何与任务ID同时提供）或原始模型误传几何任务会明确拒绝。

## API扩展

| 接口 | 输入 | 输出/用途 |
|---|---|---|
| `GET /api/v1/world-model/input-requirements` | `model_uri` | 实际模型的融合/反馈要求、几何维度及已审核零件来源 |
| `POST /api/v1/world-model/prepare-geometry` | `feature_task_id`、可选`millimeters_per_unit` | 几何摘要、来源任务、修订时间及尺度来源 |
| 既有`POST /api/v1/world-model/predict` | 新增可选`feature_task_id`、`feature_task_updated_at`、`millimeters_per_unit`；已有`current_state`提供实际加工状态 | 服务重新派生几何后调用模型；成功返回`weights_source=checkpoint` |

新接口均使用`world_model:write`权限。任务ID由服务器存储解析，接口不接受任意网格文件路径。直接`unified_state`调用方式保持兼容，但与任务来源互斥。

## 仍需遵守的科研边界

本轮解决了输入缺口、尺度口径和过期数据使用问题；没有改变此前切削力/振动/磨损的验证结论。已审核特征的派生向量不等于完整CAD物理表达，单状态快照也不等于完整加工轨迹。真实零件上的收益仍须使用独立数据和强基线验证。

## 后续推进：最佳轮选模与训练窗口记录

审查发现`FusionWorldModelTrainer`原来只更新`best_val_loss`，训练结束却保留末轮权重。最佳损失不一定对应导出的模型，不能据此宣称历史权重就是最佳轮。

本次修复：

- 每次验证改善时深拷贝模型、优化器、学习率调度器及AMP状态；正常结束或早停后恢复对应快照。每轮自动保存模式最终也覆盖为最佳轮。
- `epoch`仍记录本轮实际完成轮数；新增`model_selection`明确区分`selected_epoch`、`weights_epoch`、`selected_val_loss`和`applied`，完整损失历史保留。
- 训练或验证损失为NaN/Inf时明确失败。重新调用`train()`以当前模型/优化器继续微调，但重新开始选模和历史记录，避免拿旧数据的最小损失与本轮比较。
- 新checkpoint的`input_contract`记录实际训练batch观察到的历史长度列表、训练预测步长及记录格式版本。加载后向界面提供`training_history_steps`和`training_horizon`。
- 页面显示训练历史长度与当前单时刻输入的差异；超过已记录训练预测长度时提示精度未验证。未记录窗口的旧权重显示未知，不从默认值补猜。

新增回归先复现4项失败，再检查模型/优化器动量/调度器同步恢复、自动保存、重新微调、非有限损失及真实batch窗口记录。另检查已知/未知训练记录和无效元数据拒绝。

现有`1.0.0`、`1.1.0-real`、`2.2.1-delta-real-sf`权重均未改写；它们没有上述窗口记录，本轮也没有重新训练或补造最佳轮来源。此前验证分数不能直接当作本次修复后新模型的分数。
