# 冻结世界模型历史信息诊断口径

日期：2026-11-12。本说明在本轮消融复算前记录。既有验证集和历史分数已经看过，因此本轮属于探索性复算，不能升级为事前确认实验或独立最终测试。

问题：既有切削力通道相对持久性基线的改善，是否来自历史动态信息，还是接近训练分布常数也能取得的平均回归效果？

固定已有权重，不训练、不选新轮次、不修改数据。使用`cv_c1/c4/c6`对应的验证集及其训练集，对`cv-*`和`cvsf-*`两组已有权重各做一次诊断，总计6次。每次保留权重、数组和元数据的SHA256，保存逐窗口、逐预测步和逐维误差。运行预算为CPU单线程、最多几分钟；发生契约不匹配、非有限预测、训练/验证完全相同窗口时停止该项并保留失败，不自动换模型追求好结果。

| 对照 | 固定项与改变项 | 能判断什么 |
|---|---|---|
| 完整历史 | 原始20帧及动作，使用checkpoint声明的反馈模式 | 复现现有模型行为 |
| 仅末帧 | 几何、动力学、历史动作取末条；未来动作与反馈不变 | 当前接口长度变化的诊断；属于长度分布外输入，不能等同于重训的末帧模型 |
| 重复末帧 | 历史长度、几何和动作保持不变，仅用末条动力学重复填满 | 控制窗口长度后，更早动力学信息是否影响结果 |
| 打乱早期顺序 | 每窗口保留末条，固定种子42共同打乱更早几何/动力学/历史动作 | 时间顺序是否影响模型；不改变未来动作或反馈 |
| 持久性 | 末条状态重复到未来 | 是否优于保持不变 |
| 训练均值 | 仅用相应训练集目标拟合逐通道常数 | 是否优于无时序的平均回归；禁止使用验证目标拟合 |

读出：切削力归一化通道为主要诊断通道（对应既有收益主张），同时完整报告磨损和振动等全部八维，避免只挑有利维度。记录各对照的MAE、相对持久性增益、输出标准差、与完整历史输出的最大绝对差。不同量纲不平均成一个总体分数；基线误差为零时百分比为未定义，不写成0%增益。

预期区分：若完整历史与重复末帧/打乱顺序几乎相同，且训练均值更好，则“击败持久性”不足以归因为动态历史建模。若完整历史在三个组上都改善相对对照的误差，并超过训练均值，也仅支持当前验证数据上的描述性证据；独立泛化仍需新保留组或从未参与选模的记录。

独立单位是加工实验组；113个窗口、5个未来步不是113或565个独立实验。每项只有一个验证组，不对窗口做伪独立显著性检验，也不把训练种子当新加工实验。所有组都曾被用于早停/版本选择，本轮不报告“独立测试通过”。历史权重最佳轮一致性未确立时保留未知。
