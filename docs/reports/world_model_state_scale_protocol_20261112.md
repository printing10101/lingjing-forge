# 状态损失与增量单位：探索性诊断口径

日期：2026-11-12。现有三个加工组已用于选模，以下为修复诊断，不是新的独立最终测试，不以窗口数或种子数冒充加工实验数。

观察：仅由训练部分计算的五步持久性RMSE，磨损约0.00036～0.00042mm，振动/归一化力约0.11～0.21。损失跨物理单位平均、以及增量头用统一物理步长更新，都可能压住慢变量；另一个竞争解释是这批标签在短窗口上本来就几乎等于持久性，复杂模型没有可用增益。

固定输入标准化，在c1/c4/c6留组划分上做2×2对照，各3组，共12项：

| 因子 | 水平1 | 水平2 |
|---|---|---|
| 训练损失 | 原单位MSE | 除以训练持久性RMSE后计算MSE |
| 增量参数单位 | 头输出直接作为原单位增量 | 头输出乘训练持久性RMSE后还原成原单位增量 |

尺度只由训练目标与该窗口实际末条状态计算；验证目标不参与拟合。变化RMSE<1e-8的通道尺度设为1，仍有正监督，避免零权重造成静默漂移。动作、接口输入、反馈和最终预测保持原单位；增量头尺度不是全状态输出z-score，不减状态均值。

所有12项都把增量头权重/偏置置零，使训练前预测精确等于持久性；不是只给有利方案零初始化。其余初始参数、种子42、187475个可训练参数、数据顺序、输入标准化和优化器都相同。CPU单线程，每项20轮、batch32、AdamW lr=0.001、相同调度。选模统一使用由训练尺度定义的验证损失，避免各项用不同标尺选轮次；训练损失与选模损失分别记录。预算总计300秒，不临时调参追分；数值失败保留日志、停止，不替换为好看的种子。

主要读出为磨损MAE相对持久性；同时完整报告力、振动及其余通道，比较持久性、训练目标均值、仅训练窗口拟合的逐预测步平均漂移（末条状态+平均训练增量）。漂移基线与模型使用相同末条反馈，不能用验证标签拟合。

区分：同一增量单位内比较损失水平，判断重加权效应；同一损失下比较增量单位，判断参数单位效应。单纯“恢复梯度/误差降低”不等于超过简单基线；若漂移常数已更好，则不能宣称学到了有用的历史动态。零初始化与此前非零初始化试跑不直接作因果对照。

保存所有方案，不只保留赢家。checkpoint分别保存训练损失尺度、共同选模尺度、增量输出尺度；重载后推理仍为原单位。已有模型不改变、不覆盖、不切换生产激活版本。
