## 3. 值得对外讲的三个数字（带限定语）

1. **"图纸进、代码出"全流程秒级**：单件 0.118 s（开发机实测），AI 起草不是等待瓶颈。
2. **"敢上机"几乎免费**：闭环工作流中 CAM 物理校验仅占周期 **1.8%**（0.26 ms）——安全闸门不构成性能代价。
3. **安全盾 100% 拦截 + 微秒级开销**：1,000 个随机越界/超速动作 100% 被拦截回退，strict 模式单次开销 0.057 ms。

## 4. 已知缺口（诚实清单）

| 缺口 | 影响 | 状态 |
|---|---|---|
| API 基准内置凭据 401② | 基准专用账号未在本地服务配置，认证端点未覆盖；健康/查询/并发指标有效 | 配置 `LJ_BENCH_USERNAME/PASSWORD` 后可全量覆盖 |
| 业务逻辑基准跳过 | business_logic_bench 已迁移 research/ | 按设计跳过 |
| LNN 套件为合成模型基准① | 测量的是投影计算吞吐，非真实 LTC 权重推理 | 对外表述必须注明 |
| 世界模型基准为随机权重 + 原始 8 维路径 | 测推理框架开销，不测预测精度；融合模式（ADR-020）性能由 research/ 侧 fusion_trainer 专项覆盖 | 对外表述必须注明 |
| 单机环境 | 所有数字为开发机实测，非生产 SLA | 对外必须带限定语 |

> 修复记录：世界模型套件曾因 `WorldModelConfig` 默认 `use_fusion=True`（融合输入 132 维）与本基准的 8 维 StateField 输入不匹配而整组崩溃，已在本批修复（基准显式声明原始路径）。API 套件曾因默认端口硬编码 8000（服务实际监听 8765）长期静默无数据，已改为对齐实际端口并支持 `LNN_API_BENCH_BASE_URL` 覆盖。
