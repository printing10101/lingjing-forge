# I13 工艺知识审核与版本验收

日期：2026-10-16。接续 I12，完成后端知识审核闭环与正式推荐准入整改。

后续审核界面、待审依据保存和浏览器实际操作验收见 [I14 界面验收](I14-工艺知识审核界面与交互验收-2026-10-16.md)。本报告保留 I13 阶段状态。

## 缺陷与结果

原逻辑仅排除已知未验证来源，任意其他来源标签都可能进入正式推荐。
现改为针对当前内容的有效人工批准，`manual`、`experiment`、`generated_validated` 等名称均不能代替审核。
仿真生成记录仍可作为参考保存，不自动成为已批准的加工知识。

| 项目 | 本轮实现与验收 |
|---|---|
| 新增知识 | 服务端标识、初始待审；忽略提交者自带的批准元数据 |
| 批准 | 明确来源 URL、文档校验值、页码、材料、刀具、逐参数单位、适用条件、核验方法、未解决事项为空 |
| 身份 | 登录工程师或管理员；拒绝匿名、访客、操作员和自报审核人 |
| 拒绝与撤销 | 合法状态转换；撤销后不再正式推荐 |
| 修订 | 保留标识，递增版本，重新待审；保留旧内容快照及审核历史 |
| 并发冲突 | 请求携带预期版本；过期操作返回 409，不覆盖更新结果 |
| 保存失败 | 内容、审核历史和查询索引一起撤回，磁盘原文件保留 |
| 重启 | 批准、修订、撤销及历史可恢复；旧记录无审核信息时按待审处理 |
| 内容防篡改 | 批准摘要绑定内容；新增清空审核，查询对象使用副本 |

审核证据的完整性检查不是文档真实性或工艺安全性的自动判定。
批准只适用于明确材料和具体条件；通用材料不可批准。有限正数参数之外的数据需要明确拆分后审核。

## 验收证据

`I13-validation/run_regression.py` 复跑 I12 的验收文件并加入审核、运行时工具和推荐状态回归。
最终结果见 `final-regression.xml`、`coverage.json`；新审核策略和路由模块满足新模块 80% 覆盖率门槛。
完整回归 264 项通过，新增两个模块的语句和分支覆盖率均为 100%；调整路由注册、补齐旧记录稳定标识后另复验 60 项审核与持久化测试。
API 文档门禁通过，564 条扫描路由均有文档，缺漏为 0；历史文档多余条目 121 条不作本轮已清理声明。
`mutate_review_guards.py` 在独立子进程内存中移除内容绑定、未解决事项、单位、版本冲突、失败撤回、
正式推荐过滤、新增审核清空等七项检查，均由测试抓住；结果见 `mutations.json`。
最终回归在正常源码上完成，故障注入未修改正式源文件或知识库。

指定 desktop_runtime 启动桌面后端，`verify_live_review.py` 仅执行只读 HTTP 验收：
健康接口正常，未登录审核访问返回 401，受限 Agent Token 查询正式工艺仍为 `knowledge_empty`。
正式知识文件未生成；没有把测试批准写进真实库。在线记录见 `live-acceptance.json`。
审核批准、拒绝、撤销及修订的完整生命周期使用临时库和合成样本验证；本轮未重新验收整套 Nexent MCP 服务。
