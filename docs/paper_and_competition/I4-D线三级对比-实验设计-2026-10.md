## 0. 一句话结论

**三级对比的证据结构是「数据覆盖 × 模型口径 × 机制贯通」三维量化，不是一条"精度提升曲线"。**
代码实测钉死了两条诚实边界（§1）：M1 提示词进化未接入重放路径、规则管线不读切参数据库——
任何"进化让指标变好"的叙事在当前代码里**不成立**，I4 的任务是把这些真实资产量化成答辩可用的
指标矩阵 + 指标表，并如实标注哪条轴的"改善曲线"要等 LLM 接线后才可测。

## 4. v3 演化实验（机制轴，两轮最小可行）

1. **轮 1**：`replay_harness prepare → run`（种子集，隔离灰度 DB）→ 产出基线 stats。
2. **轮 2**：灌入 C4 v2 批次真实失败统计后，`EvolutionEngine.run_loop()` 一轮 → 产出提案（如触发）与进化报告。
3. **门控验证**：`replay_harness gate <baseline_db> <candidate_db>` 两库对比 → 记录门控判定（预期 inconclusive 或 neutral：种子集小、两轮间无真实改动——**这本身就是"门控不武断"的正面证据**）。
4. **回滚验证**：人为注册一个劣化候选 → promote → gate FAIL → 自动回滚 → 报告记录 rolled_back。这是"可进化且有安全闸"的最硬机制证明。

## 5. D8 防 reward hacking 纪律

1. **held-out 真值**：手册区间真值 20 组合人工抽检（与 C2 `manual_audit_20.csv` 联动执行，一次人工动作两处签注）。
2. **双口径纪律**：沿 I2 §4——随机切分与分组切分双报，达标只认分组口径；不达标不回退充数。
3. **分数隔离**：M0 composite_score 只作回归门控与内部迭代，**不作为对外宣传指标**；对外只用 D7 四指标 + manifest 级溯源。
4. **自产数据声明**：批量轨迹 = "决策闭环自产数据"，与真实机床数据分开表述（I1 §7 原口径不变）。
