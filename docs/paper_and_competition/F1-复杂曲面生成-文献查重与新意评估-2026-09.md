## 0. 结论（先行）

拟研究的交集 **「LLM 生成 CAD ∩ 自由曲面 ∩ 加工物理评估」** 首轮查重通过，但新意落点必须收敛：

- **已被占据，不可作为贡献点**：几何指标的 text-to-CAD 基准；视觉反馈修复闭环；几何规则级 DFM 检查；点云→参数化曲面重建。
- **未发现先例（本次贡献点）**：用**过程物理信号**（颤振稳定域、切削力、材料去除仿真、3 轴可达性）对 LLM 生成的 CAD 模型做**可制造性评估与反馈**，尤其在自由曲面场景下量化「几何有效 ≠ 可加工」。
- 直接交集检索的原话（2026-09-17）："No results directly combine generative CAD model evaluation with machinability — that intersection appears to be a relatively novel research topic."

## 1. 研究定位（查重对象）

一句话：**评估与反馈信号的创新，而非生成能力的创新**。

- 输入：自然语言/参数化描述 → LLM 生成 CadQuery 代码（自由曲面特征：loft/sweep/revolve/变截面/高阶圆角）
- 评估：五级信号漏斗——编译执行 → B-rep 拓扑有效 → 几何相似度 → 3 轴可达性 → **加工物理**（颤振稳定域 / Kienzle 切削力 / 体素材料去除仿真）
- 核心实证主张：现有 benchmark 的几何指标与「可制造性」显著解耦；物理信号可以作为新的评估维度与反馈信号。

## 2. 三篇核心文献精读

### 2.1 Text2CAD-Bench（arXiv:2605.18430）— 最大的重叠与最大的空白同源

| 维度 | 内容 |
|---|---|
| 规模 | 600 个人工核验案例（L1:200 / L2:200 / L3:100 / L4:100），1200 条双风格 prompt（几何描述式 + 专家指令序列式），约 4 周 3 人建设 |
| 特征覆盖 | L1 基元；L2 布尔与标准特征；**L3 已包含 sweep（含螺旋路径）、loft（异截面过渡）、shell、倒角圆角、自由曲面、Bézier 参数曲线、扭曲拉伸**；L4 真实零件 |
| 评估指标 | Chamfer Distance（30k 采样点）、Invalidity Rate（执行失败/超时/退化）、IoU（256³ 体素）、L4 加 VLM 多视角打分。**全部是几何/执行层指标** |
| 被测模型 | GPT-5.2、Claude-4.5-Sonnet、Gemini-3-Flash、DeepSeek-V3.2、Qwen3-max、MiniMax-M2.1、GLM-4.7 + Text2CAD/Text2CADQuery/CADFusion |
| 关键发现 | L1→L3 性能崩塌：IR 从 ~15% 升到 70–90%，sweep/loft/shell 是重灾区；领域模型存在 IR-CD 解耦（语法对几何错） |

**对本文线的双重含义**：
1. **重叠警告**：自由曲面案例本身已有人做了——Paper A 的贡献点**不能**写成「曲面 text-to-CAD 基准」。
2. **空白确认**：全文（本次抓取核验）**从未出现 manufacturability / machining / physics / CAM**。其 limitation 明确聚焦在覆盖面（钣金/装配/参数族未覆盖）与评估协议（零样本单轮），完全没提制造可行性评估。它评估「画得像不像」，不评估「造不造得出来」——这正是我们的缺口，且它的 IR 70-90% 崩塌发现恰好是我们的绝佳动机引用。

### 2.2 LLM-Aided Design for Manufacturing（arXiv:2609.05559，2026-09）— 概念近邻，信号层次不同

| 维度 | 内容 |
|---|---|
| 任务 | 对**已有** CAD 零件做保设计意图的可制造性重设计（非 text-to-CAD 生成） |
| 架构 | 两智能体子系统：DFM Reviewer（每次提出一项可制造性改进）+ CAD Modifier（编辑 CadQuery 程序） |
| 验证信号 | **编译通过 + 多视角渲染图的视觉检查**（accept/abandon 每步修改） |
| 评估 | 46 零件 benchmark，chamfer 距离；优于思维链单智能体；32 步链式修改的泵壳案例 |
| 自我定位 | 作者自述 "a preliminary report"，完整评估进行中 |

**对本文线的含义**：
1. 「DFM 修复闭环」的叙事制高点已被这个工作抢先，Paper A 的 related work 必须引用并明确区分。
2. **区分度清晰**：其可制造性信号是**视觉/几何规则级**（渲染图审查）；无切削力、无颤振、无刀轨、无材料去除仿真；无 3 轴可达性分析。我们的信号层次深一层（过程物理 vs 外观检查）。
3. **威胁**：它是 preliminary report，完整版发表时可能补充物理信号。**投稿前必须重查此组的后续版本**。

### 2.3 Point2CAD（CVPR 2024 Spotlight, ETH）— 正交，仅 related work

- 任务：从 3D 点云**重建**已有几何（分段 → 解析基元 + 隐式神经自由曲面拟合），非生成。
- ABC 基准；项目页无任何制造/加工考量（本次抓取核验）。
- 用途：Paper A related work 中作为「自由曲面参数化拟合」引用；其 face 分割/拟合思路可借鉴到我们评估链的「生成模型 → 特征面」环节。

## 4. 新意声明（Paper A 草案）

> 现有 text-to-CAD 评估体系止步于几何相似度与执行有效性；本文提出并验证**加工物理在环的可制造性评估框架**：对 LLM 生成的自由曲面 CAD 模型执行五级信号评估（编译→B-rep→几何→3 轴可达性→颤振/切削力/材料去除仿真），首次量化「几何有效 ≠ 可制造」的差距，并证明物理失败信号构成一类现有基准无法捕捉的、有区分度的失败模式。

配套 Paper B（后续）：把物理失败信号反馈回生成器做修复，与视觉反馈（CADCodeVerify 式）对比。

## 5. 威胁与时效

1. 该领域以周为单位出论文（Text2CAD-Bench、TextCAD-Bench、CAD Arena、2609.05559 全部是 2026 年出现）。**投稿前必须重跑本文档 §3 的检索**。
2. arXiv:2609.05559 完整版大概率会扩展评估信号——若其完整版加入物理仿真，Paper A 的差异化空间将被压缩，届时重心移向 Paper B（物理反馈修复方法）或自由曲面专项。
3. Text2CAD-Bench 的 L3 已覆盖我们的案例类型：案例集构建应**引用并复用其难度分层法**（L1-L4 + 双风格 prompt），评估维度与它拉开。

## 6. 残留不确定性（诚实边界）

- CADCodeVerify、CAD Arena、AutoReview、TextCAD-Bench 仅来自检索摘要，未逐字核验全文。pilot 期间（F2 的 M4 节点）应补齐精读。
- 2026-09-17 检索中途遭遇搜索服务限流（429），直接交集查询（"chatter × text-to-CAD"）的第一次尝试未完成；成功的那次交集检索已给出无命中结论，但**最终投稿前需用 Google Scholar / Scopus 再做一轮系统检索**。
- Point2CAD 抓取自项目页而非论文全文；结论（正交性）基于项目页信息，风险低。
