## 3. 组件归因（当前证据）

1. **惯用法技能库是主杠杆**（+38pp）：三类实测失败模式中，"Nothing to loft" 类惯用法错误与"数学依赖/沙箱契约"错误覆盖了基线失败的绝大多数，对应卡片直击病灶。
2. **API 接地对强模型增益有限**（+10pp）：DeepSeek 的 API 幻觉率本来就低；api 静态卡在 F05 还出现 -2 噪声（16 张卡的上下文可能轻微干扰）。**假设：API 接地对 API 幻觉高发的弱模型（llama/qwen3-30b）增益更大**——待 llama 消融验证（运行中）。
3. **全家桶 45 < skills 48**：-6pp 差异在 n=50 的采样噪声范围内（分族看主要是 F03/F04/F06 各 -1 的波动），但"api 卡对强模型是否轻微有害"值得在扩基准时用更大 n 验证。论文口径：报告逐组件增益 + 置信区间，避免过度声称"越多越好"。

## 4. 与文献对话

- 基线 58% 与 Text2CAD-Bench 的 L3 崩塌（失败率 70-90%）量级一致，互为印证；
