## 2. 三个条件效应（论文消融章节素材）

1. **沙箱契约效应（+8 案例，+14pp）**：relaxed（预注入 cq/math、import 白名单）把 F03 波形（0/5→4/5 生成、IoU≈1.0）和 F04 凸轮（0/5→5/5，IoU≈0.99+）从"全灭"救回——证实 F3 §4 的 `math is not defined` 聚类确为口径伪影。**部署口径与研究口径的测量差异本身是基准设计的方法论发现**：现有学术基准（普通 Python 执行）天然处于 relaxed 口径。
2. **材料/参数效应（全局翻转）**：TC4 条件下 Fz≈2003N 恰好越过 2000N 力限，17 个模型全部判物理失败。注意：pilot 的力判据是模型无关常数（固定 ae/fz），所以该条件是"材料翻转"而非逐案区分——逐案区分需要从实际刀轨提取啮合参数（P2 遗留项，已记录）。
3. **模型效应**：llama/qwen3-30b（本地 GPU）失败特征与 DeepSeek 显著不同（F01 loft 尝试 `loft(sections=...)` 不存在的 API 参数、cd 普遍偏大），多模型差异是基准价值的直接证据。
4. **llama 口径的诚实边界（重要）**：7/50 是**下界而非能力结论**。约 20 个案例毁于 ReadTimeout（qwen3-30b 是思考型模型，本机 GPU 卸载未命中后 CPU 推理超 90s 超时）；其余失败中相当比例是 API 幻觉簇（`loft(sections=)`、`twistExtrude(twistAngle=)`、`Workplane.helix`、`cq.sin`——全部是不存在的 API）。P2 待办：timeout 提至 600s（或关闭思考模式）重跑，并对 API 幻觉做独立的失败码统计——「模型对 CadQuery API 记忆的忠实度」本身可以成为一个分析维度。

## 4. 对论文叙事的增量

1. 主张强化：「几何有效 ≠ 可制造」的缺口在两种执行口径下都成立（strict 12 个、relaxed 13 个模型被 S4 判需多轴，其中含 IoU=1.0 的完美几何）。
2. 消融设计升级：沙箱口径 × 材料 × 模型三轴条件矩阵，给 Paper A 提供了完整的 ablation 章节。
3. 新增待办（记录进 F0 P2）：逐案啮合感知的力判据；llama 批次的物理评估；relaxed 口径下 F02/F08 仍全灭 → 多轴反馈修复（Paper B）素材库继续扩大。

## 5. 诚实边界

- TC4 力判据为全局常数（见 §2.2），该条件目前只支撑"材料敏感性"结论。
- llama 批次 -ngl 99 实际未完全命中 GPU（llama-server 日志 fit 失败告警），推理速度受限；单卡显存口径记录于 `pilot/llama_server.log`。
- 所有 relaxed 执行仅在白名单（cadquery/math）内放行 import，AST 危险属性审计保留；两口径的超时一致（120s）。
