## 0. 定位与边界

本模板是论文实验阶段的**数据骨架**，与 D-1（叙事材料）配对使用：

| 维度 | D-1 工程贡献叙事材料 | D-2 论文实验数据收集模板（本文档） |
|------|---------------------|----------------------------------|
| 性质 | 已完成工程的回顾性叙事 | 未执行实验的前瞻性数据骨架 |
| 时态 | 过去时（P2-1 / P2-4 已完成） | 将来时（实验执行时填充） |
| 用途 | 投稿工程贡献章节 + 大创赛答辩 | 实验执行现场填表 + 论文实验章节 |
| 数据来源 | 代码与测试矩阵（已完成） | 模型训练 + 车间校准（待执行） |

**核心原则（项目记忆硬约束）**：
1. **工程可用性优先于学术价值**：所有实验数据收集必须服务于"能在真实车间跑出合格零件"，而非堆砌论文指标
2. **学术诚信不可妥协**：固定随机种子 + MLflow 全量记录 + 数据集冻结 + 诚实标注 HRC52 状态
3. **跨实验引用一致性**：每个 cam_report_id / experiment_id / run_id 必须可追溯，论文表格中的数字必须能在 MLflow 中复现
4. **HRC52 数据标注规则**：`pending_calibration` 阶段产出的数据必须标记 `AR-02 pre-fix data`，论文中显式排除或单独成段说明

## 1. 学术诚信硬约束（数据收集前置）

### 1.1 固定随机种子

**所有**实验脚本在导入任何随机源之前，必须执行以下种子固定代码块：

```python
import os
import random
import numpy as np
import torch

# 项目记忆硬约束：固定随机种子保证可复现性
SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)
torch.cuda.manual_seed_all(SEED)

# cudnn 确定性模式（牺牲少量性能换取可复现性）
torch.backends.cudnn.deterministic = True
torch.backends.cudnn.benchmark = False

# Python 哈希种子（影响 dict 迭代顺序）
os.environ["PYTHONHASHSEED"] = str(SEED)
```

**记录字段**（写入 MLflow params）：

| 字段名 | 类型 | 示例值 | 说明 |
|--------|------|--------|------|
| `seed.python_random` | int | 42 | `random.seed()` |
| `seed.numpy` | int | 42 | `np.random.seed()` |
| `seed.torch_cpu` | int | 42 | `torch.manual_seed()` |
| `seed.torch_cuda` | int | 42 | `torch.cuda.manual_seed_all()` |
| `seed.python_hash` | int | 42 | `PYTHONHASHSEED` 环境变量 |
| `cudnn.deterministic` | bool | True | `torch.backends.cudnn.deterministic` |
| `cudnn.benchmark` | bool | False | `torch.backends.cudnn.benchmark` |
| `torch.version` | str | 2.3.1+cu121 | PyTorch 版本 |
| `cuda.version` | str | 12.1 | CUDA 版本 |
| `gpu.model` | str | NVIDIA RTX 4060 | GPU 型号 |

## 3. LTC 颤振预测模型实验数据收集规范

### 3.1 模型架构记录模板

每次实验运行必须将以下 YAML 写入 `model_config.yaml`：

```yaml
model:
  type: LTC                          # Liquid Time-Constant Network
  variant: closed_form               # cf-LTC vs node-LTC（项目当前用 cf）
  hidden_size: 64
  input_size: 8                      # 特征数（FFT 频带 + 时域统计）
  output_size: 2                     # stable / chatter
  time_constant_init: 1.0            # τ 初始化
  time_constant_min: 0.01            # τ 下限
  time_constant_max: 10.0            # τ 上限
  solver: rk4                        # ODE 求解器
  dt: 0.01                           # 时间步长
  sequence_length: 100               # 输入序列长度

features:
  - name: fft_band_energy_low        # 0-1 kHz 频带能量
  - name: fft_band_energy_mid        # 1-5 kHz 频带能量
  - name: fft_band_energy_high       # 5-10 kHz 频带能量
  - name: fft_peak_frequency         # 主频频率
  - name: time_rms                   # 时域 RMS
  - name: time_kurtosis              # 时域峭度
  - name: time_crest_factor          # 峰值因子
  - name: time_skewness              # 偏度
```

**记录字段**（写入 MLflow params）：

| 字段名 | 示例值 | 说明 |
|--------|--------|------|
| `model.type` | LTC | 模型类型 |
| `model.variant` | closed_form | LTC 变体 |
| `model.hidden_size` | 64 | 隐藏层维度 |
| `model.time_constant_init` | 1.0 | τ 初始值 |
| `model.solver` | rk4 | ODE 求解器 |
| `model.dt` | 0.01 | 时间步长 |
| `features.count` | 8 | 特征数 |

### 3.2 训练超参数记录模板

```yaml
training:

  learning_rate: 0.001
  weight_decay: 0.0001
```
