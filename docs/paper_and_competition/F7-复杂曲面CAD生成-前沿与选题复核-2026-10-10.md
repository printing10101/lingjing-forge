# F7：复杂曲面 CAD 生成前沿与选题复核

日期：2026-10-10。性质：选题决策备忘，非完整系统综述，非新颖性确权。

后续复核：见 `F8-约束曲面编辑-价值验证与方法设计-2026-10-10.md`。已补查传统约束曲面方法、B-repLer 最新 v4 和语言 B-spline 先验；多面自由曲面编辑已有直接先例，候选一应收窄到显式设计约束下的动作选择与可复核约束保持，不能按宽泛方向主张空白。

## State-CAD 的定位

[State-CAD](https://doi.org/10.1016/j.cad.2026.104128)，Computer-Aided Design 199 (2026), 104128，Dawei Lin、Yuanning Liu。

出版社公开内容说明：CAD-Parser 将需求转换为可更新的结构化状态 SSR，生成器使用 SFT 后的 GRPO，以几何及拓扑反馈训练；构建 36K 多模态样本。数据建立于 DeepCAD，明确聚焦 sketch–extrude。因此它是精确参数建模及多轮迭代的重要直接先例，公开证据不等于任意多片修剪自由曲面已被解决。公开配置中 RL 使用八张 80GB A800；这只是该文配置，不是此类研究的最低资源需求。

## 前沿对照与旧贡献判定

| 工作 | 本轮核查到的能力 | 对 F0–F6 的影响 |
|---|---|---|
| [CADSmith](https://arxiv.org/html/2603.26512v1)（预印本） | CadQuery API 文档检索、建模例子、错误修复知识库、内核与视觉校验 | API 卡、惯用法卡、分类反馈三件套已有高度相近先例，不能按组合本身主张首创 |
| [ToolCAD](https://arxiv.org/html/2604.07960v1)（预印本） | CAD 交互环境、工具轨迹、课程强化学习 | 工具调用和 RL 已进入同一研究框架；简单增加工具或 GRPO 不足以确立新意 |
| [RA-CAD](https://arxiv.org/html/2608.05714v1)（预印本） | 执行后状态批评与 RL；局限节明确草图—拉伸 DSL、6-bit 参数 | 反馈学习已有先例，连续参数和更丰富操作域仍需单独验证 |
| [ReliCAD](https://arxiv.org/html/2609.22325v1)（预印本） | 设计意图、特征依赖、内核求解、运行证据与定向修复 | “显式意图＋求解器＋修复”通用框架已有直接先例；不能把这一组合当作新贡献 |
| [NURBGen](https://ojs.aaai.org/index.php/AAAI/article/view/37922)（AAAI 2026）；[正文](https://arxiv.org/html/2511.06194v2) | LLM 输出 NURBS 参数与解析元素混合表示；正文讨论非修剪表示局限及混合处理 | 文本到 NURBS 已非空白。不能把它简化为“完全不处理修剪”，也不能据此认为任意修剪拓扑已获严格保证 |
| [DreamCAD](https://arxiv.org/html/2603.05607v2) | 可微参数曲面；共享边界控制点/权重更新处理 C0；G1 与 Laplacian 正则 | “首次加连续性损失”不成立。软正则、结构性边界约束与面向指定接缝的误差保证需要区分 |
| [FutureCAD](https://arxiv.org/html/2603.11831v1)（预印本） | CadQuery 程序生成与文本到 B-rep 几何元素定位 | 面/边语义选择也不是无人研究的方向 |
| [CADTests](https://arxiv.org/html/2605.07807v1)（预印本） | 可执行需求测试及相关评测方法 | “生成后做可执行检查”不足以成为独立新意 |
| [MUSE](https://arxiv.org/abs/2605.28579)（预印本） | 功能、制造、装配设计量规；采用 VLM 判评并以人工标注验证 | “几何相似度之外测工程质量”已有先例。特定加工条件下的独立几何/物理证据仍可研究 |
| [OmniMech](https://arxiv.org/abs/2608.05539)（预印本） | 作者报告大规模尺寸、公差图纸及多种三维表示；含工具评测任务 | 泛称大规模图纸到 CAD 基准已拥挤；发布可用性及许可尚未逐项核查 |

结论：研究已从一次性代码生成推进到状态维护、工具交互、执行反馈学习和约束保持；自由曲面也已进入参数表示与连续性处理阶段。但这些能力在不同系统中分别被验证，不应拼接成“一个系统已全部解决”。

## 本地资产的实际边界

复核范围为工程侧 `engineering/python/app/benchmarks/machinability_pilot/`，没有把工程侧结论扩大为全项目资产结论。

- `generate_loop.py` 明确允许 loft/sweep/revolve/twist，不能用产品 `nl2cad_llm.py` 的基础体提示词代表研究能力。
- `grounding.py`、`idiom_cards.py` 中的规则检索与技能库可用作基线和实验资产；通用框架新意不足。
- `case_families.py` 是十个参数化构造族；同族五档不能替代独立复杂曲面拓扑和跨族泛化证据。
- `physics_chain.py:s4_accessibility` 按面法向和底面排除估计 undercut 面积，未实现完整刀具/刀柄扫掠与遮挡检查；其结果应称启发式风险筛查，不能称完整三轴可加工真值。
- 同文件的力和稳定切深使用固定加工参数，代码明确模型无关；不能据此证明逐案物理判别能力。
- F6 的 48/50 是运行及度量口径，不是全部满足设计要求的成功率；卡片与真值来自相同构造族，独立性须以冻结时间、留出族和模板相似性审计核实。
- 旧 `pilot/runs` 未在当前仓库定位。F3–F6 数值暂按报告记录引用，未复算；已保存的 inspectability 小样本输出不等于原生成批次恢复。

## 候选一：设计意图约束的多曲面局部编辑

问题：修改一片曲面时，如何同时保持指定接缝的 G1/G2、指定锐边、固定截面/尺寸，以及非编辑区域的几何稳定性？

先限定固定邻接拓扑、少量 Bézier/B-spline 曲面片；明确排除任意修剪和拓扑重构，随后再扩展。状态记录接缝目标等级、锐边标签、锚定尺寸和编辑作用域。LLM 选择编辑对象与操作，几何求解器处理连续参数，并输出违反约束的位置和残差。

增量必须来自新表示/求解/反馈如何降低约束破坏，而非使用求解器本身。局部性和光顺性有冲突，需定义允许传播的区域；不能承诺任意输入均存在可行解。采样通过不等于连续参数域内严格保证。

最低对照：直接重写程序、全局光顺、常规局部约束优化、带状态与定向反馈的方法。评价指定接缝残差、锐边保真、固定尺寸误差、非目标区域最大变化、几何有效率和预算。用独立原模型/几何族划分数据。

判定：候选切口，几何研究潜力较高；与 State-CAD/ ReliCAD 的通用迭代编辑不同，但必须补查传统曲面编辑、G2 拼接和约束优化文献。不能只比较 LLM 基线而回避传统求解器。

## 候选二：加工条件变化下的曲面最小干预修复

问题：设计满足形状要求后，刀具直径、伸出长度或允许装夹变化，系统应修改曲面、换刀、改装夹，还是报告约束不兼容？哪些改变可保留功能要求？

先限制单一加工方向、有限刀具集合和可控夹具；输出具体干涉位置、缺失覆盖区域或残留超差，而非只有一个不可加工分数。制造方案调整与几何修改分开计成本；固定接口、孔位等硬约束不可通过模型自行放宽。无解判断仅限已定义的动作空间，不能由搜索失败推断全局不可加工。

最低对照：几何规则、连续参数优化/搜索、通用 LLM 加制造文本反馈、空间定位反馈与约束保持方法。测加工覆盖与过切/残留、硬约束违反、几何改变量、装夹/换刀成本和评估预算。优先使用解析可判定案例校准验证器，再以独立 CAM 或专家复核拓展案例；报告离散精度收敛。

判定：最贴合已有工程资产，但目前验证器不足，首要风险是制造标签不可信。现有制造评测和优化已很多，只能把明确的任务设定、可靠反馈和可区分的机制作为候选贡献，不能声称制造在环首创。

## 推进顺序与止损

1. 恢复旧逐案例数据，统一分母、生成预算、超时与几何错误分类；缺失则明确重跑新实验，不伪装恢复。
2. 两条候选各做小规模诊断，先验证强基线是否稳定失败及约束判据是否可信。样本量只用于决定是否扩大实验，不用于宣布方法领先。
3. 若坚持曲面建模本体贡献，优先候选一；若希望最大化复用 CAD/CAM 链，优先候选二。不要同时把任意修剪、多轮编辑、全物理、五轴与 RL 作为一期目标。
4. 冻结任务与验证器后再选择是否训练。RL 是可能的实现手段，不能先选 GRPO 再寻找科学问题。
5. 如果传统优化在已定义任务中同样有效且更便宜，缩小或取消 LLM 方法贡献；仍可将结论转为任务/验证研究，但须重新核查相应新意。
