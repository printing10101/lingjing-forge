## 1. C3 · 切参数据扩容（12 → 200 → 1000）

**三路来源合流，每条带 `source` 溯源字段**（schema 扩一列，向后兼容）：

| 来源 | 方法 | 首批量 |
|---|---|---|
| 文献数字化 | 《切削手册》常用矩阵：材料（45钢/6061/TC4/铸铁）× 刀具（HSS/硬质合金/陶瓷/PCD）× 工序（车/铣/钻/镗），查表结构化录入 | ~120 条 |
| uniwear 派生 | 对 39,903 行真实工况聚类（转速-进给-力区间），导出"实测工况包络"行，标注 `source=uniwear_derived` | ~40 条 |
| pilot 真值 | `app/benchmarks/machinability_pilot/` 10 案例族的推荐参数入库 | ~10 条 |

**落地**：`engineering/python/scripts/expand_cutting_parameters.py`——读三路中间格式 → schema 校验（速度/进给区间合法性、单位字段）→ 按 `material_id+tool_series+tool_material+工序` 去重 → 原子写回 JSON。单测覆盖校验与去重。
**验收**：9 月底 ≥200 条（演示最小量）；11 月中 ≥1000 条。**禁止**无出处编造数值——每条必须有 source。

## 2. C4 · 失败案例库灌数（47 → 200 → 500）

**生成方式（自产数据闭环，这正是赛题"可进化"的卖点）**：M2 AgentRuntime 批量决策任务——同一案例族 × 切削参数扰动 × 材料扰动，走 `决策 → G-code → 体素仿真校验`，**失败与边缘案例回写 failure_cases.db**（`outcome` 按失败类型分类，`source=batch_evo_v1`），成功案例不入库。

- 边界：machinability_pilot 的 LLM 生成失败（沙箱契约冲突等）语义不同，**不灌**这个库，留作论文素材。
- 落地：`app/agent/runtime/` 批量跑批脚本 + 回写适配（对齐 `failure_recorder` 现有写入路径）。
- 验收：9 月底 ≥200 行；11 月 ≥500 行，可画出"失败模式分布随版本收敛"曲线（D2 素材）。

## 3. C2 · cutting_force v2 真实数据重训

**v1（100 行合成）保留作为三级对比基线，不覆盖。**

- 首选数据：**uniwear force_z**（39,903 行真实切削力 + 同源工况列）——特征映射：主轴转速/进给从数据集工况列取，切削深度若缺失则以数据集自带变量重定义特征序（manifest `feature_order` 如实更新，**不做没有的特征假装有**）。
- 备选：PHM2010 力信号（标签为物理代理，须在 manifest notes 与答辩材料**如实标注"实测信号 + 物理派生标签"**）。
- 流程：dataset_store 注册（对齐 v1 的 `dataset_store` 溯源格式，content_hash 全长）→ 训练（沿用 MirrorMLP 同构 + parity 校验）→ manifest v2 → 指标达标线：R²≥0.90 / MAPE≤15%（向 wear_prediction 口径看齐）。
- 验收：10 月内完成；manifest 指向真实数据集且哈希可复现。

## 4. D1/D2 · 三级进化对比实验协议

- **v1** 合成 100 行（已有）→ **v2** 真实数据重训（§3）→ **v3** 在线进化（M0 评分 + M1 演化引擎 + M2 轨迹回写：决策 → 执行 → 结果入案例库 → 影响下次决策）。
- 指标（D7，每个出"以前 X / 现在 Y"两列，即 C7 指标表）：决策一次通过率、切参推荐误差、颤振误报/漏报率、案例库命中率。
- **防 reward hacking**（D8 口径，答辩必备）：held-out 真实案例验证 + 人工抽检，不只看 validator 分数。
- 产出：三级对比曲线（v1/v2/v3 × 指标矩阵），同时是 G1 决策质量大屏的数据源。

## 7. 风险与诚实边界

1. **C2 标签性质**：uniwear 是实测力信号（优）；PHM2010 是物理代理标签——材料里必须写"实测信号 + 物理派生标签"，不可称实测验证。
2. **批量轨迹是自产数据**：答辩口径 = "决策闭环自产数据"，不是真实机床数据；二者在材料中分开表述，避免被追问时露馅。
3. **切参文献行**：手册数值属于公开工艺知识，逐条标 source；答辩被问"数据从哪来"时按三路来源如实分层回答。
