# I14 工艺知识审核界面与交互验收

日期：2026-10-16。接续 I13 后端审核闭环，交付可操作的审核页面及浏览器验收证据。

后续候选写入与 Nexent 联运见 [I15 更新闭环验收](I15-Nexent候选知识更新闭环验收-2026-10-17.md)。本报告保留 I14 阶段状态。

## 实现清单

| 项目 | 结果 |
|---|---|
| 页面与入口 | `/process-knowledge-review`，侧栏“数据与运营 → 工艺知识审核”，中英文导航标签齐全 |
| 权限 | 工程师、管理员可操作；访客、操作员不读取审核记录；修复前端将 engineer 错降为 viewer 的问题 |
| 待审资料 | 新增、搜索、状态筛选、当前内容和版本查看 |
| 来源保留 | 新增 `candidate_context` 保存来源、页码、单位、条件、未解决事项和说明；旧文件兼容 |
| 审核 | 批准、拒绝、撤销、修订重新待审，实际调用 I13 后端接口 |
| 批准前置条件 | 参数单位、HTTPS 来源、文档校验值、页码、适用范围、核验方法和明确确认 |
| 修订保护 | 切换操作重新载入已保存内容；显示但未保存的参数或材料不能直接批准 |
| 失败处理 | 409 后阻止旧版本重提；503 不冒充保存成功；401/403 清除旧记录展示；防重复提交与乱序读取 |
| 历史 | 旧内容、审核人、时间、原因、来源和适用条件可追溯 |
| 开发服务 | 排除 Python 运行时和构建目录的文件监听，解决本轮复现的脚本请求长时间无响应 |

`candidate_context` 是待审注释，不赋予批准状态，也不修改已批准依据；正式推荐仍只接受有效批准。
通用材料及未解决事项不满足批准契约。所有真实厂商资料保持待审。

## 自动验收

- 前端 80 项测试通过：界面实际提交、角色识别、导航、请求契约、来源保存、错误提示和版本保护。
- 后端扩大回归 275 项通过；另有 70 项针对性阶段复验。最终以 `backend-regression.xml` 为准。
- 新增前端四个模块整体语句/行覆盖率 98.56%，分支 95.62%，函数 91.17%；各模块均高于 80%。
- 六种前端故障注入全部被抓住：移除人工确认、HTTPS 检查、未保存参数检查、旧版本阻止、重复提交阻止、工程师角色识别。
- 七种待审依据故障注入全部被抓住：丢弃来源注释，以及移除对象、未知字段、文本、页码、单位和未解决事项的类型检查。
- 第一轮故障注入暴露两处测试缺陷：旧版本调用虽然返回失败，但未断言没有发出第二次请求；重复提交测试仅以超时失败。已加强请求次数断言，最终均以断言失败捕获。
- 故障注入只作用于测试转换结果，前后源码字节一致。正常源码上再次完整执行前端针对性验收。
- 类型检查和前端生产构建通过；构建仍有第三方注释、混合导入和大分块警告，不作为本轮已修复声明。

证据目录 `I14-validation/`：`frontend-tests.xml`、`frontend-coverage/`、`backend-regression.xml`、
`frontend-mutations.json`、`build.log`、`http-acceptance.json`。

## 浏览器实际验收

通过真实 Vue 页面与指定 desktop_runtime 启动的隔离 FastAPI 服务通信。
隔离服务使用临时知识目录、合成工程师身份和仅本机测试令牌，不读取正式知识库，不连接机床。
浏览器完成“待审 v1 → 拒绝 v2 → 修订待审 v3 → 批准 v4 → 撤销 v5”，
验证缺失确认时不能批准；另新增第二条待审资料，重新加载后来源、页码、单位和未解决事项保留。
最终通过 HTTP 读取断言生命周期、版本、历史、900 rpm 修订值及第二条待审记录。

截图 `browser-approved-synthetic.png` 为合成样本批准时的完整页面；`browser-review-ui.png` 为最终撤销后的页面。
`browser-final-state.txt` 和 `browser-pending-after-reload.txt` 保留实际页面状态。
这些记录只证明界面和接口工作流，不构成真实工艺数据的专家批准或加工效果证明。

正式桌面后端已更新并复验：健康正常，未登录审核接口返回 401，受限 Agent Token 查询正式推荐为 `knowledge_empty`。
正式知识文件仍不存在，没有将测试记录写入真实库。

开发服务观察：修复前约 25,477 个进程句柄，脚本请求 15 秒超时；排除无关目录后约 1,237 个句柄，
同一脚本请求返回 200、约 252 ms。这是本次环境的前后观察，缓存和启动状态可能影响结果，不是统计性能基准。
