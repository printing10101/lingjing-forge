# I12 材料关联与刀具规格整改验收

日期：2026-10-16，继续处理 I11 的材料 ID、刀具族直径和材质匹配缺陷。
本轮完善加工草案的一致性和不确定性表达，不把内置参数升级为已审核工艺知识。

## 缺陷与修复

| 缺陷 | 修复 | 验证重点 |
|---|---|---|
| 旧 material_ 前缀参数无法关联规范材料 ID | 对 45 钢、6061、304 保留明确旧别名；其他记录仅允许唯一精确材料名关联 | 新旧 ID 得到相同参数集合；近似名称、歧义名称和其他牌号不会借用 |
| 刀具范围中点冒充固定规格 | 保留原范围，只有单一尺寸才建立固定直径 | [6,20] 不再变成已确定的 13 mm 刀具 |
| 过大钻头被解释为覆盖小孔 | 固定精确尺寸优先；钻头大小不匹配则不声称匹配 | 13 mm 和 6 mm 钻头均不能作为 φ8 孔的确定规格 |
| 刀具族候选被当成具体刀具 | 候选目标尺寸携带 diameter_verified=false、原范围、明确提示，评分封顶 50 | 范围内 φ8 候选不会变成库存存在或已安装的声明 |
| 同尺寸不同材质刀具被去重丢失 | 按原始 ID 保留独立记录 | WC、HSS 同范围刀具都保留 |
| 按材料和刀具系列取首条参数，忽略刀具材质 | 匹配器同时过滤材质，仅将 WC/tungsten_carbide 归为 carbide | HSS、硬质合金、涂层硬质合金不互相套用 |
| 缺少中心钻时继承最终孔径 | 中心钻规格标为未知，直径 0，保留未确认提示 | 不把最终 φ8 孔径伪装成已确定的中心钻规格 |

`diameter_verified` 只区分记录中的确定尺寸与范围候选，不代表机床实物或库存验收。
无具体刀具时仍可生成带警告的概念草案；不声称完整工艺或上机条件已通过。

## 测试及故障验证

新增实际数据关联、控制样本材质隔离、范围候选、尺寸偏差、无效输入、歧义材料名和中心钻回归。
初次故障注入显示单测未覆盖名称顺序不同的 304 / 6061 显式别名，补齐后七种变异均被抓住。
覆盖参数材质过滤、材料别名、中点伪规格、候选误报确定尺寸、过大钻头、候选评分及中心钻借用孔径。
变异只在子进程内存中进行，不改正式源文件或刀具目录。

最终 213 项针对性回归通过，进程正常退出；七种故障变异均被测试拦住。
最终测试记录：`I12-validation/final-regression.xml`；故障注入：`I12-validation/mutations.json`。
早期对现有数据的测试假设使用旧快照（误以为没有 WC 钻削参数、固定刀具范围），已改为受控反例加实际数据断言。
本轮没有修改 609 条参数或原始刀具 JSON 来迁就测试。

## 在线验收

使用指定 desktop_runtime 重启后端，经 Nexent 实际运行六个 MCP 工具。
在线孔草案要求 φ8 钻削候选，保留原刀具族范围、未确认规格及参数来源提示；工序计划采用 8 mm 草案几何。
切削参数显示 source=handbook_common_range、source_verified=false；正式四元组推荐仍为 knowledge_empty。
中心钻缺失仍是明确的待补充项，不冒充实物刀具。
完整回读与断言见 `I12-validation/live-acceptance.json` 和 `mcp-tool-execution.json`。

## 未通过的业务验收

- 原始参数仍缺工况与可信出处审核，不能把映射成功当成参数已正确或安全。
- 刀具族候选仍需确认具体刀具型号、尺寸、库存、装夹及现场安装。
- 厂商候选资料的速度单位、材料等价关系、正式审核批准流程仍待补齐。
- 大模型自主 Skill 执行、动态本体、跨文档多跳与真实行业效果评测仍未完成。
- 本轮未连接或操作实体机床，也未验收真实加工或 DNC 下发。
