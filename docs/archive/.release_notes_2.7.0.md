## 灵境制造 2.7.0

AI 驱动的制造智能桌面应用：**图纸 → 3D 模型 → 工艺规划 → NC 代码** 全流程智能化。
Tauri(Rust) + Vue3 + Python/FastAPI 全栈。

### 安装

1. 下载 `灵境制造_2.7.0_x64-setup.exe`（约 397 MB，首次启动会初始化嵌入式 Python 后端，耗时约 1 分钟）
2. 双击安装，启动后从以下位置读取初始密码：
   `%LOCALAPPDATA%\com.lingjing.manufacturing\logs\admin_initial_password.txt`
3. 使用 `admin` + 初始密码登录，登录后**必须立即修改密码**

### 本版修复

- 修复安装包残留开发机配置文件问题：安装目录不再携带 `.env` / 用户数据，首次启动自动生成指向安装目录的配置（普通用户开箱可用）
- 修复 SQLite 长路径前缀（`\\?\`）导致数据库无法打开的问题
- 修复 NSIS 打包 260 字符路径限制导致的构建失败
