### 2.1 最快加工工艺流程说明

针对 70,000 件大批量，推荐一次装夹完成全部车削要素，减少掉头：

1. **下料**：Ø78 圆钢按 81 mm 长度锯切（或棒料送料机直接送料）。
2. **调质**：外协热处理 20-24HRC（不计入机加工时间）。
3. **装夹**：三爪卡盘夹持毛坯，伸出 80 mm；若用棒料送料机则自动夹紧。
4. **T01 外圆粗车刀**：车端面见平 → 粗车外圆至 Ø76.5（留 0.5 mm 精车余量）。
5. **T02 外圆精车刀**：精车端面保证总长 80 → 精车外圆至 Ø76。
6. **T03 镗刀**：钻/镗中心底孔 Ø20 → 粗镗 Ø46 台阶 → 精镗 Ø46 H8；粗镗 Ø26 台阶 → 精镗 Ø26 H8。
7. **T04 倒角刀**：所有锐边倒钝 C0.5。
8. **下料/换件**：切断或松开卡盘换件，循环下一工件。
9. **后处理**：去毛刺、清洗、终检。

## 10. 风险提示与假设说明

1. **图纸尺寸不确定性**：图纸左侧部分小尺寸（20.6 / 6.6 等）分辨率不足，内孔结构按 Ø46×26 + Ø26×54 假设。实际投产前请用高清图纸或 STEP 模型复核。
2. **预钻孔假设**：内孔镗削按已预钻 Ø20 mm 底孔计算。若毛坯中心未预钻孔，需增加中心钻 + 钻孔工序（约 +0.5~1.5 min/件）。
3. **调质处理**：20-24HRC 建议外协，不计入机加工时间；调质后硬度会显著影响刀具寿命和切削参数。
4. **G 代码说明**：本报告 G 代码由项目通用后处理器生成，数控车床实际使用前需按具体机床（Fanuc/Siemens/广数等）和车削循环（G71/G72/G70 等）调整。
5. **产能瓶颈**：单台单班约 31 件/天，70000 件约需 2259 个工作日。大批量交付必须采用自动送料、双主轴或多机并行。
