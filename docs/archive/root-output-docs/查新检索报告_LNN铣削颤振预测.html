3.3 LNN 基础模型（技术底座，非本案新颖点）

  • CfC（Closed-form Continuous-time）闭式连续时间模型：Hasani et al., 2022（arXiv:2106.13898），以闭式解取代 ODE 数值求解，训练/推理提速 1–5 个数量级，保留连续时间、输入依赖时间常数、抗噪、因果特性。
  • LTC / 神经电路策略（Neural Circuit Policies）：原始 LNN 形态，神经元状态由微分方程驱动，时间常数随输入自适应。

五、创造性（非显而易见性）分析

以 LSTM/1D-CNN-LSTM 颤振检测（P5、L1–L3）为最接近现有技术，本案若欲具备创造性，需论证 LNN 替代离散 RNN 并非「等效替换」，而是带来可证的技术效果：

  • 早预警能力：LNN 连续时间建模可在颤振谐波初现时（无需凑满固定窗口）即响应，相较 LSTM 的窗口切片延迟具技术优势（需实验对比预警提前量）。
  • 非均匀采样鲁棒性：变速铣削、断续切削下 LNN 无需插值/填充，避免虚假谐波，提升复杂工况泛化（需对比准确率/误报率）。
  • 边缘部署低开销：CfC 闭式解去 ODE 求解器，参数量与算力显著低于 LSTM，利于 Tauri 桌面端 / 嵌入式实时推理（需对比时延与功耗）。
  • 物理信息增强（建议加入）：将稳定性叶瓣图或循环平稳能量比作为物理先验耦合进 LNN，既强化技术属性（符合审查指南「算法+自然规律」），又提升小样本泛化，构成区别于 L5（仅磨损）的明确界碑。
创造性成立的前提是实验数据。审查阶段需提供本案 LNN 方案与 LSTM/CNN 基线的对比实验（准确率、预警提前量、跨工况泛化、边缘时延）。请在申请前整理 2–3 组对比实验作为说明书「有益效果」证据。

六、与自身已公开代码的冲突评估（最高优先级风险）

核心风险：据项目记录，源代码已推送至公开 GitHub 仓库，且公开不足 6 个月。中国《专利法》第二十四条的 6 个月宽限期仅限国际展览会、规定的学术/技术会议、他人未经同意泄露三种情形，不包括申请人自行在 GitHub 公开。因此公开日即构成潜在现有技术日，对之后提交的申请有新颖性对抗风险。

但仍有可操作空间，理由有二：

  • 新颖性按权利要求逐项比对。GitHub 公开的是「软件/代码与功能」，未必披露权利要求所界定的具体方法步骤与发明点（如 LTC 的具体连续时间构造、输入依赖时间常数的计算式、物理指标耦合方式、非均匀采样处理流程）。只要权利要求覆盖的内容在仓库中未充分对应，该部分仍具新颖性。
  • 审查员通常不主动爬 GitHub，自公开被检索到的概率偏低；主要风险在授权后的无效宣告环节。

缓解措施（务必执行）：

  • 立即停更一切公开发布（论文、演示、新功能介绍），直至申请提交。
  • 精确记录首次 push 日期与提交内容，作为「公开边界」抗辩依据。
  • 权利要求刻意覆盖仓库未披露的方法细节，而非泛泛的「一个 AI 预测系统」。
  • 核心权重、专有训练数据、调参诀窍以商业秘密锁死，代码同步做软著登记补强。

八、申请策略与权利要求差异化要点

  1. 保护主题：同时撰写「方法、系统/装置、计算机可读存储介质、计算机程序产品」四类权利要求（审查指南 2024 已明确允许程序产品主题）。
  2. 独立权利要求核心特征（建议，且尽量避开已公开代码）：
    • 获取铣削过程多源时序信号（加速度/声发射/主轴电流），保留原始采样时间间隔作为连续时间输入；
    • 以 LTC/CfC 液态神经元构建连续时间动态系统，时间常数 τ 由输入依赖门控自适应生成；
    • 将物理颤振指标（循环平稳能量比 / 每转 RMS / 稳定性叶瓣临界参数）作为监督或物理约束耦合进训练；
    • 输出颤振发生概率与提前量预警，并在边缘端实时推理。
  3. 说明书充分公开：清楚记载 LTC/CfC 具体算式、τ(t) 计算、物理指标定义、训练流程，并附对比实验数据。
  4. 权属与费减：个人名义申请 + 学生证办费减（85%）；但需先确认大创经费是否构成职务发明，避免学校后续主张权利。
  5. 加快通道：高端装备制造多属保护中心预审领域，可走预审加快（最快约 3 个月授权）。
