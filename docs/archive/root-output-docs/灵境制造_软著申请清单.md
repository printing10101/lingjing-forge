# 灵境制造 · 软件著作权（软著）申请清单

> 结论：**建议现在自办（官费 0 元），与组队 / 申报书 / demo 准备并行推进，不必阻塞其他步骤。**
> 目的：作为「挑战杯（大挑）」科技发明制作 A 类的知识产权佐证；也为后续可能的互联网+ 报名提供 IP 清晰度。

## 一、周期与费用（2026 核实）

- **官费：0 元**（自 2017 年起软著正常审查官费已免征）
- **普通审查周期：30–60 工作日（约 1.5–3 个月）**；遇补正则顺延（补正需在 30 日内完成）
- **加急**：1–35 工作日不等，需额外付费（学生不建议，普通即可）
- **代理费**：自办 0 元；委托代理机构约 300–1000 元（不必要）
- **时间线**：现在（2026.08）申请 → 2026.10–12 拿电子证书 → 大挑校赛（2027.1–3 提交）前就位，时间充裕

## 二、2026 新规注意

- 需**诚信声明**：确认软件为独立开发、**未使用 AI 编写代码 / 撰写文档 / 生成登记材料**。灵境制造代码为本人开发，如实声明即可。
- 提交的 60 页源码**不得含第三方版权声明 / GPL 等开源协议头注释**的文件，否则需补权利说明。应抽取**本人应用代码**（如 `engineering/python/app/` 等自研模块），**不要**提交 `node_modules`、第三方依赖或开源库。

## 三、申请材料

| 材料 | 要求 |
|---|---|
| 软件源代码 | 前 30 页 + 后 30 页，共 60 页，每页 50 行（不足 60 页全交） |
| 软件文档 | 用户手册 / 设计说明书，前后各 30 页（或 30+ 页） |
| 身份证明 | 个人申请仅需身份证 |
| 申请表 | 《计算机软件著作权登记申请表》（官网填写） |
| 合作开发（若适用） | 共有人协议（若后续以团队名义，需全体签署） |

## 四、申请路径

1. 登录**中国版权保护中心**官网（中国版权保护中心）注册账号
2. 选择**个人申请**（著作权人填本人 / 学生）
3. 软件名称建议：`灵境制造 AI-CAM 一体化软件 V1.0`（或贴合实际功能命名）
4. 上传源码（PDF，仅本人代码）+ 用户手册 + 身份证 + 申请表
5. 等待形式审查（约 15 工作日反馈），通过后下载**电子证书**（与纸质同等效力）

## 五、与赛事的衔接

- 大挑要求作品 IP 清晰、学生主导 → 软著著作权人为学生本人，正好契合
- 若后续组建团队并以团队名义，可补**合作开发共有人协议**；但个人名义拿证已足以作为佐证
- 专利（发明专利）周期 18–24 个月，赶不上 2027 大挑，本次不选
