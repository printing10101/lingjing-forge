目标

所有重构的前提是"改了不坏"的检测能力。先补齐主链测试与 CI 强制，后续每一步有兜底。

执行步骤

  2. 补 5 条主链 E2E（缺哪条补哪条）：
    • E2E-1 认证链路：注册→登录→Bearer→RBAC 4 级访问控制→token 过期。
    • E2E-2 CAD 主链：上传 DXF→特征识别→工艺规划→G-code 生成（后处理 11 控制器抽样）。
    • E2E-3 仿真链路：切削力→颤振叶瓣→体素切削→结果持久化。
    • E2E-4 DNC 链路：MTConnect/OPC UA 适配器（mock 服务器）→TDengine 落库。
    • E2E-5 RAG+Agent：RAG 检索→Agent Gateway LNN 推理→审计日志。
  3. 强化 tests/architecture/test_import_directions.py：新增三条禁令（见各 DoD），纳入 CI（workflow 中 pytest 强制）。
  4. 新增 scripts/openapi_diff.py：导出前后 OpenAPI 契约 diff，路由重构零回归门禁。
门禁：5 条 E2E 全绿；architecture 测试全绿；OpenAPI diff 脚本可运行。

D1 · 全局单例消费方迁移（DI 落地，1.5 周）

现状：模块级 get_* 定义 416 个；app/dependencies.py 已注册 ~40 个工厂；消费点 216 处仍直接 from app.xxx import get_*。FastAPI 端点多数是函数内调用而非 Depends 注入。

步骤（分批，每批可独立验证）

  1. 生成迁移清单：脚本输出 消费文件 → getter → 目标模块 → 是否已注册 映射表（216 条）。
  2. 批次 A（低风险，机械替换）：对已注册的 ~40 个 getter，用 sed 批量把消费方 from app.X import get_y → from app.dependencies import get_y。行为完全等价（工厂内部委托原实现）。~60-70 文件，全量 pytest 回归。
  3. 批次 B（未注册 getter）：二选一——①在 dependencies.py 补注册（惰性 import 模式）；②若确为一次性局部 helper，就地内联并删除导出。
  4. 批次 C（FastAPI 端点注入，高风险）：端点签名改为 store: XStore = Depends(get_x)，删除函数内 await get_x() 调用。逐文件迁移，每个文件跑其路由测试。
  5. 批次 D（收尾）：原模块 get_* 加 @deprecated 标记；reset_all_singletons() 扩展覆盖全部懒加载。

改造模式（示例）

# 旧（函数内直接调用）
async def list_models():
    reg = get_llm_registry()          # 模块级导入 + 调用

# 新（Depends 注入）
from app.dependencies import get_llm_registry
async def list_models(
    reg: LLMRegistry = Depends(get_llm_registry),
):
    ...                              # 测试可注入 mock
风险：批次 C 改变调用语义（单例→每次请求解析）。缓解：工厂本身已单例化（_LazySingleton），行为不变；逐文件验证。
DoD：216 消费点归零；architecture 测试新增禁令——禁止 from app.* import get_（白名单仅 app.dependencies）；pytest 全绿。

D3 · API 直连 DB → Repository 层（1 周）

现状：api/v1 下 20 文件 import app.database/app.models，其中 C 类（真正直连 DB 操作）~9 个：auth、users、agent_state、goal_alignment、governance、cost_budget、notifications、lnn/routes_system；health 属合理基础设施检查（保留）。其余为 B 类（仅类型导入，不动）。

步骤

  1. 分类三态：C 类（需建 Repository）/ B 类（类型导入，仅收紧为 app.models.schemas）/ 保留（health 基础设施查询）。输出分类表。
  2. 为 6 个核心域建 app/infrastructure/repositories/<域>_repo.py：auth_user_repo、agent_state_repo、goal_repo、governance_repo、budget_repo、notification_repo。Repository 只含数据访问，不含业务规则。
  3. API 层改为 store: XRepo = Depends(get_x_repo)，删除内联 Session/ORM 访问。
  4. 业务规则（校验、计算）留在 services/domain 或 API 编排层，不随 SQL 下沉。
  5. 每个 Repository 补 ≥3 条单测（CRUD + 边界）。
门禁：api/v1 下无直接 db.execute / session / Session() 调用；Repository 单测通过。
DoD：C 类 9 文件清零；architecture 测试新增禁令——api/ 不得 import app.database（白名单 app.models.schemas 除外）。

现状：main.py 直注册 5 条 @app.*；11 个非 API 包自带 APIRouter 散落挂载。

  1. main.py 5 条路由去向：

  2. 11 个非 API 包 router（dxf/api.py、rag/routes.py、simulation/api.py、projects/project_api.py、step_import/api.py、integrations/mes/api.py、knowledge_graph/extractor/review.py、cad/process_router.py、ai/ollama_routes.py、ai/process_understanding/routes.py、middleware/metrics_middleware.py）→ 全部改由 app/router_registry.py 统一挂载，删除 main.py 中散落 include_router。

门禁：OpenAPI diff 为零；architecture 测试——main.py 禁止 @app.xxx。
DoD：main.py 无路由装饰器；router_registry 为唯一挂载点；端点集零回归。
