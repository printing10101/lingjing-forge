# 灵境制造（Spirit Realm Manufacturing）· 项目简介

> 一份 AI 驱动的 CAM（计算机辅助制造）桌面软件，定位为「图纸 → 3D 模型 → 工艺规划 → NC 代码」全流程智能化工作流。
> 主开发者：李昱龙（贵州大学）｜技术形态：Vue3 + Tauri(Rust) 桌面壳 + Python/FastAPI 后端

---

## 一、产品定位

面向数控加工场景，把"读图—建模—定工艺—出代码"这一原本依赖老师傅经验的链条，做成可交互、可复现的软件工具。目标是降低 CAM 的使用门槛，并让加工工艺决策可被 AI 辅助与预测。

## 二、技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 桌面壳 | Tauri + Rust + Vue3 + TypeScript | 跨平台桌面应用，轻量、原生体验 |
| 后端 | Python / FastAPI | 70+ 后端模块，按 api / app / infrastructure 分层 |
| 智能内核 | PyTorch / 液态神经网络(LNN) | 加工动力学与稳定性预测 |
| 知识 | RAG 工艺库 | 工艺知识检索增强 |

## 三、已落地核心能力（代码可查）

1. **图纸解析与三维建模**：支持 DXF / STEP 图纸导入，生成可用于工艺规划的三维几何。
2. **自然语言生成 CAD（NL2CAD）**：通过 `app/api/v1/nl2cad/` 模块，由自然语言描述生成 CAD 草图。
3. **工艺规划与加工仿真**：`process_planning/` `cam_validation/` 等模块，完成工艺路线与加工可行性校验。
4. **铣削颤振 / 加工稳定性预测**：基于液态神经网络（LNN）的 `app/ai/lnn/` 模块，对铣削颤振与加工稳定性进行预测。
5. **数控后处理（9 种已验证）**：Fanuc、Siemens、Heidenhain、Mitsubishi、KND、HNC、Fagor、GSK、XMachine 等主流数控系统的 NC 代码生成。

## 四、与「数字设计 + AI 工艺优化」的衔接

本项目的主线——**数字设计（图纸→3D→工艺）→ 用 AI 预测加工性能（LNN 颤振/稳定性）**——与"有限元—人工智能融合的工艺优化与性能预测""基于机器学习的制造工艺反向设计"属于同一类工程命题：用数据/模型方法解决制造工艺与性能预测难题。区别在于底层物理视角（本项目偏切削颤振动力学），但方法论同源，可作为工程落地能力的直接支撑。

## 五、工程规模

- 完整源码与构建链路可审阅。
