# 核心路径性能基线（E4）

日期：2026-11-15。基线文件：`engineering/python/benchmarks/core_paths_baseline.json`。

## 工具口径（与验收差异，如实记录）

验收要求 "pytest-benchmark 基线存档"，但本机 **无法安装 pytest-benchmark**：

```
ERROR: Could not find a version that satisfies the requirement pytest-benchmark (from versions: none)
```

因此改用自建 harness（`engineering/python/scripts/benchmark_core_paths.py`），输出同口径统计
（min / p50 / p95 / mean，ms），基线 JSON 存档并可回归比对。差异：没有 pytest-benchmark
的自动校准/历史曲线；相同点：同一测量点、可重复、阈值化。

## 基线数值（本机，Python 3.14 / Windows 11）

| 阶段 | p50 (ms) | p95 (ms) | 说明 |
|---|---:|---:|---|
| dxf_parse | 12.35 | 14.19 | 25 孔板 DXF（ezdxf） |
| feature_extract | 1.69 | 2.08 | 孔/轮廓/包络提取 |
| step_build | 404.21 | 418.79 | CadQuery 拉伸 − 25 孔布尔并导出 STEP |
| cutting_params | 239.68 | 249.52 | 25 条推荐 + 稳定性证据 |
| gcode_generate | 42.36 | 54.30 | 真实工艺管线（规划→后处理→语法校验） |
| voxel_validate | 428.74 | 474.94 | 200×150×50 默认毛坯体素去料（本案例 100×100×10） |

复测（同日第二次）：全部 `ok`，比值 0.76×–1.37×，说明基线可重复。

## 回归判据

- 同机比对 p50：> **2×** 基线 → `warn`；> **3×** → `fail`（退出码 1）。
- 跨机器/跨 Python 版本不可直接比；基线文件含 `environment` 指纹，比对前先核对。
- 未接入 CI：CI runner 与本地机器不同，直接比对会产生假阳性；本地发版前跑 `--compare`。

## 用法

```bash
PY='C:/Users/<user>/AppData/Local/Programs/Python/Python314/python.exe'
$PY engineering/python/scripts/benchmark_core_paths.py --iterations 5 --save     # 重建基线
$PY engineering/python/scripts/benchmark_core_paths.py --iterations 5 --compare  # 回归检查
```

## 验收

- 基线 JSON 入库；脚本可复现；`--compare` 在本机全绿（overall=ok）。
- 单测 5 项（`tests/unit/test_core_path_benchmark.py`）：统计、空输入、三档判定、缺基线、阈值校验。
