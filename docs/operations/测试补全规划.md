## T1 · feature_extraction 几何算法（P0）

- **目标**：`plane_extractor.py`(16%) / `cylinder_extractor.py`(16%) / `hole_detector.py`(14%) → 60%+
- **为什么 P0**：特征识别（孔/面/腔/凸台）是「图纸→NC」链路第一步，上游全依赖它。
- **依赖**：trimesh（构造 mesh）+ sklearn（RANSAC）。均在 requirements 已声明。
- **策略**：
  1. 用 numpy 合成小 mesh（如 `trimesh.creation.box/cylinder` 或手写顶点/面），喂给 extractor；
  2. 测「正例」：规则平面/圆柱/孔能被正确识别（feature_type、params、confidence）；
  3. 测「边界」：空 mesh、退化几何、极小半径、噪点；
  4. `precision_disclaimer.py` 与 `feature_store.py` 已 100%/86%，只补算法层。
- **工作量**：2-3 天。风险：RANSAC 对合成数据的敏感度，需调阈值避免 flaky。

## T2 · step_import parser/converter（P0）

- **目标**：`step_parser.py`(24%) / `step_converter.py`(37%) → 60%+
- **依赖**：cadquery（环境已装）。
- **策略**：
  1. `BoundingBox`/`ModelInfo`/`EntityInfo` dataclass 构造与序列化；
  2. `StlExportOptions.linear_tolerance/angular_tolerance`（纯 property）；
  3. `ConvertResult.success` / `BatchConvertResult.success`；
  4. `_check_geometry_issues`（几何缺陷检测，可用 mock shape）；
  5. `_extract_model_info`/`_extract_entities`（用真实 cadquery shape，如 `cq.Workplane().box()`）；
  6. 用仓库内 `data/test_fixtures/*.step` 或 `data/external/cnc_machining/` 的真实 STEP 文件做一条集成冒烟。
- **工作量**：2-3 天。风险：cadquery 版本对 STEP 解析的兼容性。
