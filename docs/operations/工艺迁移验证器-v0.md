# 工艺迁移验证器 v0（B3）

日期：2026-11-14。状态：**v0 可用**，已在真实案例（25 孔板，FANUC 0i → GSK 980/25i）跑通。

## 解决的问题

"这套程序换到国产系统能不能用"以前只能口头保证。现在变成一张可核对的清单：**同一份工序计划**分别用两套后处理器生成程序，逐项比对功能等价性，方言差异单列提示。

## 判定口径

**功能项（任一不过即 FAIL）**

| 检查项 | 规则 |
|---|---|
| `cutting_segment_count` | 切削段（linear/arc）数量一致 |
| `cutting_motion_sequence` | 切削段类型序列逐段一致 |
| `cutting_endpoint_deviation` | 逐段终点坐标最大偏差 ≤ 0.001 mm |
| `arc_radius` | 圆弧半径差 ≤ 0.001 mm |
| `feed_rates` | 进给值集合一致（0.001 精度） |
| `spindle_speeds` | 主轴转速集合一致 |
| `xy_positions` | 全部 X/Y 定位点集合一致 |
| `drill_cycles` | 钻孔循环数量一致 |

**提示项（不计失败）**

- `total_segments`：总段数差异——快速定位拓扑可合法不同（G28 vs G30 参考点选择）；
- `dialect_codes`：仅在一侧出现的 G/M 代码（如 `G5.1` AI 轮廓控制仅 FANUC、`G30` 仅 GSK）。

## 用法

```bash
PY='C:/Users/<user>/AppData/Local/Programs/Python/Python314/python.exe'
$PY engineering/python/scripts/validate_controller_migration.py --target gsk_980_25i
# 其他目标：hnc_848_22 / knd_1000_2000_3000 / mitsubishi_m70_m80 / fagor_8055 / xmachine_xm100
```

支持的目标控制器来自 `GCodeGenerator.supported_controllers`（9 种）。脚本返回 0 表示 PASS，非 0 表示 FAIL，可直接接入 CI。

## 边界（重要）

1. 验证的是**后处理输出语义**，不是机床实际行为；不替代空运行与首件试切。
2. 只覆盖运动/工艺参数/循环数量；不检查宏变量、刀补建立时机、M 码时序语义。
3. 圆弧检查仅在程序含 R 或 IJK 且解析器识别出半径时生效；本案例 0 段圆弧。
4. 单个案例（矩形板 + 钻孔）；型腔/曲面/多轴迁移需补案例。
