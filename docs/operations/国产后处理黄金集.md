## 为什么 XM-100 未纳入

- XM-100 行程仅 **±50 mm**（100×100×100 有效区）；
- 本管线平面工序坐标不随工件零点平移：孔位已按「零点=毛坯中心」平移到 −40..40，但平面工序仍输出 `X195`；
- 因此 100×100 件无法在 XM-100 上生成合法程序。

**这不是放宽标准，而是暴露真实产品缺口**：工件零点（G54）偏移尚未贯通到平面工序。XM-100 的价值改为验证硬闸——生成时必须抛出 `ValueError: X100.0 超出 XM-100 X行程 (±50mm)`，测试已固化该行为。

## 归一化口径（逐字节比对的前提）

仅把日期 `YYYY-MM-DD` 替换为 `<DATE>`；其余字符（空格、换行、注释、大小写）一个不改。比对使用 Python 字符串全等，不是 diff 容忍。
