## 已知限制

### SessionStorage vs Cookies
- **当前**: 使用 SessionStorage（页面关闭后清除）
- **优点**: 安全性高，自动清除
- **缺点**: 无法跨标签页共享，刷新页面依赖 sessionStorage 恢复

### 生产环境建议
如果需要同步多个标签页的状态，建议：
1. 使用 BroadcastChannel API 实现跨标签页通信
2. 或升级到 Cookies 存储（HttpOnly + Secure）
