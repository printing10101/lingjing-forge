# P3-4: 首次试切件质量检测方案（三坐标 + 粗糙度 + 良品率）

**ADR 关联**: [ADR-019-车间落地准备.md](../adr/ADR-019-车间落地准备.md) P3-4
**状态**: 待执行（P3-1 / P3-3 完成后可启动）
**责任人**: 项目负责人 + 持证 CNC 操作员 + 导师 + 三坐标测量员
**前置文档**: [P3-1-控制器兼容性验证.md](P3-1-控制器兼容性验证.md)、[P3-3-颤振模型校准试验.md](P3-3-颤振模型校准试验.md)

## 1. 目标

基于 P3-1（控制器兼容性已通过）与 P3-3（颤振模型已校准）的成果，加工首个真实试切件，并通过三坐标测量、表面粗糙度测量、良品率统计三个维度验证全链路在真实加工环境中的可行性。

**核心验证命题**：灵境制造生成的 G 代码 + 推荐切削参数，能否在真实 CNC 机床上加工出满足工业硬门槛（配合面公差 0.01mm、良品率 0 缺陷容忍）的合格零件。

**产出**: `first_part_quality_report.json`（含尺寸测量、粗糙度、良品率、缺陷记录）

## 2. 工业硬门槛（必须满足，无例外）

| 门槛 | 指标 | 验证方式 |
|------|------|----------|
| 良品率 | 0 缺陷容忍 | 全尺寸检测 + 粗糙度检测 + 外观目视 |
| 配合面公差 | 0.01mm | 三坐标测量机（CMM） |
| 非配合面公差 | ±0.05mm（GB/T 1804-m） | 三坐标测量机（CMM） |
| 表面粗糙度（精加工面） | Ra ≤ 1.6μm | 粗糙度仪 |
| 表面粗糙度（粗加工面） | Ra ≤ 6.3μm | 粗糙度仪 |
| CNC 操作员 | 持证 | 证件复印件归档（见 P3-5） |
| 导师签字 | 必须 | 签字记录归档 |
| 车间保险 | 已生效 | 保险凭证归档 |
| 试切件材料 | 与 P3-3 校准试验同批次 | 材料质保书归档 |
| 刀具状态 | 与 P3-3 校准试验同型号、无异常磨损 | 刀具记录卡归档 |

## 3. 试切件设计原则

### 3.1 试切件几何特征要求

试切件应覆盖灵境制造全链路支持的全部典型特征，验证软件链路对真实几何的处理能力：

| 特征类型 | 在试切件中的体现 | 检测重点 |
|----------|------------------|----------|
| 平面（台阶面） | 至少 2 个台阶面 | 平面度、粗糙度 |
| 轮廓（外形） | 至少 1 个矩形外形 | 尺寸公差、垂直度 |
| 型腔（凹槽） | 至少 1 个矩形凹槽 | 深度、宽度、角落清角 |
| 孔（钻孔） | 至少 2 个不同直径孔 | 孔径、孔距、位置度 |
| 配合面 | 至少 1 个标注配合面（0.01mm 公差） | 严格公差验证 |

### 3.2 试切件尺寸约束

- 整体尺寸：建议 80mm × 80mm × 30mm 以内（适配常见机床工作空间与三坐标测量机量程）
- 材料：6061-T6（首选，校准数据充分）或 45# 钢（次选）
- 毛坯余量：单边 2-3mm（保留粗精加工分层）

### 3.3 试切件来源

试切件的 G 代码必须由灵境制造全链路生成，不可使用 CAM 软件手动编程：

```
照片（试切件参考模型）→ 3D 重建 → 几何特征 → 参数化几何 →
切削参数（基于 P3-3 校准后的 HRC52 / 6061-T6）→ 颤振预测 →
G 代码 → CAM 校验（P2-1 PyCAM 真实可用）→ cam_report.json →
持证操作员加载到机床 → 试切 → 质量检测（本方案）
```

## 5. 执行 SOP

### 步骤 1：试切前预检查

1. 核对全链路产物完整性（照片 → cam_report.json 链路可追溯）
2. 确认 P3-1 控制器兼容性报告 `overall_pass=true`
3. 确认 P3-3 颤振模型已校准（如试切件含 HRC52 材料）
4. 确认 CAM 校验通过：`cam_software_report.status ∈ {pass, manual_pending}`
5. 确认机床、刀具、毛坯、测量设备全部就位
6. 操作员、导师、测量员三方到场签字确认

### 步骤 2：毛坯装夹与对刀

1. 操作员按车间规程装夹毛坯（夹紧力、定位面确认）
2. 操作员执行对刀（X/Y/Z 轴零点设定）
3. 操作员输入刀具补偿值（长度、半径）
4. 项目负责人记录装夹照片、对刀数据
5. 导师现场确认装夹与对刀数据无误

### 步骤 3：粗加工试切

1. 操作员调用粗加工 G 代码程序（`O__ROUGH`）
2. 单段试运行首件，确认刀位正确、无碰撞
3. 全程粗加工，记录切削参数（v_c / f_z / a_p / a_e）
4. 记录切削过程中的异常（振动、噪声、切削液状态）
5. 粗加工完成，毛坯卸下，吹扫干净

### 步骤 4：精加工试切

1. 操作员重新装夹（如需精加工基准转换）
2. 操作员调用精加工 G 代码程序（`O__FINISH`）
3. 单段试运行首件，确认精加工余量合理
4. 全程精加工，记录切削参数
5. 精加工完成，工件卸下，吹扫干净

### 步骤 5：试切件外观目视检测

1. 目视检查试切件表面（有无刀痕、振纹、烧伤、毛刺）
2. 拍照记录整体外观 + 各特征局部
3. 记录任何可见异常（即使不影响尺寸，也需记录）
4. 外观异常件直接判定不合格，进入步骤 8 失败回退

### 步骤 6：三坐标测量（CMM）

1. 测量员在 CMM 上装夹试切件（基准面对齐）
2. 标定测头（使用标定球，确认测针半径）
3. 按试切件图纸测量全部关键尺寸：
   - 配合面尺寸（公差 0.01mm）
   - 非配合面尺寸（公差 ±0.05mm）
   - 平面度、平行度、垂直度、位置度
   - 孔径、孔距
4. CMM 输出测量报告（PDF + CSV）
5. 测量员签字确认测量数据

### 步骤 7：表面粗糙度测量

1. 在粗糙度仪上选择合适测量参数（取样长度、评定长度）
2. 使用标准样块校验粗糙度仪
3. 对每个加工面测量 Ra 值（每个面至少 3 个位置，取平均值）
4. 重点测量精加工面（公差 Ra ≤ 1.6μm）
5. 记录粗糙度仪测量原始数据

### 步骤 8：良品率判定

1. 汇总外观、尺寸、粗糙度三项检测结果
2. 按第 6 节验收标准逐项判定
3. 任一项不合格 → 整件判定为不合格
4. 生成 `first_part_quality_report.json`
5. 三方（项目负责人 + 操作员 + 导师）签字确认判定结果

## 7. 验收标准（充要条件，全部满足方为合格）

### 7.1 外观验收

1. 试切件表面无可见刀痕异常（正常切削纹理除外）
2. 无振纹（颤振预测失败的直接证据）
3. 无烧伤（切削温度过高，冷却不足）
4. 无毛刺（去毛刺工序前的状态记录）
5. 外观照片清晰，覆盖全部特征

### 7.2 尺寸验收（CMM）

6. 全部配合面尺寸偏差 ≤ 0.01mm
7. 全部非配合面尺寸偏差 ≤ ±0.05mm
8. 全部形位公差（平面度 / 平行度 / 垂直度 / 位置度）满足图纸要求
9. 全部孔径、孔距满足图纸公差

### 7.3 粗糙度验收

10. 全部精加工面 Ra ≤ 1.6μm
11. 全部粗加工面 Ra ≤ 6.3μm
12. 每个面至少 3 次测量，取平均值作为判定依据

### 7.4 良品率验收

13. **0 缺陷容忍**：任一项不合格 → 整件判定为不合格
14. `first_part_quality_report.json` 的 `overall_pass=true` 为唯一合格标志

### 7.5 可追溯性验收

15. 试切件唯一编号与全链路产物（照片 → cam_report.json → fpqr 报告）链路完整
16. 全部签字记录归档（见 P3-5）
17. 试切件实物归档（贴标签，存指定位置）

## 8. 失败回退路径

### 8.1 外观异常（振纹 / 烧伤 / 毛刺）

- **振纹**：可能是颤振预测失误 → 重新校验 P3-3 模型，检查切削参数是否落在稳定域
- **烧伤**：切削温度过高 → 检查冷却液供给、降低切削速度、检查刀具磨损
- **毛刺**：刀具钝化或进给过大 → 更换刀具、降低进给

### 8.2 尺寸超差

- **系统性偏差**（全部尺寸偏大或偏小）：对刀数据错误 → 重新对刀，检查刀具补偿
- **随机性偏差**（个别尺寸超差）：机床精度问题或工艺系统刚性不足 → 联系机床维修、检查装夹刚性
- **配合面超差**（>0.01mm）：精加工余量不足或刀具让刀 → 增加精加工余量、减小切削力

### 8.3 粗糙度超差

- **Ra 偏大**：进给过大、刀具磨损、切削速度不当 → 优化切削参数
- **Ra 不稳定**（同面不同位置差异大）：机床振动、装夹刚性不足 → 检查机床状态

### 8.4 失败后的处置

1. 不合格试切件**不可丢弃**，需归档（标记"不合格"）作为后续改进的对照基准
2. 失败原因分析报告归档（附在 `first_part_quality_report.json` 的 `defect_summary` 字段）
3. 调整方案需经导师签字确认后方可重新试切
4. 重新试切前必须重新走 P3-1 控制器兼容性验证（如 G 代码有改动）

## 9. 已知工程边界

### 9.1 首件试切的统计局限性

- **单件试切不代表批量良品率**：本方案验收的是"首件合格"，不是"批量稳定"。批量良品率验证需后续 P3-4-Extension（10-30 件小批量试切）。
- **0 缺陷容忍门槛的含义**：首件即合格为充要条件；首件不合格 → 必须分析原因、调整工艺、重新试切，不可"凑合接受"。

### 9.2 三坐标测量机（CMM）的局限性

- CMM 测量的是离散点，不能完全代表整个表面质量
- 复杂自由曲面（如叶轮曲面）的 CMM 测量需专用测头路径规划，本方案未覆盖
- CMM 测量精度受温度影响（标准 20℃ ± 2℃），非恒温车间需温度补偿

### 9.3 粗糙度测量的局限性

- 接触式粗糙度仪可能划伤软材料表面（如铝合金），需选低测力测头
- 粗糙度仪测量方向应垂直于加工纹理方向，否则数据失真
- Ra 不能完全表征表面质量（同 Ra 值可能有不同表面形貌），如有条件应补充 Rz / Rq / Sm 等参数

### 9.4 试切件归档的局限性

- 试切件实物长期保存可能氧化、变形（铝合金尤甚）
- 建议试切件涂抹防锈油 + 真空袋封装 + 干燥剂
- 归档位置避免阳光直射、温度剧烈波动

### 9.5 与论文实验数据的关系

- 本方案产出的 `first_part_quality_report.json` 是论文实验数据的**核心组成部分**
- 论文需报告：试切件设计、加工参数、检测结果、良品率判定
- 失败案例的失败原因分析同样有价值，论文应如实报告（不可仅报告成功案例）
- 全部原始数据（CMM CSV、粗糙度原始数据、照片 EXIF）需归档以备审稿人核查
