## 二、上线差距清单（按严重度）

### P0 — 阻断真实上线
1. **CI 主流水线是红的**：python-unit-tests 覆盖率 9.39% < 24% fail_under（exit 1）；eslint 16 errors；前端 coverage 步骤必崩。当前任何 push 到 CI 都会失败。
2. **GitHub Releases 无任何安装包**（API 实测 NO RELEASES），README 却声称"前往 GitHub Releases 下载最新安装包"→ 用户按文档操作是断链。tag v1.7/1.8/1.10 存在但无 release 资产。
3. **eslint 16 errors 全是真实 Vue 反模式**：`vue/no-mutating-props`（EquipmentSettingsDialog 4 处、WorkflowSubmitDialog 3 处、WorkspaceTrainForm 9 处）——子组件直接改父组件 prop，会造成状态静默串扰。

### P1 — 上线前必须修
4. **sidecar_main.py（开发模式入口）在有 torch 的环境启动必失败**：stub `__getattr__` 把 `__file__` 等 dunder 也返回成函数 → torch import 时 inspect 遍历 sys.modules 拿函数去 `.endswith` → 崩。打包运行时无 torch 不受影响，但开发机/CI 装 torch 后桌面 dev 模式无法启动。（已实测复现 2 次）
5. **顶层 MES/DNC 测试 25 个失败**：代码加了强制鉴权后测试未同步（全部 401）；且这些测试不在 CI 任何 job 里，属孤儿测试，失败无人知晓。
6. **前端 flaky**：SimulationViewer.test.ts 的 API 导出测试 10s 超时（3 连跑 2 次失败）——CI 上随机红，且掩盖真实回归。
7. **冷启动 ~20s vs Tauri 就绪超时 45s**：余量仅 25s，低配机/首次启动可能超时被杀；README 声称"3-8 秒"不实。
8. **api-docs 同步检查假绿**：脚本路径未随 V2.7 重构更新，永远报告"FULLY SYNCHRONIZED"。

### P2 — 质量债

10. **上线就绪评分报告（20260804）多个数字不实**：1927 口径错误、覆盖率 24.45% 未复现、eslint "0/0" 不实、vitest "×3 全绿" 不实、api-docs "" 假绿——作为上线依据不可信，需按实测重写。

### D 项：顶层 MES/DNC 孤儿测试收编（25 failed → 27 passed）

**背景**：tests/test_dnc_api.py、tests/test_mes_api.py 位于仓库根 tests/，不在 pytest.ini
testpaths（engineering/python/tests）覆盖范围，CI 从不收集（孤儿测试）；且代码加强制鉴权后
未适配，本地跑全部 401。

**处置**：
1. **迁移**：git mv 至 engineering/python/tests/api/，纳入 CI full suite（pytest tests/）收集。
2. **鉴权适配**：新位置由 engineering/python/tests/conftest.py 预置
   LNN_PERMISSION_ENFORCED=false（测试降级环境，与既有 API 测试一致）。
3. **MES 测试修复**：补 mocker 缺失 fixture 参数（NameError）、datetime.now() → UTC（P2-7 约定）、
   底部 import 上提到模块顶层；业务用例统一走 app.dependency_overrides[get_mes_client] mock 注入。
4. **DNC 测试修复**：原用例真实连接 OPC UA/MTConnect（5 次重试可挂起数十秒），改为 autouse fixture
   mock dnc_manager 网络方法（AsyncMock/PropertyMock），仅验证 API 契约。
5. **响应断言对齐**：当前统一信封格式为成功 {code:0, data:...}、业务错误 HTTP 200 + 非零 code、
   异常 {code, message}（5xx 消息脱敏为「系统内部错误，请联系管理员」）。
6. **CI 依赖安全**：改用 unittest.mock + monkeypatch，不依赖 pytest-mock（CI pip install 未包含）。

**验证**：pytest engineering/python/tests/api/test_dnc_api.py test_mes_api.py → **27 passed**。
