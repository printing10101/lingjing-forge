# 快速入门

> 本文档通过一个完整的示例（铝制法兰盘工件），带你 30 分钟内跑通"工件导入 → 工艺规划 → LNN 推理 → 刀轨仿真 → 后处理 → NC 代码导出"的完整流程。

## 0. 准备

- 已按照 [安装指南](./安装指南.md) 完成部署，服务运行在 `http://localhost:8765`
- 已创建至少一个普通用户账号（默认管理员 `admin` 除外）
- 浏览器已打开 Web 端：`http://localhost:8765/web`（或桌面端启动后自动弹出主窗口）

## 1. 登录系统

1. 打开主界面
2. 在右上角"登录"区域输入：
   - **用户名**：`admin`（或您创建的账号）
   - **密码**：安装时设置的密码
3. 点击 **登录** 按钮

登录成功后右上角会显示您的头像与用户名，并解锁全部功能。

## 2. 创建新项目

> 项目是工件的容器，所有工件、规则、工艺、NC 代码都归属于某个项目。

1. 在左侧导航栏点击 **项目管理**
2. 点击右上角 **+ 新建项目** 按钮
3. 填写项目信息：
   - **项目名称**：`flange-demo`（示例）
   - **工件类型**：`法兰盘`
   - **目标机床**：`Haas VF-2`（可在"机床管理"中预设）
   - **材质**：`6061-T6 铝合金`
4. 点击 **创建**

## 3. 工件导入

### 3.1 文件格式说明

| 格式 | 用途 | 大小限制 | 备注 |
|------|------|----------|------|
| `.step` / `.stp` | 3D 实体模型 | 50 MB | 推荐格式，包含完整几何与拓扑 |
| `.iges` / `.igs` | 3D 实体/曲面模型 | 50 MB | 老旧格式，部分曲面信息可能丢失 |
| `.dxf` | 2D 工程图 | 20 MB | 用于纯轮廓加工场景 |
| `.svg` | 2D 矢量图 | 5 MB | 通常需要后处理标注 |
| `.png` / `.jpg` | 2D 位图 | 10 MB | 系统会自动进行 AI 识别，精度较低 |
| `.pdf` | 2D 工程图（矢量） | 20 MB | 自动解析为矢量图元 |

### 3.2 导入步骤

1. 进入刚才创建的 `flange-demo` 项目
2. 在 **工件管理** 标签页中点击 **+ 导入工件** 按钮
3. 弹出导入对话框：
   - **来源类型**：选择 `本地文件` / `样例库` / `CAD 软件直连`
   - **文件**：拖拽 `.step` 文件到上传区，或点击浏览选择
   - **单位制**：`毫米`（默认）
   - **坐标系**：选择"自动检测"或手动指定
4. 点击 **开始导入** 按钮

系统会自动执行以下流程：

```
[STEP 解析] → [几何校验] → [特征识别] → [工艺预览] → [导入完成]
```

导入进度通过进度条实时反馈，通常 5-30 秒完成。

### 3.3 导入验证

导入成功后，您应该看到：

- 3D 预览窗口中出现工件的旋转视图
- **特征清单** 标签页列出识别到的加工特征（如"φ10 通孔 × 4"、"φ50 外圆"、"M6 螺纹孔 × 6"）
- **尺寸信息** 显示工件包围盒与关键尺寸

> **提示**：如果特征识别不全，可点击 **手动标注特征** 进入交互式标注界面补充缺失特征。

## 4. 工艺规划

### 4.1 参数配置

1. 在项目主界面点击 **工艺规划** 标签页
2. 系统会基于已识别特征推荐默认工艺路线，点击 **参数配置** 展开详细参数：

| 参数组 | 关键参数 | 默认值 | 说明 |
|--------|----------|--------|------|
| **粗加工** | 切削深度 `ap` | 2.0 mm | 单次切深，影响材料去除率 |
|  | 进给量 `f` | 0.15 mm/tooth | 每齿进给，影响表面粗糙度 |
|  | 切削速度 `Vc` | 250 m/min | 刀具线速度，影响刀具寿命 |
|  | 加工策略 | `等高线铣削` | 决定走刀模式 |
| **精加工** | 切削深度 `ap` | 0.3 mm | 精加工余量 |
|  | 进给量 `f` | 0.08 mm/tooth | 影响最终表面粗糙度 Ra |
| **刀具** | 主轴最大转速 | 12000 rpm | 受机床限制 |
| **冷却** | 冷却液 | `乳化液` | 影响刀具寿命 |

3. 点击 **保存配置**

### 4.2 AI 智能推荐

1. 切换到 **AI 推荐** 子标签
2. 点击 **▶ 开始推理** 按钮
3. 系统会调用 LNN 推理引擎：
   - 基于历史加工数据
   - 给出最优切削参数组合
   - 附带 **置信度评分**（0-1 之间）

4. 推荐结果示例：

```
[推荐方案 A] 置信度 0.92
  ap = 1.8 mm, f = 0.12 mm/tooth, Vc = 280 m/min
  预计刀具寿命: 145 分钟
  预计表面粗糙度: Ra 0.8 μm

[推荐方案 B] 置信度 0.85
  ...
```

5. 选择一个方案，点击 **采纳此方案**

### 4.3 预览操作

在 **预览** 标签页可查看：

- 工序列表（粗加工 → 半精加工 → 精加工 → 切槽 → 攻丝）
- 每个工序的走刀路径（俯视图 / 3D 视图切换）
- 单个工序的预计耗时与成本估算

## 5. 刀轨仿真

1. 在工艺规划主界面点击 **▶ 仿真** 按钮
2. 选择 **仿真精度**：
   - 快速（1×）：30 秒
   - 标准（4×）：2 分钟
   - 精细（16×）：5 分钟
3. 系统调用基于 Rust 引擎的体素仿真，输出：
   - 切削余量云图
   - 碰撞/过切检测报告
   - 工时估算
4. 仿真结果无碰撞后，点击 **通过**，进入下一步

## 6. 后处理与 NC 代码生成

1. 切换到 **后处理** 标签页
2. 选择 **目标数控系统**（后处理器）：
   - `Fanuc 0i-MF`（推荐示例）
   - `Siemens 840D sl`
   - `Heidenhain TNC 640`
3. 配置后处理参数：
   - **行号格式**：`N0001`（每 10 行递增）
   - **注释风格**：`(` 中文 `)`（如 `N10 G21 (毫米模式)`）
   - **换刀格式**：`T## M06`（如 `T01 M06`）
4. 点击 **生成 NC 代码** 按钮
5. 等待生成完成（通常 1-3 秒），系统会显示 NC 代码预览

### 6.1 导出

1. 在 NC 代码预览界面点击 **⤓ 导出** 按钮
2. 选择导出格式：
   - `.nc` / `.tap` 文本格式
   - `.txt` 文本格式
   - `.zip` 打包（含工艺单、刀具单、NC 代码）
3. 保存到本地

## 7. 验证

1. 切换到 **工时分析** 标签页
2. 系统自动汇总本次加工的关键指标：

| 指标 | 数值 |
|------|------|
| 总工序数 | 5 |
| 总切削时间 | 12 分 35 秒 |
| 预计刀具消耗 | 1.5 把 |
| 预计成本 | ¥ 45.20 |
| 表面粗糙度 | Ra 0.8 μm |

3. 完成后，点击 **归档项目**

## 8. 完整流程图

```
[创建项目] 
   ↓
[导入工件]  ← STEP / DXF / 样例
   ↓
[特征识别 + 手动标注（如需要）]
   ↓
[工艺规划]  ← AI 推荐 / 手动配置
   ↓
[刀轨仿真]  ← 碰撞 / 过切检测
   ↓
[后处理]   ← Fanuc / Siemens / Heidenhain
   ↓
[NC 代码生成与导出]
   ↓
[项目归档]
```
