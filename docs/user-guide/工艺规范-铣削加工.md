# 铣削加工工艺规范（试用版）

> 版本：v0.1（2026-10-14）｜ 定位：工艺决策知识库（RAG / Nexent `lingjing_machining_kb`）的规范类文档
> 口径声明：本文所有规则均锚定灵境制造仓库内已实现的校验口径（章节标注对应模块），不是泛泛的教科书摘抄；
> 数值类条目与 `app/data/cutting_parameters.json`（609 条，三路来源带溯源）一致，冲突时以数据库为准。

## 1. 切削参数选择原则

**对应模块**：`app/data/cutting_parameters.json`、`app/process_planning/`

1. **优先查库**：切参推荐先查切参数据库（材料 × 刀具系列 × 刀具材料），命中则取区间中庸值起步，按仿真反馈微调。
2. **区间语义**：库内速度/进给均为**常用推荐区间**（非最优点），保守工况取区间下限 1/3 处，高效粗加工可取 2/3 处，精加工取下限附近。
3. **溯源纪律**：每条参数带 `source` 字段（handbook_common_range / repo_seed_v1）。若推荐值无库内出处，必须声明"保守推荐，建议试切"（与 B5 决策智能体口径一致）。
4. **材料类别差异**：钛合金/不锈钢按"低速度-低进给-充分冷却"；铝合金按"高速度-大进给"；铸铁注意陶瓷刀具仅适用车削类工序。
5. **镍基合金（Inconel 718 等）**：进给取 superalloy 类区间（防止加工硬化），速度取区间下限，避免停刀滞留。

## 2. 颤振安全域

**对应模块**：`app/simulation/chatter/`（叶瓣图 + LNN 时序预测）、ChatterReport 契约

1. **单一判据**：以 `axial_depth_mm / limit_depth_mm`（切深比）为核心——**< 1.0 为稳定域，≥ 1.0 为不稳定域**，一律不得放行不稳定特征直接生成 G 代码。
2. **裕度分级**：`stability_margin ≥ 0.15` 正常加工；`0.02 ~ 0.15` 为低裕度边缘案例（需在决策中标注风险等级"中"）；`< 0.02` 视同临界，建议降切深一档。
3. **预测方法声明**：`method=analytical`（Kienzle/T-lusty 解析解）时结论为解析近似；`ltc_active=true`（LNN）时才可宣称模型预测。二者不得混称。
4. **不稳定域行为**：超限特征触发 `UNSTABLE_FEATURES` 失败（case 库实证：216 例），正确响应是**降切深/降切宽重规划**，不是绕过校验。

## 3. 参数越界处理（clamp 语义）

**对应模块**：G 代码生成参数校验（B 轴 48 例实证）

1. 进给/转速越界时产品行为是 **L1 clamp 建议（warning）而非拒绝**：越界值被夹到安全边界并附带建议说明。
2. 极端值（0 进给、负进给、99000 m/min）同样被 clamp 兜住，不产生危险 NC 输出。
3. 决策链路引用 clamp 后值时，须在依据中注明"原值越界，已按 L1 建议收紧"。

## 4. 程序级运动学校验（DNC 闸门）

**对应模块**：`app/simulation/kinematics/`（K001–K009）

NC 代码下发前必须通过运动学校验，任一失败即阻断 DNC：

| 码 | 校验项 |
|---|---|
| K001–K003 | 3 轴行程极限（X/Y/Z） |
| K004–K006 | 主轴转速 / 进给 / 快移上限 |
| K007–K008 | 扎刀（快速移动碰撞）/ 装刀干涉 |
| K009 | 程序级综合校验 |

## 5. 体素仿真强制校验 + DNC 硬闸

**对应模块**：`app/cam_validation/`、Rust compute-core 体素切削

1. **所有** AI 产出的 NC 代码必经体素仿真强制校验才可上机（产品叙事硬承诺，无例外通道）。
2. DNC 下发为硬闸兜底：校验未通过的任务在下发层直接拒绝。
3. 校验结果入案例库（`failure_cases.db`）：失败带 `source` 分类（unstable_features / pipeline_exception），成功仅记计数要素。

## 6. 装夹与工序排序

**对应模块**：`app/process_planning/`

1. 装夹方案优先平口钳（vise），薄壁/大件按特征说明升级真空吸盘或压板，并在决策依据中声明理由。
2. 工序排序遵循"先粗后精、先面后孔、基准先行"；同一特征粗精分离时注明中间余量。
3. 多工序计划的 seq 必须连续（E 轴 12 例双工序实证：seq=1/2 顺序入册）。

## 7. 数据口径（答辩/汇报引用规范）

1. 切参数据库：**609 条**（2026-10-14，三路来源带溯源；uniwear 派生路因无工况列未启用）。
2. 失败案例库：**641 行**（success 419 / failure 222；unstable_features 216 + pipeline_exception 6），one_pass_rate **0.6537**；B/C 轴含同参数复跑案例，统计计入分母（口径披露见 I1 §2）。
