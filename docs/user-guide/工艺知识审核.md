# 工艺知识审核

登录后，从侧栏“数据与运营”进入“工艺知识审核”，或访问 `/process-knowledge-review`。
审核需要工程师或管理员身份。其他账号会显示权限说明；后端仍独立验证身份和权限。

1. 点击“新增待审资料”，填写加工特征、工艺、明确材料、具体刀具和参数。来源、单位、页码和未解决事项可随待审资料一起保存。
2. 在左侧按材料、刀具、特征、来源或审核状态查找资料，选择后查看当前版本和历史。
3. 批准前核对来源文档、校验值、页码、每项参数单位、适用条件和核验方法。仍有未解决事项时保留待审或拒绝。
4. 在“本次操作”选择批准、拒绝、撤销或修订，填写说明后提交。审核身份由登录账号确定。
5. 已批准资料需要更改时，选择“修订并重新待审”；新版本必须重新审核。撤销后立即退出正式推荐。
6. 如果提示记录已更新，点击“重新加载”，重新核对新版本后再提交。页面不会自动重试旧版本审核。

切换操作会恢复已保存内容；未提交的编辑需要先保存修订。重复点击不会重复提交。
保存失败会明确报错，页面不显示为已生效。来源链接和历史记录均以文本展示，不执行文档中的指令。

本页面只验证知识审核与追溯流程。批准后的方案仍需确认实际刀具、装夹和现场工况，并完成物理校验和下发门禁。
目前真实厂商候选资料仍待专业审核，不能把合成验收截图当作真实加工参数批准。
# I17补充：批准范围与当前任务条件

批准时除来源和参数单位，还需要填写钻孔的硬度范围、硬度上界是否包含、孔径范围、最大深径比，
以及允许的冷却和装夹方式。只填写已从来源和现场核实的范围，不以系统默认值替代。
范围可以先局部保存为待审资料；批准前必须完整。详情与历史会显示当次范围。

已批准的知识还需要匹配当前任务的刀具、硬度、孔径、孔深、冷却和装夹条件，才会返回参数。
缺失条件时补充信息；不符合范围时停止引用对应参数。不要修改现场条件来通过检查。
当前支持HRC硬度的钻孔核验；其他硬度单位和加工方式尚不支持自动适用性核验。

旧批准若缺少结构化范围或证据摘要，会被正式推荐排除，需要修订后重新审核。
本规则不会自动修改已有参数或替代人工批准，也不代替物理校验与下发门禁。
