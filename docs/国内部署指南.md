## 部署方案概述

灵境制造针对国内环境提供三种部署方案：

| 方案 | 适用场景 | 数据库 | 安装步骤 | 推荐度 |
|------|---------|--------|---------|--------|
| **Docker 完整版** | 中大型企业、生产环境 | PostgreSQL + Redis + TDengine | 5 步 | |
| **SQLite 轻量版** | 单机部署、工厂车间、开发测试 | SQLite | 3 步 | |
| **离线安装包** | 无网络/内网环境、军工/政府 | SQLite 或 PostgreSQL | 3 步 | |

### 国内镜像源配置

项目统一的 `docker-compose.yml` 通过 `IMAGE_REGISTRY` 环境变量支持国内镜像源，在 `.env` 中配置即可：

- **Docker 镜像**：在 `.env` 中设置 `IMAGE_REGISTRY`（华为云 SWR / 阿里云 ACR）
- **pip 源**：阿里云镜像（`mirrors.aliyun.com`）
- **npm 源**：npmmirror（`registry.npmmirror.com`）
- **AI 模型**：魔搭社区（ModelScope）/ 国内 API

> 说明：项目仅提供 `docker-compose.yml`（完整版）与 `docker-compose-sqlite.yml`（轻量版）两个 compose 文件，不再单独维护 `docker-compose-cn.yml`。国内用户通过 `IMAGE_REGISTRY` 环境变量即可使用国内镜像源，无需额外 compose 文件。

## 快速开始

### 方案 A：在线部署（有网络）

```bash
# 1. 克隆代码
git clone https://github.com/printing10101/Virtual-Realm-Manufacturing.git
cd Virtual-Realm-Manufacturing

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，设置密码和 API Key

# 3. 下载 AI 模型（从魔搭社区）
pip install modelscope -i https://mirrors.aliyun.com/pypi/simple/
python scripts/download_models.py --all

# 4. 启动服务（国内版 docker-compose）
docker compose -f docker-compose.yml --profile full up -d

# 5. 访问
# http://localhost:8765
```

### 方案 B：离线部署（无网络）

```bash
# 1. 解压离线安装包（由 prepare_offline.sh 生成，见「离线安装包制作」）
tar -xzf lingjing_offline_package.tar.gz
cd offline_package

# 2. 运行安装脚本（脚本位于解压后的包根目录）
bash install_offline.sh   # Linux/Mac
install_offline.bat       # Windows

# 3. 访问
# http://localhost:8765
```

## 方案一：Docker 容器化部署

### 1. 环境要求

- **操作系统**：Linux (Ubuntu 20.04+, CentOS 7+) / Windows 10+ / macOS
- **Docker**：20.10+
- **Docker Compose**：2.0+
- **内存**：≥ 8GB（推荐 16GB）
- **磁盘**：≥ 20GB 可用空间

### 2. 安装 Docker（国内镜像）

#### Linux

```bash
# 使用阿里云镜像安装 Docker
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun

# 启动 Docker
sudo systemctl enable docker
sudo systemctl start docker

# 验证
docker --version
```

#### Windows

从 [Docker 官网](https://www.docker.com/products/docker-desktop) 下载 Docker Desktop，或使用离线安装包中的 `docker-installer/Docker Desktop Installer.exe`。

### 3. 配置环境变量

```bash
# 复制模板
cp .env.example .env

# 编辑 .env 文件
vim .env  # 或使用其他编辑器
```

**关键配置项**：

```bash
# 数据库密码（必须修改）
POSTGRES_PASSWORD=your_secure_password
REDIS_PASSWORD=your_secure_password

# AI 模型配置
AI_MODE=local  # 或 cloud

# 如使用云端 API（推荐阿里百炼）
CLOUD_API_KEY=your_aliyun_api_key
CLOUD_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
CLOUD_MODEL=qwen-plus
```

### 4. 启动服务

```bash
# 使用 docker-compose.yml 启动（在 .env 中设置 IMAGE_REGISTRY 使用国内镜像源）
docker compose -f docker-compose.yml --profile full up -d

# 查看日志
docker compose -f docker-compose.yml logs -f

# 检查服务状态
docker compose -f docker-compose.yml ps
```

### 5. 访问系统

- **Web 界面**：http://localhost:8765
- **API 文档**：http://localhost:8765/docs
- **Grafana 监控**：http://localhost:3000（默认 admin/admin）

## 方案二：SQLite 单机部署

适用于单机部署、工厂车间、开发测试环境。

### 1. 启动服务

```bash
# 使用 SQLite 版本（无需 PostgreSQL/Redis/TDengine）
docker compose -f docker-compose-sqlite.yml up -d

# 查看日志
docker compose -f docker-compose-sqlite.yml logs -f
```

### 2. 数据备份

SQLite 数据库文件位于 `./data/app.db`，定期备份此文件即可。

```bash
# 备份脚本示例
cp data/app.db data/app.db.backup.$(date +%Y%m%d)
```

## AI 模型配置

### 方式一：本地模型（ModelScope 下载）

#### 1. 安装 ModelScope

```bash
pip install modelscope -i https://mirrors.aliyun.com/pypi/simple/
```

#### 2. 下载模型

```bash
# 下载所有必需模型
python scripts/download_models.py --all

# 或指定模型
python scripts/download_models.py --source modelscope --model qwen2.5-coder:7b
```

#### 3. 配置 Ollama（可选）

如需使用 Ollama 运行本地模型：

```bash
# 安装 Ollama（国内镜像）
curl -fsSL https://ollama.com/install.sh | OLLAMA_MIRROR=https://ollama.mirror.cn sh

# 拉取模型（需先配置镜像）
ollama pull qwen2.5-coder:7b
```

### 方式二：云端 API（推荐）

#### 阿里百炼（推荐）

1. 访问 [阿里百炼控制台](https://bailian.console.aliyun.com/)
2. 创建 API Key
3. 配置 `.env`：

```bash
AI_MODE=cloud
CLOUD_API_KEY=sk-xxxxxxxxxxxxxxxx
CLOUD_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
CLOUD_MODEL=qwen-plus
```

#### DeepSeek

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)
2. 获取 API Key
3. 配置 `.env`：

```bash
AI_MODE=cloud
CLOUD_API_KEY=sk-xxxxxxxxxxxxxxxx
CLOUD_BASE_URL=https://api.deepseek.com/v1
CLOUD_MODEL=deepseek-coder
```

#### 智谱 AI

1. 访问 [智谱 AI 开放平台](https://open.bigmodel.cn/)
2. 获取 API Key
3. 配置 `.env`：

```bash
AI_MODE=cloud
CLOUD_API_KEY=xxxxxxxxxxxxxxxx
CLOUD_BASE_URL=https://open.bigmodel.cn/api/paas/v4
CLOUD_MODEL=glm-4
```

## 离线安装包制作

### 1. 准备离线资源

在有网络的机器上执行（推荐直接用项目自带脚本生成离线包，避免路径出错）：

```bash
# 一键生成离线包（产物：deploy/offline/lingjing_offline_package.tar.gz）
bash deploy/offline/prepare_offline.sh
```

该脚本会自动完成：导出 `docker-compose.yml` 中引用的基础镜像、下载 Python 依赖 wheel 包、打包 `app/` 源码与 `requirements.txt`、复制 `deploy/offline/install_offline.sh(.bat)` 与 `docker-compose*.yml` 等。

如需手动操作，基础镜像清单（与 `docker-compose.yml` / `Dockerfile` 对齐）：

```bash
# 注意：Python 基础镜像为 3.12-slim（非 3.11）
docker pull swr.cn-north-4.myhuaweicloud.com/library/python:3.12-slim
docker pull swr.cn-north-4.myhuaweicloud.com/library/postgres:15.10-alpine
docker pull swr.cn-north-4.myhuaweicloud.com/library/redis:7.4.2-alpine
docker pull tdengine/tdengine:3.0.7.5

# 下载 Python 依赖（wheel 包），使用阿里云镜像
pip download -r engineering/python/requirements.txt -d wheels/ -i https://mirrors.aliyun.com/pypi/simple/

# 下载 AI 模型（脚本位于仓库根目录 scripts/）
python scripts/download_models.py --all
```

> 离线包内已包含 `requirements.txt`（真实依赖清单，源自 `engineering/python/requirements.txt`）与 `install_offline.sh` / `install_offline.bat`（位于包根目录），无需再从 `scripts/` 单独拷贝。

### 2. 离线安装

将压缩包拷贝到目标机器，解压后运行：

```bash
# Linux/Mac
./install_offline.sh

# Windows
install_offline.bat
```

## 常见问题

### Q1: Docker 镜像拉取失败

**原因**：网络问题或镜像源不可用

**解决**：

```bash
# 检查网络连接
ping swr.cn-north-4.myhuaweicloud.com

# 如华为云不可用，可替换为阿里云镜像
# 编辑 .env 文件，将 IMAGE_REGISTRY 改为 registry.cn-hangzhou.aliyuncs.com
```

### Q2: AI 模型无法下载

**原因**：HuggingFace 被墙

**解决**：

```bash
# 使用魔搭社区（ModelScope）
pip install modelscope -i https://mirrors.aliyun.com/pypi/simple/
python scripts/download_models.py --source modelscope --all

# 或使用 HuggingFace 镜像站
export HF_ENDPOINT=https://hf-mirror.com
python scripts/download_models.py --source hf-mirror --all
```

### Q3: pip 安装依赖慢

**解决**：

```bash
# 使用阿里云镜像
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com

# 或永久配置
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
```

### Q4: npm 安装依赖慢

**解决**：

```bash
# 使用 npmmirror
npm install --registry=https://registry.npmmirror.com

# 或永久配置（已写入 .npmrc）
npm config set registry https://registry.npmmirror.com
```

### Q5: 数据库连接失败

**原因**：PostgreSQL 未启动或密码错误

**解决**：

```bash
# 检查 PostgreSQL 状态
docker compose -f docker-compose.yml ps postgres

# 查看日志
docker compose -f docker-compose.yml logs postgres

# 重置密码（谨慎操作）
docker compose -f docker-compose.yml exec postgres psql -U postgres -c "ALTER USER postgres PASSWORD 'new_password';"
```

### Q6: 内存不足

**解决**：

```bash
# 使用 SQLite 轻量版（无需 PostgreSQL/Redis/TDengine）
docker compose -f docker-compose-sqlite.yml up -d

# 或减少 Docker 资源占用
# 编辑 docker-compose.yml，调整 deploy.resources.limits.memory
```

### Q7: 如何备份数据

**PostgreSQL 备份**：

```bash
# 手动备份
docker compose -f docker-compose.yml exec postgres pg_dump -U postgres lnn_db > backup_$(date +%Y%m%d).sql

# 恢复
cat backup_20260624.sql | docker compose -f docker-compose.yml exec -T postgres psql -U postgres lnn_db
```

**SQLite 备份**：

```bash
cp data/app.db data/app.db.backup.$(date +%Y%m%d)
```
