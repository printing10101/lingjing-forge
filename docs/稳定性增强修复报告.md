### P0: 熔断器模式 已完成

#### 2. 熔断器实现 (`engineering/python/app/core/circuit_breaker.py`)

**核心组件**:
- `CircuitBreaker` 类：熔断器实现
- `CircuitBreakerRegistry` 单例注册中心
- `CircuitContextManager` 上下文管理器
- `CircuitBreakerConfig` 配置类

**状态流转**:
```
CLOSED (正常) → 失败次数≥阈值 → OPEN (熔断)
OPEN → 超时 recovery_timeout → HALF_OPEN (探测)
HALF_OPEN → 成功次数≥阈值 → CLOSED (恢复)
HALF_OPEN → 失败 → OPEN (熔断)
```

**配置参数**:
```python
config = CircuitBreakerConfig(
    failure_threshold=5,          # 连续失败阈值
    recovery_timeout=30,          # 恢复超时 (秒)
    half_open_max_calls=3,        # 半开探测次数
    success_threshold=2,          # 半开成功恢复次数
)
```

**使用方式**:
```python
from app.core.circuit_breaker import CircuitBreaker, CircuitBreakerRegistry

# 获取熔断器
registry = CircuitBreakerRegistry()
breaker = registry.get_or_create("llm_service")

# 执行受保护调用
try:
    result = breaker.execute(lambda: call_ai_service())
except CircuitBreakerOpenException:
    # 熔断器打开，调用降级策略
    result = fallback_strategy()
```

## 使用指南

### 1. 在 API 中使用新异常

```python
from app.core.exceptions import LLMTimeoutException

async def call_llm(provider: str, prompt: str):
    """调用 LLM 示例"""
    try:
        response = await llm_provider.provider.chat(prompt)
        return response
    except asyncio.TimeoutError as e:
        # 捕获超时，提升到特定异常
        raise LLMTimeoutException(
            provider=provider,
            timeout_sec=30
        ) from e
    except aiohttp.ClientConnectionError as e:
        raise LLMProviderException(
            provider=provider,
            message=str(e)
        ) from e
```

### 2. 在服务中应用熔断器

```python
from app.core.circuit_breaker import CircuitBreakerConfig

registry = CircuitBreakerRegistry()
breaker = registry.get_or_create(
    name="llm_provider",
    config=CircuitBreakerConfig(
        failure_threshold=5,
        recovery_timeout=30,
    )
)

@app.post("/api/ai/chat")
async def ai_chat(request: ChatRequest):
    try:
        # 受保护调用
        result = await breaker.execute(
            lambda: llm_provider.chat(request.prompt)
        )
        return result
    except CircuitBreakerOpenException:
        # 降级：返回缓存结果或默认响应

```
