# 灵境制造 · 一年优化计划（2026-10 → 2027-10）

> 本文是**产品/商业层年度计划**，位于《自主化与护城河路线图》（`docs/development/自主化与护城河路线图.md`，工程执行手册）之上：工程门禁任务以该路线图为准，本文不重复；本文回答的是「未来十二个月，先做什么、验收什么、不做什么」。
> 生成日期：2026-10-25。基线数字均为当日复核口径（代码在动，引用前需重新复核）。

---

## 0. 总纲

| 项 | 内容 |
|---|---|
| **北极星** | 出现第一个真实用户，敢把灵境制造生成的 NC 代码放上机床（先在教学机床/机加店成立） |
| **主线 A 产品闭环** | 四段全链条（设计意图 → 装配几何 → 工艺 NC → 加工执行）在单一软件内跑通，先求「体验闭环」不求「四段 SOTA」 |
| **主线 B 差异化资产** | LNN 证据输出 / 否决案例库 / 工艺迁移验证器——三件抄不走的资产 |
| **主线 C 可卖性** | 安装包、真实案例、License、演示视频、支持渠道六项门槛 |
| **硬约束** | 单人 + 大二/大三课业；2027-12 考研进入主线（本计划 2027-09 起减载交接）；2027-01 寒假实习申请窗口；同时在手服务单 ≤3；不建销售团队；黎阳线已关闭，不以叶片客户为规划锚点 |

**容量假设**：学期内每周 ≤10h；寒假/暑假每周 ≥30h。容量不足时的砍单顺序见 §6。

## 5. 节奏与容量

- **学期内**：每周 ≤10h，只推 P0/P1；P2 全部后置到假期。
- **寒假**：集中交付。若 FANUC/ZWSOFT 实习落地，寒假自动降级为碎片时间，仅保 B3 + C4，其余顺延——此为预期内情景，不是计划失败。
- **暑假**：全年最大交付窗口，A3/A4 拍板项必须在此落地。
- **2027-09 起**：考研线启动，本计划只留收尾、开源发布（D3）、交接文档三件事。

## 7. 不做清单（纪律，与既有定位一致）

1. 不做通用 AI-CAM 平台对标，不拼功能数与模型参数。
2. 不做四段全自研 SOTA；阶段 1 薄层、阶段 2 集成、自研守 ③④。
3. 不建销售团队；不跑全国，先做透贵阳。
4. 不同时在手 >3 个服务单。
5. 不重启黎阳/叶片客户规划；叶片结论只用于产品叙事。
6. 客户数据与论文数据严格隔离。
7. 不因进度压力降低工程门禁（路线图 §8：门禁缺口 = 任务未完成）。
