# ADR-006: 拍照重建模块（手机多角度照片 → mm 尺度网格）

**日期**: 2026-07-13  
**状态**: 已接受  
**决策者**: 项目负责人（独立开发）

---

## 背景

「灵境制造」原有几何输入路径是手工导入 STEP/IGES 文件，对非标零件、来料毛坯、客户来样的复刻场景适配性差。用户期望新增一条「拍照 → 三维 → 工艺 → G 代码」链路，并明确提出两条硬约束：

1. **硬件门槛**：必须能用普通手机完成多角度拍照重建，不强制要求工业级三维扫描仪；
2. **精度告知**：必须向用户明确说明手机摄影测量与工业级精度的差距，避免误用导致工件报废。

原提议依托 GitHub 上的 **LocateAnything-3B**（NVIDIA 视觉定位模型），但经核查该模型仅输出 2D bbox，**不具备 3D 重建能力**，不适用于本场景。需要重新选型。

工业级配合面公差（H7/h6 等）通常为 0.01 mm 量级，而手机摄影测量的物理精度极限为 0.1–1 mm，**两者相差 1–2 个数量级，物理上无法用手机摄影测量直接达到**。本模块输出必须经过 CAM 软件（NX/PowerMill/PyCAM）二次校验后才允许上机床，系统定位为「工程师助手」而非「全自动生产线」。

## 决策

采用 **COLMAP + OpenMVS** 作为主重建 pipeline，**Hunyuan3D-2** 作为备选（单图/少图神经生成，需 GPU），并以 **标定块法** 做尺度归一化。整体链路按 7 阶段推进，本 ADR 仅覆盖阶段 1（拍照重建 sidecar）。

### 7 阶段总体计划

| 阶段 | 内容 | 当前状态 |
|------|------|----------|
| 1 | 拍照重建 sidecar（COLMAP+OpenMVS / Hunyuan3D） | 本次完成 |
| 2 | 几何特征辅助提取 | 待启动 |
| 3 | 参数化几何输出（STEP） | 待启动 |
| 4 | 切削参数推荐 | 待启动 |
| 5 | 颤振预测接入（LTC） | 待启动 |
| 6 | G 代码生成（OCL） | 待启动 |
| 7 | CAM 校验对接 | 待启动 |

阶段 2-7 不在本 ADR 范围内，将各自单独编写 ADR。

### 阶段 1 实现要点

1. **外部二进制 + subprocess 模式**：COLMAP / OpenMVS 通过 `subprocess` 调用预编译二进制，而非 `pycolmap` Python 绑定。原因：Windows 上 `pycolmap` 编译复杂，外部二进制模式更易部署。
2. **尺度归一化用标定块法**：用户在拍摄场景中放置已知尺寸的标定块（推荐 30 mm 量块），重建后用标定块把无量纲 mesh 转成 mm 单位。无标定块时输出无量纲 mesh 并明确警告「不允许进入工艺仿真链路」。
3. **精度告知三档**：在 API 响应中注入 `precision_disclaimer` 字段，包含 `expected_accuracy_mm` / `suitable_for` / `not_suitable_for` / `industrial_hard_gates` 等 9 个字段，覆盖完整精度差距告知。
4. **条件导入**：trimesh / Pillow 缺失时降级运行（trimesh 缺失则原样拷贝 mesh 不做尺度归一化）。
5. **CAM 校验硬门槛**：所有输出均带 `requires_cam_validation=true` 字段，前端必须显示「需 NX/PowerMill/PyCAM 二次校验」提示。

## 理由

### 考虑的方案

1. **方案 A: LocateAnything-3B 单图 3D 重建**
   - 优点：单图输入，用户操作最简单
   - 缺点：**该模型仅输出 2D bbox，不具备 3D 重建能力**（已澄清）；不适用
   - 决策：**否决**

2. **方案 B: COLMAP + OpenMVS 传统多视角摄影测量**（已选）
   - 优点：
     - 完全开源，无 GPU 依赖，普通手机 + 笔记本即可运行
     - 精度 0.1–1 mm，满足「普通手机完成」约束
     - 工业上成熟方案，文献充分
     - 外部二进制模式部署简单
   - 缺点：
     - 需要多角度照片（≥ 8 张），用户操作稍复杂
     - 无量纲输出，需额外标定块做尺度归一化
   - 决策：**采纳为主 pipeline**

3. **方案 C: Hunyuan3D-2 单图/少图神经生成**
   - 优点：1-4 张照片即可生成 3D 模型，用户操作最简单
   - 缺点：
     - 需要 GPU（≥ 8 GB 显存），普通笔记本无法运行
     - 精度 1-5 mm，不如方案 B
     - 生成几何可能 hallucinate，工业可信度低
   - 决策：**采纳为备选**（GPU 可用时启用，作为少图场景的 fallback）

4. **方案 D: 商业三维扫描仪（如 EinScan-SE）**
   - 优点：精度可达 0.05 mm，工业级
   - 缺点：违反「普通手机就能完成」硬约束
   - 决策：**否决**

### 关键技术选择

- **不用 pycolmap Python 绑定**：Windows 上 `pycolmap` 编译复杂，需要 COLMAP SDK + CUDA 工具链，普通用户难以部署。改用「外部二进制 + subprocess」模式，用户只需下载 COLMAP 官方预编译包即可。
- **标定块法而非 AR 标记**：AR 标记（如 ArUco）需要打印，且对光照敏感；标定块（30 mm 量块）可购买标准件，精度高且耐用。
- **trimesh 条件导入**：trimesh 是尺度归一化的核心依赖，但桌面版可能未安装。条件导入 + 降级策略保证模块在缺失依赖时仍可启动（输出无量纲 mesh）。

## 后果

### 积极影响

- 普通手机即可完成三维重建，硬件门槛降到最低
- 精度差距通过 `precision_disclaimer` 字段完整告知，避免误用
- 标定块法把无量纲 mesh 转成 mm 单位，可进入后续工艺仿真链路
- 条件导入 + 外部二进制模式，部署简单，桌面版兼容性好
- 为阶段 2-7（特征提取 → 参数化 → 切削参数 → LTC 颤振预测 → G 代码 → CAM 校验）提供几何输入

### 消极影响

- 手机摄影测量精度 0.1-1 mm，**物理上无法达到工业级配合面公差 0.01 mm**
- 必须依赖用户正确放置标定块，否则输出无量纲 mesh 不可用于工艺仿真
- COLMAP / OpenMVS 二进制需要用户单独下载安装（约 200 MB）
- 重建耗时较长（单任务 5-30 分钟，取决于照片数量），用户体验不如实时扫描

### 技术影响

- 新增 `app/image_to_3d/` 模块（7 个文件：`__init__.py` / `colmap_runner.py` / `openmvs_runner.py` / `scale_normalizer.py` / `precision_disclaimer.py` / `task_store.py` / `pipeline.py`）
- 新增 `app/api/v1/image_to_3d/routes.py`（8 个 API 端点）
- 修改 `app/main.py`：添加条件导入 + 双重开关路由注册（`_IMAGE_TO_3D_AVAILABLE and config.image_to_3d.enabled`）
- 修改 `app/config/__init__.py`：新增 `ImageTo3DConfig` dataclass（14 个配置字段 + `precision_specs` 属性）
- `requirements.txt` 中 `trimesh==4.6.0` 与 `Pillow==11.1.0` 已存在，无需新增
- **不依赖 pycolmap**（采用 subprocess 外部二进制模式）

### 业务影响

- 用户可用普通手机完成非标零件 / 来料毛坯 / 客户来样的几何输入
- 系统定位明确为「工程师助手」，不替代专业 CAD 人员
- 所有输出必须经过 CAM 软件二次校验，保证生产安全
- 物理机床执行仍需 CNC 持证操作员 + 导师签字 + 保险（大一独立项目无法独立完成此环节）

## 精度档位规格

`ImageTo3DConfig.precision_specs` 属性返回三档精度规格：

| 档位 | expected_accuracy_mm | suitable_for | not_suitable_for | colmap_feature_threshold | openmvs_resolution_level |
|------|----------------------|--------------|------------------|-------------------------|--------------------------|
| coarse | 0.5-2.0 | 工艺理解 / 装夹方向预判 | 配合面 / 精密测量 | 2000 | low |
| standard | 0.1-1.0 | 非配合面尺寸复核 / 铸锻毛坯检验 | 配合面 / H7/h6 公差 | 4000 | medium |
| high | 0.1-0.5 | 小零件细节观察 | 工业级配合面 / 0.01 mm 公差 | 8000 | high |

### 工业硬门槛（precision_disclaimer.industrial_hard_gates）

- 良品率 0 缺陷容忍
- 配合面公差 0.01 mm 不可达（手机摄影测量物理极限 0.1 mm）
- CNC 操作员需持证
- 导师签字 + 保险
- CAM 软件二次校验（NX/PowerMill/PyCAM）
- 系统定位为「工程师助手」，非「全自动生产线」
