# ADR-016: 可解释性可视化

**日期**: 2026-07-14
**状态**: 已接受
**决策者**: 灵境制造团队
**关联**: ADR-001（LNN AI 引擎选型）、ADR-005（核心架构契约）、ADR-013（颤振预测接入）、ADR-015（项目导入导出）

---

## 背景

阶段 7 的目标是 **power user 粘性**：让工艺工程师不仅能"拿到预测结果"，还能"看懂
预测为什么产生、模型有多确信、如果改动输入会发生什么"。这是 LTC（液态神经网络）
颤振预测从"黑箱工具"演进为"工程师助手"的关键一步。

### 当前现状

1. **已有可视化但偏运维视角**：`python/app/ai/lnn/visualization.py` 已实现离线渲染
   管线，输出"预测值时间序列 + 帧能量 + 锚点漂移 + 轨迹偏差"四子图 PNG。但内容
   面向算法开发者做离线分析，未对接前端，工艺工程师无法在 Web UI 中查看。
2. **流式推理已有 PagedHiddenState**：`streaming.py` 的 `PagedHiddenStateCache` 管理
   关键帧隐状态分页（GPU/CPU 分级 + LRU 淘汰），`HiddenStatePage` 记录每帧隐向量
   与访问次数。这本身就是 LTC "连续时间记忆"的具象化，但当前仅供推理路径内部使用，
   未输出给可视化层。
3. **MC dropout 已存在但未可视化**：`LNNPredictor` 支持 MC dropout 不确定性估计
   （多次随机前向 → 均值 + 方差），结果存在 `PredictionResult.confidence`，但仅是
   一个标量，未展示分布形状、未对比不同样本的置信度差异。
4. **反事实分析缺失**：用户问"如果主轴转速提高 5%，颤振概率会变化多少？"目前
   只能手动改参数重新跑推理，没有系统化的反事实解释接口。
5. **工艺工程师信任问题**：车间用户对黑箱模型天然不信任，若不能解释"为什么模型
   认为会颤振"，预测结果难以指导实际调参。

### p7 目标

- **隐状态可视化**：将 LTC 推理过程中 PagedHiddenState 的隐向量轨迹投影到 2D/3D
  空间，展示"模型记忆"随时间的演化
- **注意力/门控可视化**：LTC 的 `dt` 门控（时间常数）决定每帧信息保留比例，将其
  沿时间轴可视化，揭示模型"关注"哪些帧
- **反事实解释**：给定基准输入 + 特征扰动范围，自动生成"特征→输出"响应曲线
- **置信度披露**：MC dropout 多次采样分布的可视化（直方图 + 置信区间 + 异常样本高亮）
- **非侵入**：不修改现有 `LNNPredictor` / `StreamingPredictor`，新建独立的
  `ExplainabilityService` 消费推理路径产出的中间状态

## 决策

采用"**消费推理副产物 + 独立解释服务 + 前端可视化面板**"三层方案，**不修改现有
LNN 推理路径**，新建独立的 `ExplainabilityService` 通过"快照采样"方式获取隐状态/
门控/置信度分布：

### 1. 三类解释结果契约

定义 `python/app/contracts/explainability.py`，三类解释结果共享 `ExplanationResult`
基类，每类对应一个独立子结构：

```
ExplanationResult (基类)
├── explanation_id: str           # UUID
├── explanation_type: str         # hidden_state | gate_dynamics | counterfactual | confidence
├── model_uri: str                # 被解释的模型（model://<name>/<version>）
├── source_snapshot_id: str       # 关联的实验快照（可追溯）
├── created_at: datetime
├── metadata: dict                # 解释元数据（如降维方法、MC 采样数）
└── payload: dict                 # 类型特定载荷（见下）

HiddenStateExplanation
├── frame_ids: list[int]          # 帧序号
├── projections: list[list[float]]  # 2D/3D 投影坐标（t-SNE / UMAP / PCA）
├── energies: list[float]         # 各帧信号能量（着色）
├── keyframe_flags: list[bool]    # 关键帧标记
├── projection_method: str        # tsne | umap | pca
├── hidden_dim: int               # 原始隐状态维度
└── sample_count: int             # 采样帧数

GateDynamicsExplanation
├── frame_ids: list[int]
├── gate_values: list[list[float]]  # 每帧的 dt 门控向量
├── time_constants: list[float]    # 派生时间常数 τ = 1/dt
├── mean_gate_per_feature: list[float]  # 特征维平均门控
└── anomaly_frames: list[int]      # 门控异常帧（颤振前兆候选）

CounterfactualExplanation
├── base_input: dict              # 基准输入特征
├── perturbed_feature: str        # 扰动特征名（如 spindle_speed）
├── perturbation_range: list[float]  # 扰动范围 [min, max]
├── perturbation_steps: int       # 采样点数
├── outputs: list[float]          # 每个扰动点的预测输出
├── output_metric: str            # 输出指标（chatter_probability | tool_wear）
├── sensitivity: float            # 灵敏度（∂output/∂input 数值导数）
└── critical_points: list[dict]   # 关键转折点（如概率跃变 >0.3）

ConfidenceExplanation
├── sample_count: int             # MC 采样数
├── mean_prediction: float        # 均值预测
├── std_prediction: float         # 标准差
├── percentiles: dict             # {p5, p25, p50, p75, p95}
├── histogram_bins: list[float]   # 直方图 bin 边界
├── histogram_counts: list[int]   # 直方图计数
├── epistemic_uncertainty: float  # 认知不确定性（模型不确定性）
├── aleatoric_uncertainty: float  # 偶然不确定性（数据噪声）
└── anomaly_score: float          # 异常分数（分布偏移程度）
```

### 2. 非侵入式采样策略

**关键约束**：不修改 `LNNPredictor.predict` / `StreamingPredictor.predict_stream` 的
签名与返回值。解释服务通过三种方式获取中间状态：

1. **被动捕获**：`LNNPredictor` 已在 `PredictionResult.model_info` 中携带流式元数据
   （keyframe_decisions / anchor_drift / trajectory_deviation），解释服务直接消费
   这些字段，不额外触发推理。
2. **主动快照**：`ExplainabilityService` 接受 `model_uri` + `input_data`，调用
   `LNNPredictor.predict_with_intermediates()`（**新增方法**，返回隐状态 + 门控的
   副本），不修改原 `predict` 签名。
3. **MC dropout 模式**：复用 `LNNPredictor` 现有的 MC dropout 推理路径
   （`predict_with_mc_dropout` 若已存在则直接调用，否则在解释服务内多次调用
   `predict` 并临时启用 dropout），收集分布样本。

`predict_with_intermediates()` 新增方法签名：
```python
def predict_with_intermediates(
    self,
    input_data: np.ndarray,
    return_hidden: bool = False,
    return_gates: bool = False,
) -> Tuple[PredictionResult, Optional[np.ndarray], Optional[np.ndarray]]:
    """返回预测结果 + 可选的隐状态/门控副本（不修改 self._state）."""
```

### 3. 降维与投影

LTC 隐状态通常维度为 32-128，需降维到 2D/3D 才能可视化：

- **PCA**：默认方法，线性、可复现、计算快（sklearn.decomposition.PCA）
- **t-SNE**：非线性、保局部结构、计算慢（sklearn.manifold.TSNE），仅对 ≤5000 样本启用
- **UMAP**：非线性、保全局结构、计算中速（umap-learn），可选依赖

降维器实例缓存在 `ExplainabilityService`，按 `model_uri + method` 复用，避免每次
重新拟合。降维器序列化到 `<output_dir>/explainability/reducers/<model_uri>.pkl`，
重启后加载复用（保证同一模型的投影坐标稳定）。

### 4. REST API 设计

prefix: `/api/v1/explainability`

```
POST   /hidden-state              生成隐状态投影解释
POST   /gate-dynamics             生成门控动力学解释
POST   /counterfactual            生成反事实解释
POST   /confidence                生成置信度分布解释
GET    /{explanation_id}          查询解释结果（持久化缓存）
GET    /                          列出历史解释记录（分页 + 过滤）
DELETE /{explanation_id}          删除解释记录
POST   /compare                   对比两个解释（基准 vs 扰动后）
```

权限模型：
- `explainability:read` —— 查询/列出/对比解释
- `explainability:write` —— 生成/删除解释

### 5. 持久化

新增两张表（Alembic 迁移 `c0d1e2f3a4b5_add_explainability.py`）：

```sql
CREATE TABLE explanation_records (
    id TEXT PRIMARY KEY,
    explanation_type TEXT NOT NULL,         -- hidden_state | gate_dynamics | counterfactual | confidence
    model_uri TEXT NOT NULL,
    source_snapshot_id TEXT,
    input_signature TEXT NOT NULL,           -- 输入数据 sha256（用于缓存命中判断）
    payload_path TEXT NOT NULL,             -- 解释载荷 JSON 文件路径
    payload_size_bytes INTEGER NOT NULL,
    metadata_json TEXT NOT NULL DEFAULT '{}',
    created_by TEXT NOT NULL,
    created_at TIMESTAMP NOT NULL,
    expires_at TIMESTAMP                    -- 可选过期时间（解释结果可缓存复用）
);

CREATE TABLE explanation_comparisons (
    id TEXT PRIMARY KEY,
    base_explanation_id TEXT NOT NULL,
    compared_explanation_id TEXT NOT NULL,
    comparison_type TEXT NOT NULL,          -- hidden_state_shift | sensitivity_diff | confidence_shift
    diff_payload_path TEXT NOT NULL,
    created_by TEXT NOT NULL,
    created_at TIMESTAMP NOT NULL,
    FOREIGN KEY (base_explanation_id) REFERENCES explanation_records(id),
    FOREIGN KEY (compared_explanation_id) REFERENCES explanation_records(id)
);
```

载荷文件存 `<output_dir>/explainability/payloads/<explanation_id>.json`，不写入数据库
避免单行过大。`input_signature` 用于缓存命中：相同模型 + 相同输入签名 + 相同解释
类型的请求可直接返回已有结果，不重复计算。

## 风险与缓解

| 风险 | 严重度 | 缓解 |
|------|--------|------|
| 隐状态降维计算慢（t-SNE 对 >5000 样本） | 中 | 默认 PCA，t-SNE 仅对 ≤5000 样本启用，超限自动降级 PCA |
| MC dropout 多次采样阻塞推理线程 | 中 | 采样数默认 30，最大 100；大采样数走 BackgroundTasks 异步 |
| 反事实扰动空间爆炸（多特征联合扰动） | 高 | v1 仅支持单特征扰动（`perturbed_feature` 单字段），多特征联合扰动列入 v2 |
| 解释载荷文件膨胀（高频生成） | 中 | `expires_at` 默认 7 天，定时任务清理过期载荷 |
| 降维器序列化兼容性（sklearn 版本升级） | 低 | 序列化时记录 sklearn 版本，加载时校验，不兼容则重新拟合 |
| 中间状态采样泄露训练数据分布 | 低 | 解释结果仅返回投影坐标与统计量，不返回原始隐向量 |
| LTC 模型未启用 MC dropout 时调用 confidence 端点 | 中 | 服务层检测模型能力，不支持时返回 `ErrorCode.INVALID_REQUEST` + 提示启用 MC dropout |
| 前端渲染大数据点（>10000 帧）卡顿 | 中 | 后端预降采样到 ≤2000 点，前端 ECharts 大数据模式 |

## 设计原则

1. **非侵入**：不修改 `LNNPredictor.predict` 签名，仅新增 `predict_with_intermediates`
2. **可缓存**：相同模型 + 相同输入签名的解释请求直接返回已有结果
3. **可追溯**：每条解释记录关联 `source_snapshot_id`，可回溯到具体实验
4. **可复现**：降维器序列化复用，随机种子固定（t-SNE `random_state=42`）
5. **优雅降级**：torch/umap/matplotlib 不可用时降级到仅 JSON 输出
6. **车间友好**：解释结果可导出为 PNG 报告（复用 `visualization.py` 渲染管线）
