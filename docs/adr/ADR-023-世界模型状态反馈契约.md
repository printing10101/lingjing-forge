# ADR-023: 世界模型状态反馈契约（initial_state 直连）

- 状态: 已接受（Accepted）
- 日期: 2026-10-21
- 关联: ADR-017（加工过程世界模型）、ADR-020（思路1 统一表示融合）、`reports/wm_real_finetune_20261021.md`

## 背景

PHM2010 真实数据微调（1.1.0-real）暴露根因性缺陷：`WorldModelNet` 的
LTC 解码器从 LSTM 压缩向量回归「绝对磨损水平」，预测的磨损**标准差为
0.0000**（塌缩为常数 0.103，真实 std 0.0465）——模型完全没用上磨损历史。
what-if 实验证明给解码器直连「最后观测状态」可让慢变量（颤振/磨损/Ra）
误差降 2–5 倍，但未带反馈训练时快变量（振动）被拖坏，必须契约级联合训练。

## 决策

1. **数据集契约**：`FusionTrajectoryDataset` 样本可选第 5 字段
   `initial_state: [state_dim]`（最后观测状态）。一致性契约：全量提供或
   全量缺省，部分提供构造期即报错；`fusion_collate_fn` 按元组长度自动
   兼容 4/5 元组 batch。
2. **训练器契约**：5 元 batch 时 `initial_state` 随 batch 传入
   `model.forward(initial_state=...)`；checkpoint metadata 记录
   `state_feedback`（训练期是否见过 initial_state）。
3. **数据构建器**：`build_wm_trajectory_dataset.py`（合成）与
   `build_wm_real_dataset.py`（PHM2010）npz 均含 `initial_state`
   （= `states[steps-1]` / `states[history-1]`）。
4. **推荐用法**：`initial_state` 与 **Δ 状态预测**（`--delta-prediction`）
   组合使用——`prev_state = initial_state + delta_head(h)`，水平被钉死、
   模型只学增量；非 Δ 模式下 initial_state 仅影响第一步。
5. **生产默认 checkpoint 维持 `1.1.0-real`**（绝对状态模式，快变量更稳）；
   `2.2.1-delta-real-sf` 作为慢变量/长时程变体留档，未替换生产默认。

## 验收（三折留一交叉验证，c1/c4/c6）

| 指标 | Δ+反馈（2.2.x） | 绝对状态（1.1.0） | 持久性基线 |
|---|---|---|---|
| 磨损 MAE（c6 折） | **0.0115**（1.1.0 为 0.0418，好 3.6×） | 0.0418 | 0.000179 |
| Ra MAE（c6 折） | **0.0218**（1.1.0 为 0.5056，好 23×） | 0.5056 | 0.000537 |
| 切削力增益（均值±std） | **+8.2% ± 2.7%（3/3 为正）** | +16.5% ± 8.2%（3/3 为正） | — |
| 振动增益（均值±std） | −23.2% ± 45.4%（1/3 为正，c4 折 −83%） | −9.9% ± 26.6%（1/3 为正） | — |

结论：状态反馈修复了慢变量水平塌缩，但磨损/Ra 仍**未打平**持久性基线
（PHM2010 磨损 5 步内变化极小，持久性近乎最优）；切削力增益在两种架构下
均稳健；振动增益两种架构下均不稳健。

## 风险与后续

- **磨损打平持久性需要信息增量**：dynamics 输入无切削力信号（力只出现在
  标签里），后续应把测力信号纳入 dynamics 输入或用更细步长数据。
- c4 组振动特性与其余组差异大（域偏移），留一交叉验证低估泛化；正式
  评估应使用真实产线数据而非单数据集留一。
- `2.2.2-delta-sf-w`（带权）磨损再降 34% 但常量维漂移，留作负结果。
- 向后兼容：不提供 `initial_state` 的数据集/调用方行为完全不变（6 条
  契约测试 `test_state_feedback_contract.py` 锁定）。
