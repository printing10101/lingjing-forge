## 详细实施计划

### Phase A: MTConnect 实时监控集成

#### Week 1: MTConnect 适配器框架
**文件结构**:
```
engineering/python/app/integrations/mtconnect/
├── __init__.py
├── client.py          # MTConnect 客户端 ( POLLING + 事件驱动)
├── agv.py             # Agent 视图定义 (XML 解析)
├── data_items.py      # 数据项 Schema 定义
├── adapter.py         # 适配器抽象基类
└── streaming.py       # WebSocket 实时流推送
```

**核心 API**:
```python
class MTConnectClient:
    def connect(self, agent_url: str) -> bool
    def poll_sensor_data(self, items: List[str]) -> Dict[str, Any]
    def subscribe(self, callback: Callable[[Dict], None])
    def disconnect()
```

**门禁**:
- ruff check 全绿
- mypy 0 错误
- 单元测试 15 个 (mock MTConnect Agent)
- 集成测试 (真实 Agent 模拟)

#### Week 2: 实时采集管道
**功能**:
- Polling interval 动态调整 (5s/10s/30s)
- 数据缓存 + MQTT 消息队列 (可插拔)
- WebSocket 实时推送 (前端订阅)

**测试**:
- 模拟 1000 条/s 数据流，延迟 <100ms
- 断线重连 + 幂等性验证

#### Week 3: 颤振检测 + 刀具寿命
**算法复用**: `app/simulation/cutting_force.py`
- 实时加速度数据分析
- 颤振预警阈值配置
- 刀具寿命预测可视化

### Phase C: 数据采集 API

#### Week 1: HTTP + WebSocket 接口
**端点设计**:
