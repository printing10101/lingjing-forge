# 预检发现-修复清单（接线前必须修复的 2 个真实 BUG）

**创建日期**: 2026-08-21  
**用途**: 接线前静态预检发现 2 个测试文件路径层级错误，会导致 2 个测试文件（~36 用例）在 pytest 收集时失败。
**优先级**: 必须在接线门禁验证前修复（否则 §6 门禁不通过）

---

## BUG 1：test_dialect_declared_hooks_phaseE.py 插件根路径错误

**文件**: `engineering/python/tests/unit/test_dialect_declared_hooks_phaseE.py`（第 18-21 行）

```python
_PLUGIN_ROOT = (
    Path(__file__).resolve().parents[3]   # 解析到 engineering/postprocessor-plugins（不存在）
    / "postprocessor-plugins"
)
```

**实际位置**: `postprocessor-plugins/` 在**仓库根**（parents[4] 层级），已实测确认
`C:\Users\<user>\Desktop\灵境制造（上线版）\postprocessor-plugins\siemens_840d\dialect.yaml` 存在，
而 `engineering\postprocessor-plugins\...` 不存在。

**后果**: `test_yaml_structure` 的 `path.exists()` 断言失败 + `_SIEMENS_HOOKS`/`_HEIDENHAIN_HOOKS`
加载失败 → 整个文件（~18 用例）setup ERROR/失败。

**修复**:
```python
_PLUGIN_ROOT = (
    Path(__file__).resolve().parents[4]   # 仓库根
    / "postprocessor-plugins"
)
```

## BUG 2：test_sovereignty_ratio.py scripts 路径错误

**文件**: `engineering/python/tests/unit/test_sovereignty_ratio.py`（第 11 行）

```python
_SCRIPTS = Path(__file__).resolve().parents[2] / "scripts"   # 解析到 engineering/python/scripts（不存在）
```

**实际位置**: `scripts/` 在**仓库根**（parents[4] 层级），已实测确认
`C:\Users\<user>\Desktop\灵境制造（上线版）\scripts\sovereignty_ratio.py` 存在，
而 `engineering\python\scripts\...` 不存在。

**后果**: `import sovereignty_ratio as sr` 抛 ModuleNotFoundError → 整个文件（~18 用例）setup ERROR。

**修复**:
```python
_SCRIPTS = Path(__file__).resolve().parents[4] / "scripts"   # 仓库根
```
