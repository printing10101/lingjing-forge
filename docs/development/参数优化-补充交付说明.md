## 设计要点（供验收）

1. **优雅降级**：无基线无数据 → 返回 None（API 404 提示）；统计回调异常 → 自动回退 L0
2. **物理安全**：所有推荐参数经 `clamp_to_safe_bounds` 钳制，`clamped` 标记审计
3. **可解释**：`Recommendation.to_dict()` 含 strategy/confidence/basis（依据+样本数）
4. **可扩展**：L2/L3（LNN/贝叶斯）预留——`ParameterRecommender` 构造参数可注入更高级策略
