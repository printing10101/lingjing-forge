## 目标

补全方言插件的**完整生命周期语义**。现有 `DialectRegistry` 只有
discover → compile → register 单向流程，缺卸载/重建/状态查询。
P4-2 提供白盒生命周期状态机，后续可被 registry.py 委托。

## 已交付

### 白盒模块
`app/postprocessor/dialect/_lifecycle.py`（纯 stdlib，不 import app 任何模块）：

| 声明/函数 | 说明 |
|---|---|
| `DialectLifecycleStage` | 生命周期阶段枚举（discovered/compiled/registered/unregistered/failed） |
| `LIFECYCLE_TRANSITIONS` | 转移规则表（含错误建议） |
| `can_transition(cur, tgt)` | 转移合法性判定 |
| `assert_transition_allowed` | 断言式校验（非法抛 ValueError） |
| `next_stage_after_success(cur, op)` | 操作成功后的下一阶段 |
| `next_stage_after_failure(cur)` | 操作失败 → failed |
| `can_discover(cur)` | 是否可重新发现（failed/unregistered 可恢复） |
| `is_terminal(cur)` | 终态判定（registered） |

状态转移图：
```
DISCOVERED → COMPILED → REGISTERED → UNREGISTERED → (可重新 REGISTERED)
    ↘ FAILED → DISCOVERED（恢复）
COMPILED ↘ FAILED
REGISTERED ↘ FAILED
```
