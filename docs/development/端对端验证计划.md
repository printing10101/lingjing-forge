## 目标

在 **1 台真实机床**上跑通「图纸 → 3D → 工艺 → NC → 加工 → 采集 → 优化」全流程，
验证功能缺口填补的实际效果，产出可复现的真实案例报告。

---

## 验证流程

```
Step 1: STEP 导入 ──► 3D 模型 + 特征识别（P1 白盒化成果）
Step 2: 工艺规划 ──► 刀路 + 参数生成
Step 3: NC 生成 ────► 方言选择（Siemens/Fanuc/Heidenhain）
Step 4: 仿真验证 ──► 碰撞/干涉检查
Step 5: 机床加工 ──► MTConnect 实时监控（Phase A）
Step 6: 数据采集 ──► cutting_experience 落库（Phase B/C）
Step 7: 参数优化 ──► 推荐参数 → 第二轮加工（Phase D）
Step 8: 对比报告 ──► 效率/寿命/质量数据
```

---

## 验收指标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| NC 生成成功率 | ≥95% | 生成成功的程序数 / 总程序数 |
| 加工误差 | <0.05mm | 三坐标测量仪 |
| 节拍提升 | ≥10% | 基线 vs 推荐参数 cycle_time |
| 刀具寿命 | ≥15% | tool_wear_percent |
| 数据采集成功率 | ≥99% | 落库数 / 采集数 |
| 全流程耗时 | ≤8 小时 | 单工件首件验证 |

## 测试场景

### 场景 1: 标准三轴铣削件
- 工件：6061 铝板（200×150×20mm）
- 特征：平面铣 + 3 孔钻 + 2 螺纹
- 验证：STEP→NC 全自动 + 数据采集

### 场景 2: 异形件（四轴可选）
- 工件：45 钢支架
- 特征：曲面 + 台阶 + 深孔
- 验证：多工序 + 参数推荐

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 机床 MTConnect 不兼容 | 准备 OPC UA 中间件/手工录入 fallback |
| 数据量不足 | 先手工录入 20 条基线数据启动 L0 |
| 现场调试时间不足 | 远程调试工具 + 分阶段验证 |
| 加工安全事故 | 首件低速验证 + 人工全程监控 |
