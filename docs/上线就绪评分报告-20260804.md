## 三、测试质量修复（fe-1 方法论沉淀）

- **vi.hoisted TDZ 铁律**：vi.mock 工厂引用顶层 const 必崩 → 批量转换 ~30 文件（4 轮扫描 + 手工补漏），修复后浮出 42 个被模块崩掩盖的真实测试失败并全部清零。
- **裸 `vi.mock('axios')` 禁止**：auto-mock 的 `create` 返回 undefined → http.ts 拦截器注册崩溃（顺序相关 flaky）→ 完整 axios 形状工厂。
- **stub 键名铁律（本轮新增）**：VTU 的 `global.stubs` 中 kebab 键（`'el-dialog'`）**不覆盖** setup.ts 的 Pascal 键（`ElDialog`）——必须用 PascalCase 键；否则局部 stub 静默失效（title 走 attrs 变 prop、v-if 失效、具名 slot 不渲染——CollisionAlertModal footer 之谜的根因）。
- **setup.ts 全局 stubs 增强**：ElAlert 补默认 slot（error-detail 渲染）、ElTableColumn 补 `$index` 作用域、ElUpload 渲染 accept 属性。
- **mockState 必须响应式**：普通对象状态使 `watch(status)` 不触发（定时器不停、6 vs 3 之谜）→ reactive() 包装。
- **生产不 return promise 的方法**：`await vm.method()` 无效 → `flushPromises()`。
- 大组件子组件化后的 stale 测试：SnapshotPanel（35→16 行为级）、DxfImportDialog（38→11 行为级）——删旧结构断言，改 vm 方法/事件/子组件 stub 断言。
