# -----------------------------------------------------------------------------
# CAM 软件二次校验（阶段 7 cam_validation）可选依赖
# -----------------------------------------------------------------------------
# 说明：cam_validation 模块通过 subprocess + JSON 协议解耦外部 CAM 软件，
#       以下依赖均为「按车间实际部署的 CAM 软件选择性安装」，不强制要求。
#       CamAdapter 内置自动降级到 manual 后端（永不阻塞任务）。
#
# 1. PyCAM（开源，default_cam_backend=pycam 时使用）
#    调用方式：python <LNN_CAM_PYCAM_EXECUTABLE> <gcode_path> <controller_type>
#    包装器脚本：python/scripts/cam_adapters/pycam/autorun_gcode_check.py
#    安装命令：pip install pycam==0.6.4
#    项目跟踪：https://github.com/VatFalk/PyCAM
#    注意：PyCAM 0.6.x 是刀轨生成器（DXF/STL → G 代码），非完整 G 代码仿真器；
#          无 __main__.py（python -m pycam 不可用），Importers/ 不支持 G 代码导入。
#          包装器脚本自实现轻量 G 代码解析器，执行 4 项基础检查
#          （工作空间边界 / 安全 Z / G0 材料内 / 刀轨连续性）。
#          生产环境推荐优先使用 nx_open / powermill 后端。
# pycam==0.6.4            # 可选：解开注释安装（仅在 default_cam_backend=pycam 时需要）
#
# 2. NX Open（Siemens，default_cam_backend=nx_open 时使用）
#    无需 pip 安装，NX 安装目录自带 Python 解释器与 NXOpen 模块。
#    配置方式：将 LNN_CAM_NX_OPEN_EXECUTABLE 指向 python/scripts/cam_adapters/
#              nx_open/autorun_gcode_check.py，由 NX 自带 Python 执行。
#    前置条件：车间机器已安装 NX（含 NX Open 授权）+ 控制器后处理配置。
#
# 3. PowerMill（Autodesk，default_cam_backend=powermill 时使用）
#    无需 pip 安装，PowerMill 安装目录自带 pmill.exe 可执行文件。
#    配置方式：将 LNN_CAM_POWERMILL_EXECUTABLE 指向 pmill.exe 路径，
#              cam_adapter 通过 /run=autorun_gcode_check.mac 调用宏文件。
#    前置条件：车间机器已安装 PowerMill（含刀具路径仿真授权）。
#
# 4. manual（默认兜底后端，无需任何外部依赖）
#    生成 markdown 校验清单，工程师在前端回填校验结果。
#    当上述 CAM 软件均不可用时，CamAdapter 自动降级到此后端。
